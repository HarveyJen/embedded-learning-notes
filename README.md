# 嵌入式学习资料库（embedded-learning-notes）

一套**可独立自学的嵌入式开发系统学习笔记**：从 C 语言 → 电路/数电/模电 → 51/STM32 → FreeRTOS/通信协议/OTA → 嵌入式 Linux → 就业，外加计算机四大件、EDA 工具与维修实战、进阶专题，共 **15 个模块 / 110+ 篇笔记**。

## 从哪开始读

1. **[00-嵌入式学习路线总览](00-嵌入式学习路线总览.md)** —— 全库唯一权威入口：学习路线、阶段验收标准、110+ 篇总索引、推荐资源；
2. **[00-嵌入式术语小词典（小白必读）](00-嵌入式术语小词典（小白必读）.md)** —— 约 150 个核心术语的大白话定义 + 生活化类比，先混脸熟再开学；
3. **[00-笔记整理方法论与复用指南](00-笔记整理方法论与复用指南.md)** —— 本库如何从 0 到 110+ 篇：资料获取与核实流程、写作规范模板、脚本资产、教训清单（任何学科整理可复用）。

## 笔记特色

- **定义先行**：每个概念有大白话定义 + 生活化类比（指针 = 写着门牌号的纸条）；
- **公式给算例**：逐符号解释 + 代入实际数字算一遍；
- **代码可编译**：练习答案与数据结构实现均为完整独立程序，复制即可运行；
- **理论挂主线**：触发式学习路径——标注每个理论概念在主线学到哪一步该上场；
- **资料可溯源**：每篇文末「深入资料」标注真实视频课/书籍章节/官方文档，不编造出处。

## 使用建议

按编号顺序学，每个阶段先读它的 00 目录；笔记定位为可独立自学的第一遍教材，想学更细顺着文末资料出处走。
