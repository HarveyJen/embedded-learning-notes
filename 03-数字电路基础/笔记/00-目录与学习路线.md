# 00 · 目录与学习路线

> 定位：数字电路是单片机的"方言课"——寄存器、时序、中断、通信外设这些主线概念，全都建立在数电的地基上，本模块用最短路径把这块地基打实。

**先说人话**：本篇讲什么，学完能做什么——

单片机本质是一大片封装起来的数字电路：你在 C 语言里写的 `P1 = 0xFE`、配的定时器分频、盯着的 SPI 时序图，全是数电概念的"软件投影"。本模块只讲**嵌入式用得上的那部分数电**：数制与逻辑门（看懂寄存器为什么写成 0x）、组合逻辑（看懂数码管位选为什么省 IO）、触发器与时序（看懂定时器分频和"建立/保持时间"）、常用 74 系列芯片（看得懂工业老设备 BOM 里的"逻辑 IC"一栏）、状态机与时序图（逻辑分析仪抓波形不抓瞎）。学完之后，06-51 和 07-STM32 里的"寄存器思维""位选""预分频""CPOL/CPHA"都不再是咒语，而是你亲手摸过、仿真过的东西。

## 学习时机：阶段一（编号顺序 = 学习顺序）

**先说清楚最关键的问题**：全库编号即学习顺序，本模块编号 03——排在 02-电路基础之后、51/STM32 之前，正是它在学习路线中的位置（以 [00-嵌入式学习路线总览](../../00-嵌入式学习路线总览.md) 阶段一的安排为准）。

安排依据说清楚：

- **它和 02-电路基础 是同期兄弟**：02 模块讲器件与模拟侧（电阻电容、二极管三极管，见 [03-半导体器件](../../02-电路基础/笔记/03-半导体器件.md)），本模块讲数字逻辑侧，两边合起来才是"电路"的完整拼图。02 学得差不多了，就穿插本模块；
- **它为 06/07 模块提前打底**：51 的寄存器与数码管位选、STM32 的定时器预分频与 SPI/I2C 时序，本模块每篇都埋了对应伏笔——先在"纯逻辑"层面见过一次，到单片机阶段就是"老朋友重逢"，理解速度快一倍；
- **它不抢主线时间**：建议每天 20~30 分钟，1~2 周读完，不写大项目、不占 C 语言和单片机的整块时间。

一句话记住：**编号就是课程表——03 号课，就是阶段一第三节。**

| 硬件（可选） | 74HC 系列 3~5 片 | 推荐组合：74HC00（与非门）+ 74HC04（反相器）+ 74HC138（译码器）+ 74HC595（移位寄存器），合计约 20 元 |

## 本模块高频术语 30 秒预览

本模块天天见面的黑话，先混个脸熟（每篇还会细讲）：

| 术语 | 白话解释 |
|------|----------|
| 位（bit） | 一个 0 或 1，对应一根引脚的一个电平状态 |
| 字节（Byte） | 8 个位一组，十六进制两位数正好装一个字节 |
| BCD | 用 4 位二进制装 1 位十进制数字，伺候数码显示 |
| 真值表 | 列出所有输入组合对应的输出，逻辑电路的"说明书" |
| 组合逻辑 | 输出只看当前输入，没有记忆（自动售货机） |
| 时序逻辑 | 输出还参考过去经历，有记忆（带存档的游戏机） |
| 译码器 | 编号→选中线，如 74HC138 用 3 根线选 8 路 |
| 锁存器 / 触发器 | 电路的记忆单元；前者电平触发，后者边沿触发 |
| 寄存器 | 一排共用时钟的触发器，CPU 存数的最小单位 |
| 分频器 | 把时钟频率除以 N 的电路，定时器的心脏 |
| 三态门 / 高阻 | 输出除 0/1 外还能"闭嘴让线"，总线不打架的关键 |
| 移位寄存器 | 数据一位位进、并行出的电路（串转并），如 74HC595 |
| 时序图 | 多根信号随时间变化的"心电图"，芯片的标准语言 |
| 建立 / 保持时间 | 数据在时钟沿前后必须稳定的最短时间 |
| Moore / Mealy | 输出只看状态 / 看状态又看输入的两种状态机 |
| 亚稳态 | 时序违例后输出非 0 非 1 晃荡的失控状态 |
| 片选（CS） | "点名"信号：选中某颗芯片才有权说话 |
| 位选 / 段选 | 数码管的两套线：选哪一位亮 / 这一位显示什么字形 |

## 学习前必读的四个建议

1. **和主线"对表"学习**：主线学到 C 位运算、51 数码管、STM32 定时器、通信外设时回来翻对应篇，联动感最强、留存率最高；
2. **动手优先于完整**：宁可每篇只跑通一个仿真，也不要六篇全看完零动手——数电是"拨出来"的直觉，不是"背出来"的结论；
3. **卡壳先查词典**：遇到陌生词先翻 [00-嵌入式术语小词典（小白必读）](../../00-嵌入式术语小词典（小白必读）.md)，再回本模块对应小节；
4. **叫法冲突以手册为准**：不同教材对同一电路叫法略有出入（触发器/双稳态、锁存/透明），以芯片数据手册和主线笔记的叫法为准。

## 常见坑（新手必看）

1. **把本模块当"另一门课"专门突击一个月**：没必要。它是配角，穿插进主线才是正确姿势——主线学到位运算/数码管/定时器/通信时，回来翻对应篇即可；
2. **纠结 TTL/CMOS 深水区**：门电路内部的晶体管结构、扇出系数计算这些，第一遍不用抠，知道"输入要给确定电平、输出带负载有限制"就够单片机阶段用了；
3. **只看真值表不动手**：真值表像乘法口诀，看着都会，动手拨一遍开关、量一次电平才算真会。哪怕用仿真，也要亲手拨；
4. **实物实验不给输入脚接确定电平**：CMOS 输入悬空会乱飘，实验现象"玄学化"多半是这个原因——按键必须配上拉/下拉电阻；
5. **试图背下所有 74 系列芯片**：不需要。记 4~5 个主力型号（00/04/138/245/595），其他随用随查 04 篇速查表；
6. **跳过时序图**：05 篇的时序图读法是 STM32 阶段调 I2C/SPI 的入场券，跳过它，逻辑分析仪抓到波形也看不懂；
7. **和 01-C/10 篇割裂学习**：数电的"与门"和 C 的 `&` 是同一个东西的两面，分开学等于把一件事做两遍。

## FAQ

**Q1：完全没学过 02-电路基础，能直接学本模块吗？**
基本能。本模块对模拟电路依赖很低，只要知道"高电平=接近电源电压、低电平=接近地"即可。唯一建议提前看的是 [02/03 半导体器件](../../02-电路基础/笔记/03-半导体器件.md)里三极管当开关的那部分，其他不依赖。

**Q2：要不要像大学数电课那样学卡诺图、画状态化简？**
本模块刻意没展开。卡诺图对"设计最优门电路"有用，但嵌入式开发里逻辑综合是编译器和硬件工程师的事，应用层更需要的是"看懂时序、看懂芯片手册"。想补全学术拼图，见每篇"深入资料"里的教材。

**Q3：学完本模块能干什么？还是写不了单片机程序啊？**
它的价值是"把后面的学习速度翻倍"而不是"直接产出程序"。就像学游泳前先不怕水——到 06/07 模块遇到寄存器、位选、分频、时序图时，别人在啃新概念，你只是在回忆旧朋友。

**Q4：FPGA 需要学吗？嵌入式岗位要求里有。**
入门阶段不需要。本模块的数电知识是 FPGA 的前置，但学完本模块去写 Verilog 还为时过早；建议嵌入式主线走完阶段二后，再决定是否开 FPGA 分支。

**Q5：笔记里有些内容和 01-C/10 篇、04/51 的笔记重复了，正常吗？**
正常且故意为之。同一概念（如位运算与逻辑门）在"软件视角"和"硬件视角"各讲一遍、互相引用，是这套笔记刻意设计的"双面讲解"——重复的是概念，新增的是它背后的电路真相，两边对照记得更牢。
