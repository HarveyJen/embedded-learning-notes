# 03 · 触发器与时序逻辑

> 定位：数字电路的"记忆课"——锁存器/触发器给电路装上记忆，寄存器、计数器、分频器由此诞生；CPU 寄存器和 STM32 定时器的数电原型全在这一篇。

**先说人话**：本篇讲什么，学完能做什么——

上一篇的组合逻辑"过目就忘"，但真实芯片必须记得事：寄存器要记住你写入的值、计数器要记住数到几、状态机要记住走到哪一步。给电路装"记忆"的元件就是**触发器**。学完本篇你能：说清锁存器和触发器的区别（这是面试高频题）；明白"C 语言里的变量存在寄存器里"这句话的硬件实体是什么；看懂 STM32 定时器分频公式里 (ARR+1)(PSC+1) 的数电原型；并且学会读时序图的基本功——后面 SPI/I2C 时序图、逻辑分析仪抓波形全靠它。

## 一、时序逻辑：给电路装上记忆

**这是什么**：输出不仅取决于当前输入，还取决于电路"过去经历过什么"的逻辑。靠什么记过去？靠**反馈**——把输出绕回输入，让电路"自己锁住自己"。类比：组合逻辑像按住才亮的门铃，松手就忘；时序逻辑像拨动开关的墙壁电灯——拨一下，状态被"记住"，你去睡了它还保持。

时序逻辑家族的两个分层，先立好路标：

- **锁存器（Latch）**：最原始的记忆单元，**电平触发**；
- **触发器（Flip-Flop）**：升级版，**边沿触发**，现代同步设计的绝对主角。

一整个时序系统还有第三个角色：**时钟（Clock）**——一根全局"节拍器"信号线，周而复始地高低变化，给所有触发器喊口令。现代芯片是"同步设计"：一切动作听时钟指挥，这也是为什么 STM32 要先配时钟树再干活（[05/01 工程建立与时钟树](../../07-STM32/笔记/01-工程建立与时钟树.md) 的数电根源）。

## 二、锁存器 vs 触发器："门开着都能进" vs "喊口令才能进"

**先看最小记忆单元 RS 锁存器**：两个与非门交叉反馈（门1输出接门2输入，门2输出接门1输入）。置位端 S 有效时输出变 1 并自我保持；复位端 R 有效时输出变 0 并保持；都不动时——**输出保持原样，这就是"记忆"**。反馈的意义就在这：输出绕回输入形成闭环，不需要外界持续输入也能维持状态。

**D 锁存器：电平触发**。在 RS 前面加一级门，整理成"数据 D + 使能 EN"两根线：

- EN=1 期间（**使能电平有效**）：Q 跟着 D 走，D 怎么变 Q 立刻跟着变——**门开着，谁都能进出**；
- EN=0：门关闭，Q 冻结在关门瞬间的值——"记忆"生效。

**D 触发器：边沿触发**。两级 D 锁存器串联（主从结构），两级使能反相：时钟低电平时主锁存器开门采数据、从锁存器关门锁旧值；时钟翻高的瞬间，主门关、从门开——**Q 在时钟上升沿的那一刻，把 D 的值"拍照定格"**。之后时钟高电平期间 D 再怎么变，Q 都不动——**喊了口令才能进，一人一张票，迟到不补**。

| 对比项 | 锁存器 | 触发器 |
|--------|--------|--------|
| 触发方式 | 电平触发（使能期间透明） | 边沿触发（时钟沿瞬间采样） |
| 类比 | 门开着都能进 | 喊口令才能进 |
| 危险点 | 使能期间输入的毛刺直接穿透到输出 | 只对时钟沿前后一小段时间的输入敏感 |
| 现代芯片里 | 少用（异步透明难分析） | 绝对主角 |

**为什么单片机全用边沿触发**：电平触发期间，输入上的毛刺会"直播"到输出；边沿触发把采样时刻压缩到时钟沿一瞬，全芯片所有触发器都在同一拍拍照——**确定性**。这就是"同步设计"能大规模造芯片的前提。

### 同步 vs 异步：一个必须建立的直觉

- **同步系统**：所有触发器共用同一个时钟，动作整齐划一——好分析、好设计，是现代芯片的默认选择；
- **异步系统**：各部分各走各的节拍（如本篇四节的行波计数器进位逐级传递、芯片的异步复位脚）——省元件、响应快，但延迟逐级累积、难做时序分析；
- **同步化手段**：异步来的信号（按键、传感器脉冲）先进一级触发器"对表"，再进系统——05 篇讲亚稳态时会回来收网这条线；
- 工程直觉一句话：**内部逻辑尽量同步，跨越时钟边界的地方才谈异步处理**。

## 三、D 触发器与寄存器：CPU 寄存器的数电原型

**这是什么**：把 8 个（或 32 个）D 触发器排成一排，**共用同一个时钟和使能**，每个触发器存 1 位——这排触发器就是一个 8 位（32 位）寄存器。类比：8 个人一人拿一块写字板，喊"拍"的口令同时抄下各自面前的数字，然后集体保持。

**"写寄存器"的硬件过程**（对应 [06/02 GPIO与寄存器思维](../../06-51单片机/笔记/02-GPIO与寄存器思维.md)里的写操作）：

```
C 语言：P1 = 0xFE;

硬件层面每一步为什么：
1. CPU 把 0xFE（1111 1110）放到内部数据总线上——8 根线上出现确定的电平组合；
2. 写信号（时钟/使能）给出上升沿——"喊口令"；
3. P1 口的 8 个 D 触发器在同一沿各拍一张照：bit0 记下 0，其余位记下 1；
4. 这 8 个触发器的输出直接连到芯片引脚驱动电路——引脚电平从此变成写入的值，并保持到下一次写。
```

所以 [C/10 篇](../../01-C语言基础/笔记/10-位运算与嵌入式C编程.md)里的"读-改-写"三步，硬件上就是"总线上的值摆好 → 沿来了 → 触发器组定格"。变量、寄存器、RAM 单元，在数电层面都是"一排被口令管理的触发器"——这就是"内存是记忆的载体"的最底层解释。

### 读寄存器为什么无损：和写操作对对账

写是把总线值"拍"进触发器（**改变**状态）；读只是把触发器的输出"抄"到总线上给 CPU 看（**不改变**状态）——像看温度计读数，看了温度也不会变。这一抄一拍内完成、可无限次重复，这就是为什么调试器能反复读外设寄存器排障而系统毫无感觉（寄存器窗口的用法见 [05/07 调试实战](../../07-STM32/笔记/07-调试实战.md)）。而"读-改-写"里的改，就是把抄出来的值在 CPU 里加工后，再走一遍写流程拍回去。

## 四、计数器与分频器：定时器预分频的思想原型

**这是什么**：把 D 触发器的输出非端接回自己的 D 输入（Q# → D），就成了一个"时钟每来一个沿就翻转一次"的单元。翻转频率是时钟的一半——这就是**二分频器**；把一串这种单元级联，输出频率逐级减半，同时整体在读数上表现为"逢二进一的二进制计数器"。**计数器和分频器是同一套电路的两种用法**：盯单个位是分频，把所有位合起来读是计数。

逐级看现象（假设输入时钟 8Hz）：

```
CLK (8Hz) → [触发器1] Q0 输出 4Hz → [触发器2] Q1 输出 2Hz → [触发器3] Q2 输出 1Hz

为什么频率减半：Q# 接 D，输入每 2 个上升沿才让 Q 完成一次"0→1→0"完整周期，
所以输出周期翻倍 = 频率减半 = ÷2。
为什么同时是计数器：把 Q2 Q1 Q0 当二进制数读，每来一个 CLK 它就 +1——
8Hz 输入下，三个触发器的状态依次是 000,001,010,011... 正好在数数。
```

**接到 STM32 定时器上**（[07/03 定时器与PWM](../../07-STM32/笔记/03-定时器与PWM.md) 的伏笔现在收网）：STM32 定时器的主公式

```
T = (ARR + 1) × (PSC + 1) / TIM_CLK
```

逐符号拆：

- **TIM_CLK**：进入定时器的原始时钟（如 72MHz）——最上游那个"节拍器"；
- **PSC**（预分频值）：定时器内部一个真正的分频器寄存器，把时钟 ÷(PSC+1)。为什么 +1？因为硬件从 0 开始数，写 0 表示"不分频"，写 71 表示 ÷72——**你在本篇看到的 ÷2 级联分频链，就是它的原型，只不过位数做成了 16 位可编程，除数任意**；
- **ARR**（自动重装载值）：计数终点。CNT 从 0 数到 ARR 就溢出并归零重数，一轮共 (ARR+1) 拍——同样是"从 0 数起所以 +1"；
- **T**：一轮的总时长 = 每拍时长 × 每轮拍数。

例：72MHz 主频想定时 1ms：72,000,000 × 0.001 = 72,000 拍一轮。拆成 PSC=71（÷72 → 1MHz，每拍 1μs）、ARR=999（数 1000 拍）。当时你觉得这公式是咒语，现在你知道它就是"分频链 + 计数器"两个数电原型的软件参数版。51 的定时器初值计算同理（[04/04](../../06-51单片机/笔记/04-中断与定时器.md)），只是重装要软件手动。

### 51 与 STM32 定时器对照（数电视角）

| 对比项 | 51 定时器 | STM32 定时器 |
|--------|-----------|--------------|
| 分频 | 机器周期级固定分频（典型 ÷12，型号而异） | PSC 可编程 ÷(PSC+1)，任意档位 |
| 计数终点 | 手动算初值装入 TH/TL | ARR 硬件自动重装 |
| 数电原型 | 计数器 + 软件置初值 | 分频链 + 计数器 + 重装寄存器 |
| 常见坑 | 忘了"从 0 数起"的 +1 | 同样的 +1，外加 PSC/ARR 两级都要 +1 |

### JK 与 T：D 的两个亲戚（认识名字即可）

- **T 触发器**：T=1 时每个时钟沿翻转一次、T=0 保持——本节二分频器用的就是它；
- **JK 触发器**：T 的加强版，J=K=1 翻转、J=1 K=0 置 1、J=0 K=1 置 0、全 0 保持——老教材的老主角；
- 现代设计里它们都能用 D 触发器加一小撮反馈门等效出来，所以新芯片里 D 是绝对主角；JK/T 认识名字、面试能说清即可。

### 移位寄存器：下一场大戏的预告

把 D 触发器首尾串联（前一级 Q 接后一级 D）、共用时钟，每来一个沿全队数据整体右移一格——这就是**移位寄存器**。它一头串行进（省线）一头并行出（好接外设），是"串转并"的标准积木；04 篇重头戏 74HC595 的核心就是"8 级移位 + 输出锁存"。这里先立此存照，下一篇马上见实物。

### 环形计数器一句话：移位寄存器转圈圈

把移位寄存器的末级输出接回自己的输入，事先塞进一个 1，它就在里面转圈——每一拍只有一个输出为 1，轮流"值班"。这就是**环形计数器**：LED 跑马灯、流水灯顺序控制、逐路轮巡指示，全是它的直接应用；它还天生是"独热编码"（05 篇会提到）的硬件样本。

## 五、时序图读法入门

**这是什么**：时序图是多根信号线随时间变化的"心电图"，横轴是时间（从左往右），每行一根信号，高低跳变就是电平翻转。芯片手册里所有通信协议（SPI/I2C/UART）和行为要求（建立/保持时间）都用它表达——**不会读时序图，就等于看不懂器件的"使用说明书"**。

三个最小概念，先在这篇打地基：

- **时钟沿**：时钟信号从低跳高叫**上升沿**，从高跳低叫**下降沿**。边沿触发器件的"采样口令"就是指定的那个沿；
- **建立时间 t_su**：数据必须在时钟沿**之前**提前稳定好的最短时间。类比：上课铃响（时钟沿）之前你必须已经坐到座位上，铃响瞬间才冲进来不算到；
- **保持时间 t_h**：时钟沿过后数据还得继续稳定一小会儿。类比：下课铃响了也不能立刻起身冲出门，得等老师说完最后一句。

```
        ← t_su →│↑│← t_h →
数据 D: ──值A─────────值B──────
             │
时钟 CK: ────┘↑（上升沿采样，采到的是"值A"）
```

为什么画 D 和 CK 要这么对齐：**采样沿那一瞬间，D 必须已经是值 A 且再稳 t_h**。如果 D 恰好在沿附近变化（违反建立或保持），采到的结果就不可预测——这个后果 05 篇专门讲（毛刺与亚稳态）。现在只需记住读图口诀：**先找时钟沿，再看沿前后数据稳不稳**。下一篇 04 篇速查芯片时你会用到"移位时钟沿采数据"，05 篇精读 SPI/I2C 时序图时全套放大。

### 最小练习：一眼看懂"沿在说话"

下面是任意"时钟 + 数据"对的通用长相（两根线的时间对齐是关键）：

```
          ①       ②       ③       ④
CLK:  ────┐↑─────┐↑─────┐↑─────┐↑────
数据:  ──X═══════Y═══════Z═══════W══════
          采X     采Y     采Z     采W
```

- 每个 ↑（上升沿）是一个采样快门，采的是**沿之前已稳定**的那段电平（①采 X）；
- 数据线上的 X→Y 跳变必须安排在两个快门**之间**完成——离快门越远越安全（建立/保持裕量越大）；
- 带着这个模型去看任何芯片手册的时序图：先标沿、再标数据段，十图九通。

## 常见坑（新手必看）

1. **锁存器触发器混为一谈**：面试送分/送命题。一句话区分：电平触发=锁存器，边沿触发=触发器（"透明"与"定格"）；
2. **以为 +1 是玄学**：PSC/ARR/重装初值全是"从 0 数起"的产物——数 N 拍要数 0 到 N-1，所以配置值写 N-1。想通一次终身免疫；
3. **实物实验时钟脚悬空**：触发器没有时钟就永远不采样，输出"死"在初值——先确认节拍器在跳，再查数据线；
4. **仿真看波形只看一根线**：时序图必须多根信号对照读（时钟沿和数据的关系），单看一根等于只看心电图不看时间轴；
5. **把"边沿触发"写成"上升沿触发"**：有的器件指定下降沿采样（SPI 某些模式），读手册时"沿"的方向是重点，别默认都是上升；
6. **分频器级联后数错总频率**：n 级 ÷2 链总分频是 2ⁿ，三级是 ÷8 不是 ÷6——和二进制位权（01 篇）是一个数学；
7. **级联分频只盯最后一级输出**：中间级的分频信号也是资源（8Hz 链里 4Hz、2Hz 同时可得），只用末级等于白白浪费一排现成的分频器。

## FAQ

**Q1：为什么叫"D 触发器"，D 是什么？**
Data（数据）的 D——它只干一件事：时钟沿到来时，把数据线 D 上的值存进 Q。一个输入一个输出，规则最简单，所以成了寄存器、移位寄存器、计数器的万能积木（JK、T 触发器都能由它改造而来）。

**Q2：锁存器既然"危险"，为什么还存在？**
它便宜、省晶体管，且某些场景正需要"使能期间透明跟随"（如 74HC573 总线锁存、FPGA 里作为高效资源）。危险在高速同步设计里难做时序分析——所以"老设备里有、新设计慎用"。

**Q3：RAM 和寄存器有什么区别？不都是存数吗？**
数电层面都是触发器阵列，区别在组织方式：寄存器是"一组并列、同一口令、直连功能单元"，读写快但贵；RAM 是"海量单元 + 地址译码器选通"（02 篇的 138 就是地址译码的思路），密度高但每次读写要多一步寻址。13 模块（计算机组成原理）会把这条对比展开成存储层次。

**Q4：t_su/t_h 具体是多少纳秒，去哪查？**
每颗芯片数据手册的"Timing Requirements / AC Characteristics"表里，按供电电压和温度范围给最小值。查法和读法见 04 篇"如何读数据手册"；本模块先掌握概念和读图，具体数值随用随查。

**Q5：异步复位脚不是异步的吗，和"同步设计"矛盾吗？**
不矛盾，反而互补：复位是让整个同步系统"回到起跑线"的异步入口（上电时触发器状态随机，必须强制归零），起跑之后内部一切照常同步。所以工程上有"异步复位、同步释放"的说法——细节到 STM32 阶段配合时钟与复位章节再体会。
