# 06 · 测量仪器与调试排障

> 硬件调试三件套：万用表（电压/通断）、示波器（波形）、逻辑分析仪（数字时序）。
> 本篇是"动手篇"，结论多、推导少，重点是**会用 + 会判断 + 不踩坑**。

---

## 1. 万用表（第一件买，天天用）

> **这是什么**：万用表是硬件界的"多功能体检仪"——一台机器测电压、电流、电阻、通断，几十元就能入门。
> **为什么需要它**：调试 90% 的疑问（"这儿到底有没有电？""这两点通不通？""这颗电阻是多大？"）都靠它回答，上电前查短路更是保命步骤。

### 各档位用途

| 档位 | 用途 | 注意 |
|------|------|------|
| DC 电压档 | 测 3.3V/5V 电源、引脚电平 | **并联**到被测两端；量程选大于预期 |
| AC 电压档 | 测市电 | 【安全警示：本阶段禁止测市电，操作需专业人员】 |
| 电流档 | 测整机/支路电流 | **串联**进电路（断开一根线串进去），内阻极小，**严禁并联直接量电源=短路** |
| 电阻档 | 量电阻值 | 必须断电、离线测量 |
| 通断档（蜂鸣） | 查短路/断路、走线连通 | 最常用档：嘀=通 |
| 二极管档 | 测二极管/LED/三极管 PN 结 | 显示压降（0.5~0.7V 正常） |
| 电容档 | 量电容容量 | 电容先放电再测 |

### 标准检查流程（板子不上电先做一遍）

```
1. 通断档：电源正负极之间 → 嘀 = 短路，禁止上电！（先找短路：坏电容/连锡/芯片击穿）
2. 目视：元件立正没立正、虚焊、连锡、极性（电解/LED/二极管方向）
3. 上电：电压档测各电源点（输入5V → 稳压输出3.3V → 芯片供电脚）
4. 电压异常 → 沿供电链逐级定位
```

### 经典判断口诀
- **电源对地短路 → 先摸发烫元件**（短路的大电流会先烧/烫坏的那颗就是元凶）；
- 电压一半/偏低 → 查负载短路或稳压芯片过流保护；
- 时好时坏 → 按压法找虚焊：按住怀疑焊点看现象是否变化。

## 2. 示波器（看波形 = 看"心电图"）

> **这是什么**：示波器把电压画成一条随时间变化的曲线——万用表只告诉你"现在平均多少伏"，示波器给你放"全程录像"。
> **为什么需要它**：PWM 对不对、纹波多大、按键抖不抖——这些问题万用表一律"看不见"，只有示波器能作答。

### 能看到什么
万用表只给"平均值"，示波器给出**随时间变化的全过程**——PWM 波形、串口数据、I2C 时序、电源纹波、按键抖动，一眼看穿。

### 基本操作（以常见入门机为框架，功能大同小异）

1. **探头**：×1 档带宽低，日常用 **×10**（探头拨到 10X，机器菜单同步设 10X；×10 时探头内阻高，对被测电路影响更小、可测频率也更宽）；
2. **垂直档位**（V/div）：每格代表电压，调到波形占屏 2/3；
3. **时基**（s/div）：每格代表时间，想看 PWM 一周期就调到周期占 2~4 格；
4. **触发**：让波形"站稳"的关键。日常选 Edge + 上升沿 + 触发电平设在信号幅度中间；
5. **Measure**：自动量 Vpp、频率、占空比、上升时间。

### 嵌入式必测四件事

| 测什么 | 现象/指标 |
|--------|-----------|
| PWM | 频率、占空比是否与代码一致 |
| 电源纹波 | 3.3V 轨纹波典型应 < 30~50mV；过大查去耦电容 |
| 按键电平 | 是否有毛刺/抖动（几十 ms 内多次跳变 → 软件消抖依据） |
| 串口 TX | 电平是否对、波特率视觉上是否稳定 |

### 测量禁忌
- 探头**地夹与市电地相通**：禁止把地夹夹到带电位不同的两点（浮地系统/市电设备）【安全警示】；
- 测大电容先放电；
- ×1 档测高频会失真，注意探头档位与菜单一致。

## 3. 逻辑分析仪（数字时序的"平价示波器"）

> **这是什么**：只看"0 还是 1"（不关心电压细节）的仪器，一次能看 8~16 根线，还能自动把 I2C/串口波形翻译成数据——几十元一件的调试神器。

- 只看 0/1 电平变化，不关心模拟细节；几十元的 8~16 通道 USB 逻辑分析仪 + 上位机（PulseView/DSView）即可；
- **强项：协议解码**——设置 I2C/UART/SPI 参数后直接把总线数据解码成十六进制/字符；
- 典型场景：I2C 传感器不回 ACK、串口乱码、SPI 时序对不对——逻辑分析仪一挂，是"没 ACK"还是"数据错"一目了然。

### 三件套分工

| 仪器 | 看什么 | 举例如 |
|------|--------|--------|
| 万用表 | 稳态电压/通断 | 3.3V 是不是 3.3V |
| 示波器 | 模拟波形质量 | 纹波多大、PWM 形状 |
| 逻辑分析仪 | 数字时序+协议内容 | I2C 发了什么字节、ACK 有没有 |

## 4. 硬件故障排查总流程（方法论）

> **这是什么**：一套"从安全到定位"的排障套路。硬件维修最容易犯的错是东改一下、西换一个——按流程走，每一步都有依据，效率天壤之别。

```
第0步 安全确认：低压实验板，确认无短路再上电【安全警示】
第1步 现象描述：什么不对？全坏还是局部坏？（能定位"哪一路"就成功一半）
第2步 分区定位：电源 → 时钟 → 复位 → 外设，由骨干到枝叶
第3步 测量验证：每个假设用一次测量证实/证伪（电压、波形、通断）
第4步 单变量原则：一次只改一个东西，改完记录
第5步 对照法：有好的板子/模块就换上对比（换件法）
```

**"时好时坏"三大元凶**：虚焊（按压/补焊）、悬空引脚（BOOT/栅极/复位没上下拉）、供电不稳（去耦缺失/线太长）。

**维修禁忌**：
- 不上电时用通断档确认过才可反复上电试；
- 不带电插拔模块（尤其串口/传感器）；
- 不反接电源"试试看"；
- 不用手指摸大电容脚/电源入口（先放电）；
- 排查记录要写：现象→假设→测量→结论，这是工程师作品集的一部分。

## 5. 章节小结

- 万用表：电压并联、电流串联、通断档查短路是上电前铁规矩
- 示波器：×10 探头 + 合理触发；测 PWM/纹波/抖动四大场景
- 逻辑分析仪：协议解码利器，I2C/串口调试效率翻倍
- 排障方法论：先安全 → 现象 → 分区 → 测量证伪 → 单变量 → 对照
- 时好时坏 = 虚焊/悬空/供电，先查这三个

## 课后思考题

1. 为什么电流档直接并联到电源两端会坏？（电流档内阻近似 0，并联=短路，超大电流烧表/烧电源）
2. 示波器触发不稳、波形左右跑，该调什么？（触发电平/边沿选择——电平放到信号幅度范围内，选对应上升/下降沿）
3. I2C 设备有时 ACK 有时不 ACK，先查哪三样？（上拉电阻是否存在/阻值过大、速度是否过高、地是否共地+线过长）
4. 万用表显示 3.3V 正常但系统偶发复位，说明什么局限？（万用表只给均值，毫秒级跌落看不到——需示波器捕捉掉电瞬间的波形）
