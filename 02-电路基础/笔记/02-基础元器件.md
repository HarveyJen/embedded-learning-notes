# 02 · 基础元器件：电阻 / 电容 / 电感

> 三大无源元件，每块板子上数量最多。重点掌握：**参数含义、在嵌入式电路中的典型用法、损坏特征**。

---

## 1. 电阻（Resistor）

> **这是什么**：电阻是"对电流设卡"的元件，单位欧姆（Ω，1kΩ=1000Ω，1MΩ=1000kΩ）。它是电路里用量最大、也最便宜的角色。
> **为什么需要它**：LED 直接接 3.3V 会瞬间烧毁，5V 信号直接进 3.3V 引脚会损坏芯片——没有电阻当"阀门"和"分压尺"，这些电路都活不过一秒。

### 作用
限流（LED）、分压（ADC）、上拉/下拉、匹配阻抗、取样。

### 关键参数

| 参数 | 含义 | 选型要点 |
|------|------|----------|
| 阻值 | 多大阻碍，单位 Ω/kΩ/MΩ | 按计算取常用值（E24 系列：1k、4.7k、10k...） |
| 功率 | 能承受多大发热，如 1/16W、1/8W、0.25W | 实际功率 ≤ 标称一半更可靠；P=I²R 校验 |
| 精度 | ±1%（贴片常见）、±5%（色环） | 一般电路 ±1% 足够；取样/分压要准的用 ±0.1% |
| 封装 | 0603、0805、1206（尺寸英寸×10） | 新手手焊选 0805；1206 更好焊 |
| 温漂 | 温度变化阻值漂移 | 一般不关注，精密取样才看 |

**单位换算与功率算例**（把表格里的说法落到手上）：
- 阻值换算：1kΩ = 1000Ω，1MΩ = 1000kΩ = 100万Ω；"10k"就是 10000Ω；
- 功率校验怎么算：一支 220Ω 电阻流过 15mA 电流，发热 P = I² × R = (0.015 × 0.015) × 220 ≈ 0.05W。0603 封装标称 1/16W（≈0.06W），裕量太薄；换 0805（1/8W = 0.125W）就从容——这就是"实际功率 ≤ 标称一半更可靠"的用法；
- 封装与尺寸：0603 意思是长 0.06 英寸、宽 0.03 英寸（英寸代码 ×100），数字越大元件越大越好焊，新手手焊选 0805 就是这个道理。

### 色环读法（直插电阻）
四环：前两环数字 + 第三环倍率 + 第四环误差。
例：棕黑红金 = 1 0 ×10² = 1kΩ ±5%。
口诀：**棕1 红2 橙3 黄4 绿5 蓝6 紫7 灰8 白9 黑0**。

一步步读一遍"黄紫橙金"：
- 第一步：查口诀，黄=4、紫=7，前两位是"47"；
- 第二步：第三环橙=3，表示倍率 10³（后面添 3 个零）；
- 第三步：47 × 1000 = 47000Ω = 47kΩ；第四环金=±5% 误差。
技巧：误差环（通常金色）离其他环远一些，从它那一端"倒着读"就不会读反。

### 特殊电阻
- **0Ω 电阻**：不是真为零（约几 mΩ）。用途：①跳线/断开调试点；②单点连接数字地与模拟地；③过流保护（大电流时熔断）；
- **热敏电阻 NTC**：温度越高阻值越小 → 测温、限制上电浪涌电流；
- **光敏电阻**：见光阻值变小 → 光控灯；
- **电位器**：可调电阻 → 音量旋钮、ADC 实验常用。

### 典型应用电路
1. LED 限流（见笔记01 例题）
2. 分压采样：电池电压经分压进 ADC
3. 上拉/下拉：按键、I2C、复位引脚
4. RC 滤波（与电容配合，见下文）

### 损坏特征
- **烧毁**：表面发黑、开裂、中间烧断 → 通常是过功率或后级短路；
- **阻值漂移**：老化后变大，表现为电流变小、分压点电压异常；
- 万用表判断：电阻档直接量，偏差超过标称 ±5% 基本算坏（需离线量，在线受并联支路影响）。

## 2. 电容（Capacitor）——嵌入式电路的"稳定器"

> **这是什么**：电容是"储存电荷的小水库"，单位法拉（F）——这个单位太大，实际用的都是它的零头：**1μF（微法）= 1000nF（纳法）= 100万pF（皮法）**。写在元件上的"104"就是 10 × 10⁴ pF = 0.1μF。
> **为什么需要它**：电源不是完美水源，芯片抽电流一阵一阵，电压会抖——电容守在芯片旁边，波动来了"放水"、空闲时"蓄水"，把电压抹平。

### 作用（按频率从小到大理解）
储能（大水塘）、滤波、去耦（给芯片"就近供水"）、耦合（隔直通交）、定时（RC）。

**核心特性：电容"隔直流、通交流"，且两端电压不能突变。**
类比：水库——上游来水（电流）波动，下游水位（电压）平缓；突然想抽干水库不行，水位只能慢慢变。

### 主要类型对比（选型核心）

| 类型 | 容量范围 | 特点 | 典型用途 |
|------|----------|------|----------|
| 陶瓷电容（MLCC） | pF ~ 几十μF | 无极性、体积小、高频好、便宜 | **去耦、滤波主力** |
| 电解电容 | 1μF ~ 几千μF | **有极性！**反接会爆、容量大、高频差、寿命短（怕热） | 电源输入/输出大水塘 |
| 钽电容 | 1μF ~ 几百μF | 容量稳定、体积小、**反接/过压易起火**、贵 | 精密供电 |
| 固态电容 | 10μF ~ 千μF | 电解升级版，长寿命 | 高可靠电源 |

### 关键参数

| 参数 | 含义 | 选型要点 |
|------|------|----------|
| 容量 | 储电荷能力，μF/nF/pF | 去耦常见 0.1μF+10μF 组合 |
| 耐压 | 能承受的最高电压 | **必须留 50% 裕量**：5V 电路选 ≥10V |
| ESR | 等效串联电阻（Equivalent Series Resistance——电容内部自带的"隐形小电阻"） | 越小高频滤波越好；LDO 输出电容对 ESR 有要求 |
| 温度/寿命 | 电解电容怕高温 | 耐温 105℃ 优于 85℃ |

### 去耦电容（嵌入式必懂第一名）

**问题**：芯片内部瞬间翻转需要大电流，电源远水解不了近渴，引脚电压会被拉出尖坑 → 芯片工作异常。

**解决**：在**每个电源引脚旁边**放 0.1μF（104）陶瓷电容，就近提供瞬间电流，并把高频噪声泄放到地。

```
3.3V ──┬──┬─────────
       │  │
    [0.1μF][10μF]     0.1μF 就近高频去耦；10μF 补充中等能量
       │  │
      GND GND    （且 0.1μF 必须紧贴芯片电源引脚，走线越短越好）
```

通电后发生了什么（一步步演一遍）：
- 第一步：上电，0.1μF 和 10μF 都很快充到 3.3V，进入"待命蓄水"状态；
- 第二步：芯片内部某一瞬间翻转，几十纳秒（ns，十亿分之一秒）内猛抽一大口电流——远处的电源来不及响应，芯片电源脚电压眼看要被拉出一个"坑"；
- 第三步：紧贴的 0.1μF 立刻就地放电补上这一口（它离芯片只有几毫米，反应最快），电压坑被抹平；
- 第四步：抽走的电荷随后由 10μF 和远处电源慢慢补回来，等待下一波。
- 结果：芯片电源脚上的电压始终平稳，芯片不闹脾气。

口诀：**一个电源脚一颗 0.1μF，整板再加几颗 10μF 大电容**。画 PCB 时这条是硬规矩。

### 典型应用
1. 去耦（上面）；
2. 电源储能：适配器入口 470μF 电解；
3. RC 延时/滤波：复位电路（笔记05）；
4. 按键消抖（硬件消抖，0.1μF 并在按键上）。

### 损坏特征
- **电解电容鼓包/漏液**：电源纹波变大、设备重启、使用年限到了（顶部凸起肉眼可见）——维修更换头号对象；
- **陶瓷电容开裂/短路**：受弯折或过压，表现为电源对地短路、发烫；
- 容量衰减：滤波变差、纹波大。

## 3. 电感（Inductor）

> **这是什么**：电感是一圈圈绕起来的线圈——"电流流过产生磁场，磁场变化又反过来反抗电流变化"，单位亨利（H），常用换算 1H = 1000mH，1mH = 1000μH，板子上常见 μH（微亨）级。
> **为什么需要它**：电容管"电压别突变"，电感管"电流别突变"——DC-DC 开关电源里，能量就是存进它的磁场再放出来的，没有它就没有高效降压（笔记04 见分晓）。

### 作用
**储能（磁场）、通直流阻交流**——与电容正相反。
类比：飞轮，电流想突变时它靠惯性顶住，电流越平它越舒服。

### 关键参数

| 参数 | 含义 | 选型要点 |
|------|------|----------|
| 电感量 | μH/mH | DC-DC 按手册公式选，典型 2.2~22μH |
| 饱和电流 | 磁芯饱和后感值骤降 | **必须大于电路峰值电流**，留 30% 裕量 |
| DCR | 直流电阻 | 越小发热越少、效率越高 |
| 屏蔽 | 屏蔽/非屏蔽 | 数字板选屏蔽型防干扰 |

### 典型应用
1. **DC-DC 开关电源**（笔记04 主角）：电感是储能核心；
2. π 型滤波：C-L-C 滤掉电源纹波；
3. 磁珠：特殊"高频电阻"，串在电源线上吸收噪声（注意磁珠本质是阻抗，不是纯电感）。

### 损坏特征
- 过流烧毁：漆包线发黑、断路 → DC-DC 无输出；
- 磁芯松动异响（工作频率啸叫通常是负载轻/环路不稳，不一定是电感坏）；
- 电感本身很皮实，坏了通常伴随后级短路（先查后级再换电感）。

## 4. R、C、L 一图对照（背下来）

> **这是什么**：把三大元件的性格放一张表里对比——它们对直流、交流、突变信号的"脾气"正好互补。记住这张表，后面看滤波、去耦、储能电路就有了"元素周期表"。

| | 电阻 R | 电容 C | 电感 L |
|---|--------|--------|--------|
| 单位 | Ω | F（μF/nF/pF） | H（μH/nH） |
| 阻抗特性 | 恒定 | **通高频阻低频**（隔直通交） | **通低频阻高频**（通直阻交） |
| 瞬变特性 | 无惯性 | 电压不能突变 | 电流不能突变 |
| 储能 | 不储能（发热） | 储电场能 | 储磁场能 |
| 串并联 | 串加并积 | 串"积"并加 | 同电阻（串加并积） |
| 嵌入式用途 | 限流/分压/上下拉 | 去耦/储能/滤波 | DC-DC/滤波/磁珠 |

> 直流稳态下：电容 = 断路（充满后没电流），电感 = 导线（无变化无感抗）。分析静态电路时直接替换，简化思考。
>
> 表里"串'积'并加"补一句白话：电容的串并联算法与电阻正好相反——串联总容量按"积除以和"算（同电阻并联公式），并联则直接相加，所以两只相同电容并联容量翻倍、串联减半。

## 5. 章节小结

- 电阻：算功率防烧；0Ω 是跳线；色环口诀要会
- 电容：**去耦 0.1μF 紧贴芯片**是铁律；电解有极性、怕热会鼓包；耐压留半
- 电感：DC-DC 储能核心；选型看饱和电流；直流稳态当导线
- 电容通高频、电感通低频——滤波电路的哲学基础

## 课后思考题

1. 为什么去耦电容必须"就近"芯片电源引脚？（走线有电感，距离越长高频阻抗越大，瞬间供流能力越差）
2. 5V 电路用耐压 6.3V 的电解电容行不行？（能工作但不合规范，纹波+老化易超压，应选 ≥10V）
3. DC 稳态下电容为什么没电流？（充满电后两端电压恒定，dV/dt=0，I=C·dV/dt=0）
4. 板上 3.3V 对地短路且发烫，怀疑哪几类元件优先排查？（陶瓷电容短路、TVS/二极管击穿、芯片烧毁）
