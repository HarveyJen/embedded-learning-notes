# 04 · 电源与稳压电路

> 板子的"心脏"。目标：看懂开发板的供电链路，会选 LDO 和 DC-DC，知道去耦/防反接怎么加。

---

## 1. 嵌入式板子的典型供电链

> **这是什么**：一块板子从插上电源到 MCU 拿到干净的 3.3V，中间要经过一道"供电流水线"。先看懂这条链，后面每一节其实都在讲链上的某一环。
> **为什么需要它**：MCU 对电压要求苛刻（3.3V 上下晃一点就死机或复位），电源上的波动、接反、浪涌还会直接烧板——供电链就是板子的"消化系统"。

```
适配器/USB 5V ──> 防反接/保险 ──> DC-DC或LDO ──> 3.3V ──> MCU/传感器
                                       └──> 1.8V（部分内核/Flash）
电池 3.7~4.2V ──────────────┘
```

设计思想：**一级降压一级稳压，大电压差用 DC-DC，小电压差用 LDO**。

## 2. LDO（线性稳压器）

> **这是什么**：LDO（Low Dropout，低压差线性稳压器）是一只"自动调节的智能电阻"，串在输入和输出之间——不管输入怎么晃，它都把输出顶在设定值不变。
> **为什么需要它**：电池电压会从 4.2V 慢慢掉到 3.5V，USB 电源带纹波——但 MCU 需要"纹丝不动"的 3.3V，中间就必须有稳压器。

### 原理（一句话）
内部可调"智能电阻"串在输入输出之间，通过调节自身压降把输出顶在设定值——本质是**用发热换稳定**。

类比：水塔水位过高时，用一个可调节流阀把多余的压力"磨掉"，多余能量全部变成热。

### 关键参数

| 参数 | 含义 | 选型要点 |
|------|------|----------|
| 输入输出压差 | 稳定工作需要的最小差值 | 压差不够 → 输出跟着输入掉（跌出稳压区） |
| 静态电流 Iq | 芯片自身耗电 | 低功耗设备选 μA 级 |
| 最大输出电流 | 能带多大负载 | 常见 0.5A / 1A / 3A |
| 输出精度/纹波 | ±1~2%，纹波极小 | 给 ADC/射频供电选 LDO 正是图它干净 |

### 经典型号：AMS1117-3.3（贴片三脚 SOT-223）

```
5V ──┬────────── IN    OUT ──────┬── 3.3V
   [10μF电解]  GND(贴散热焊盘)   [22μF钽/10μF陶瓷]   （三脚：IN/GND/OUT）
      │                          │
     GND ───────────────────────┴── GND
```
- 压差 = 5−3.3 = 1.7V；带 300mA 负载时发热 P = 1.7V × 0.3A ≈ 0.5W——**这是它最大的代价**。一步步算：压差 = 输入 5V − 输出 3.3V = 1.7V（这 1.7V 全由 LDO 内部"磨掉"）；发热功率 = 压差 × 负载电流 = 1.7V × 0.3A = 0.51W——相当于一只小电烙铁贴在板上，芯片和 PCB 都会明显发烫；
- 3.7V 锂电 → 3.3V 压差仅 0.4V，发热 P = 0.4V × 0.3A = 0.12W，用低压差 LDO（如 ME6211）就很合适。

### 损坏特征
- 无输出：芯片坏或输入保险断；输出电压低/发烫：负载短路（先断开负载测空载电压再定位）；
- 大面积发烫但输出正常：可能是**负载电流超过规格**或压差太大——查负载，不是换芯片。

## 3. DC-DC（开关电源）

> **这是什么**：DC-DC 是"高频搬运工"——内部 MOS 管每秒开关几十万次，把能量一小份一小份"打包"经电感运给输出，需要多少运多少。
> **为什么需要它**：LDO 降压全靠发热（压差大就是灾难），DC-DC 靠搬运（效率 85~95%，几乎不发热）——12V 转 3.3V、大电流供电这些 LDO 干不了的活，都是它的主场。

### 原理（一句话）
用 MOS 管高频开关（几十万~几百万次/秒）+ 电感储能，"按需搬运"能量——**效率高（85~95%），几乎不发热**。

类比：不是把多余的水磨掉，而是用一个高速阀门+水桶，精准把需要的水量搬到下游，不浪费。

### 两大类

| 类型 | 结构 | 典型芯片 | 用途 |
|------|------|----------|------|
| BUCK（降压） | MOS+电感+续流二极管+输出电容 | TPS54331、MP1584、SY8088 | 5V→3.3V、12V→5V |
| BOOST（升压） | 同样四件套重新排布 | MT3608、SY1308 | 3.7V→5V |

BUCK 降压一圈怎么转（通电后一步步演）：
- 第一步：MOS 管导通，5V 直接加到电感一端，电感电流慢慢爬升，同时给输出电容充电、给负载供电；
- 第二步：输出电压被反馈脚（FB，芯片的"监督眼"，经两只电阻分压盯着输出）实时监视，一旦达到 3.3V，控制电路把 MOS 关断；
- 第三步：MOS 关断后电感"不服"——电流不能突变，它经续流二极管继续向输出放电，把存的能量倾泻出去；
- 第四步：输出电压略掉一点，FB 又让 MOS 打开……如此每秒重复几十万次，输出就被"抹"成平稳的 3.3V。

### 选型对照

| 场景 | 选 LDO | 选 DC-DC |
|------|--------|----------|
| 压差小（<1V）、电流小 | √（简单便宜纹波小） | 杀鸡用牛刀 |
| 压差大（如 12→3.3V）、电流大 | ×（发热灾难） | √ |
| 给 ADC/射频/时钟供电 | √（纹波小） | 需再加 LDO 二级滤波 |
| 成本敏感小电流 | √ | — |

口诀：**大压差大电流用 DC-DC，小压差怕纹波用 LDO；讲究的板子"DC-DC 粗稳 + LDO 精稳"两级串联。**

### 损坏特征
- 无输出/输出跳：FB 反馈电阻虚焊、电感饱和/虚焊、输出电容失效；
- 啸叫：轻载进入跳周期（多属正常）或环路不稳（换大容/查布线）；
- 纹波大：输出电容容量衰减（电解鼓包）。

## 4. 电源必备辅助电路（设计规范）

> **这是什么**：光有稳压芯片还不够，一块靠谱的电源还要配齐"五个保镖"：去耦、防反接、保险丝、TVS、指示灯。缺一个平时看不出问题，出事时全是事故。

### ① 去耦（回顾笔记02）
每个芯片电源脚 0.1μF 陶瓷 + 板上若干 10μF。

### ② 防反接（笔记03）
二极管（简单/有压降）或 PMOS（低损耗）。

### ③ 保险丝
自恢复保险丝（PPTC）串在电源入口，短路后自动断、冷却恢复。

### ④ TVS 防浪涌
TVS 管（Transient Voltage Suppressor，瞬态电压抑制二极管——平时"装死"不通，电压超限的纳秒级瞬间变成短路泄洪道）并在电源入口对地，雷击/插拔浪涌瞬间钳位。

### ⑤ 电源指示 LED
电源+2kΩ+LED 到地，看板子有没有电。

标准入口电路：
```
5V_IN ──[PPTC保险]──[肖特基防反接]──┬──[TVS到地]──┬──> 后级
                                  [470μF电解]  [0.1μF]
```

## 5. 电平转换与供电兼容（3.3V vs 5V 共存）

> **这是什么**：一块系统里经常 5V 老设备和新 3.3V 芯片混用，谁也咽不下对方的"满格电平"——这一节讲怎么让两个电压域安全对话。

- STM32 多数引脚**FT（5V tolerant，5V 容忍——引脚内部做了耐 5V 的特殊设计，datasheet 的 I/O 表里标 "FT" 字样）**可直连 5V 信号；非 FT 引脚会损坏；
- 通用方案：分压电阻（单向信号）、电平转换芯片（TXS0108E，双向）、MOS 双管电路（I2C 经典）；
- 5V 传感器接 3.3V ADC：分压到 ≤3.3V。

## 6. 章节小结

- 供电链：入口保护（保险+防反接+TVS）→ 稳压（DC-DC/LDO）→ 去耦
- LDO = 磨掉压差，简单纹波小但发热 = 压差×电流
- DC-DC = 高频搬运能量，效率高但纹波大
- AMS1117-3.3 是 5V→3.3V 最常见选择，注意算发热
- 去耦电容铁律不变：0.1μF 贴芯片脚

## 课后思考题

1. 12V 转 3.3V、500mA 用 LDO 会怎样？（P=(12-3.3)×0.5≈4.4W，需巨大散热片，基本不可行，应选 DC-DC）
2. 为什么 ADC 参考电源最好用 LDO 而不是 DC-DC？（DC-DC 纹波在 mV~几十mV 级，直接变成 ADC 采集噪声）
3. AMS1117 输出只有 2.1V，输入 5V 正常，最可能什么问题？（负载短路/过流拉垮输出，或输出电容失效——先断负载验证）
