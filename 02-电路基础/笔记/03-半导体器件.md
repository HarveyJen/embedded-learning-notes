# 03 · 半导体器件：二极管 / 三极管 / MOS管

> 嵌入式驱动电路的三大主角：MCU 引脚电流弱（几 mA~几十 mA），驱动蜂鸣器、继电器、电机、大功率 LED 都要它们"放大"。

---

## 1. 二极管（Diode）

> **这是什么**：二极管是电路里的"单向阀"——电流只能朝一个方向过，反着来就堵死。两个脚叫正极（A，Anode 阳极）和负极（K，Cathode 阴极），原理图上三角箭头指向就是导通方向。
> **为什么需要它**：电源插反要烧板（防反接）、继电器断电瞬间打高压（续流）、静电打坏接口（TVS 保护）——这些"保卫工作"全靠二极管家族。

### 原理（PN 结，一句话版）
P 型半导体 + N 型半导体交界形成 PN 结：**只允许电流从 P→N（正极→负极）单向通过**。
类比：单行道/单向阀——正向推（正向偏置）畅通，反向推（反向偏置）截止。

### 关键参数

| 参数 | 典型值 | 含义 |
|------|--------|------|
| 正向压降 Vf | 硅管 ~0.7V；肖特基 ~0.3V；LED 1.8~3.2V | 导通后两端固定压降（串联分压必算） |
| 最大正向电流 If | 按型号 | 超过烧管 |
| 反向耐压 Vr | 按型号 | 反向电压超过 → 击穿 |
| 反向恢复时间 | 肖特基最快 | 高频整流/续流选肖特基 |

> "反向恢复时间"白话版：二极管从导通切换回截止不是瞬间完成，要先清掉体内存的电荷——高频场合切换太慢就会"跟不上趟"，所以续流/高频整流优先选肖特基。

### 家族成员与用途

| 类型 | 符号/特点 | 典型应用 |
|------|-----------|----------|
| 普通整流管 1N4007 | 1A/1000V，慢 | 电源整流、防反接 |
| 开关管 1N4148 | 快速、小电流 | 信号处理、续流（小电流） |
| 肖特基 SS34/1N5822 | 压降低 0.3V、快 | DC-DC 续流、防反接（低损耗） |
| 稳压二极管 | 反向击穿区稳压 | 简易基准电压（嵌入式少用，用基准芯片） |
| TVS 管 | 反向雪崩纳秒级泄放 | 串口/USB 接口静电浪涌保护 |
| 发光二极管 LED | 压降 1.8~3.2V，串限流电阻 | 指示灯 |
| 光耦 | LED+光敏管隔离 | 隔离通信/隔离驱动 |

### 防反接电路（实用必备）

```
电源+ ──[二极管 正向]──┬──> 电路电源
正常：压降 0.3~0.7V，电流通过
反接：二极管截止 → 电路不通，保住芯片
```

通电后发生了什么（分两种情况演一遍）：
- 正常接入：第一步，电流从正极流向负极（顺箭头方向），单向阀打开；第二步，二极管"收过路费"0.3~0.7V，后级拿到的是电源电压减这一点（5V − 0.3V ≈ 4.7V），设备正常工作；
- 电源反接：第一步，电流试图反向流动；第二步，单向阀堵死，回路里几乎没有电流；第三步，后级芯片完全感受不到反接，安然无恙——代价只是这一路不通。

算个账：负载 100mA 时，肖特基（0.3V）发热 P = 0.3V × 0.1A = 30mW，普通硅管（0.7V）发热 70mW——都能工作，但压降越低浪费越少，这就是"压降敏感选肖特基"的原因。

对压降敏感的场景用 **PMOS 防反接**（压降仅几十 mV，笔记04 介绍）。

### 损坏特征与测量
- 万用表**二极管档**：红黑表笔接正负 → 显示 0.5~0.7V（硅管）为好管；反向不通（显示 OL）；
- 正反向都通=击穿；都不通=开路烧断；
- LED 同法测量时**会微微发光**——顺便判断极性（会亮时红表笔端是正极）。

## 2. 三极管（BJT）——电流放大/电子开关

> **这是什么**：三极管是"用电控的阀门"——用小电流（基极）控制大电流（集电极→发射极），所以既能当放大器、又能当电子开关。三个脚必须记熟：基极 b（base，控制端）、集电极 c（collector，接负载侧）、发射极 e（emitter，公共端）。
> **为什么需要它**：MCU 引脚只能输出几 mA~几十 mA，而蜂鸣器要 30mA、继电器要 70mA、电机要几百 mA——引脚"推不动"，就得请三极管当"中间人"。

### 结构与三种工作区
NPN 和 PNP 两种，三个脚：**基极 b（控制端）、集电极 c、发射极 e**。

类比：水龙头。基极是**手柄**（小力气拧动），集电/发射极是**水管**（大水流）。小电流 Ib 控制大电流 Ic，Ic = β × Ib（β 几十~几百）。

| 工作区 | 条件（NPN） | 表现 | 嵌入式用途 |
|--------|-------------|------|-----------|
| 截止区 | Vbe < 0.7V | c-e 不通 | 开关"关" |
| 放大区 | Vbe≈0.7V 且 Vce>0.3V | Ic=β·Ib | 模拟放大（嵌入式少见） |
| 饱和区 | Ib 足够大 | c-e 近似直通（压降~0.3V） | 开关"开" |

**做开关就记住：要么截止，要么饱和，不停留在放大区。**

### 经典电路：MCU 驱动蜂鸣器/继电器（必会）

```
3.3V ────[蜂鸣器/继电器]────┐
                            │c
MCU 引脚 ──[1kΩ]──b[NPN 8050]
                            │e
                           GND
（续流二极管反并在感性负载两端：负极接电源，正向导通方向与电流相反）
```

工作过程（通电后一步步演）：
1. MCU 输出高 3.3V → 经 1kΩ 给基极电流。一步步算：基极与发射极之间像一个二极管，导通后固定吃掉 0.7V，所以电阻两端电压 = 3.3V − 0.7V = 2.6V；基极电流 Ib = 2.6V ÷ 1000Ω = 2.6mA；
2. 三极管的放大倍数 β（也叫 hFE，datasheet 可查，典型几十~几百）设为 100 → 集电极最多可通过 Ic = β × Ib = 100 × 2.6mA = 260mA。蜂鸣器只需 30mA，管子"大力士干小活"，轻松进入饱和导通（c-e 之间压降仅 ~0.3V，近似直通）→ 蜂鸣器得电响；
3. MCU 输出低 0V → 基极没电流（Ib=0）→ 管子截止（c-e 断开）→ 蜂鸣器停电停。

**继电器必须并续流二极管**：线圈断电瞬间产生反向高压尖峰（电感电流不能突变），二极管给它泄放回路，保护三极管和 MCU。漏了它 → 管子莫名其妙损坏。

- NPN：负载放**上面**（接电源），管子通地 → 高电平导通，最常用；
- PNP：负载放下（接地），管子通电源 → **低电平**导通（发射极接电源）。

### 损坏特征
- c-e 击穿短路：负载一直工作不受控；
- b-e 开路：负载永不工作；
- 万用表判断：二极管档测 b-e、b-c 各有 0.6~0.7V（像两个二极管），c-e 间不通。

## 3. MOS管（场效应管）——电压控制，嵌入式首选开关

> **这是什么**：MOS 管是"用电压控制的开关"——栅极像感应水龙头的传感器，给个电压就开关，几乎不吃电流。三个脚：栅极 G（gate，控制端）、漏极 D（drain）、源极 S（source）。
> **为什么需要它**：控制端不吃电流 → MCU 驱动它毫不费力；导通电阻只有毫欧（mΩ，千分之一欧）级 → 大电流下发热极小。电机、LED 灯条、电源开关，嵌入式的大功率场合基本归它管。

### 特点（vs 三极管）

| | 三极管 BJT | MOS管 |
|---|-----------|-------|
| 控制量 | 电流 Ib | **电压 Vgs**（栅极几乎不吃电流） |
| 驱动功耗 | 大（持续给基极电流） | 小（静态无栅流） |
| 压降 | 饱和 ~0.3V | 导通电阻 mΩ 级，压降极低 |
| 大电流 | 一般 | 强（低压大电流首选） |
| 灵敏度 | 皮实 | **栅极怕静电**，怕过压 |

类比：三极管是"不断用力拧的水龙头"（持续耗手劲），MOS 是"按压式感应水龙头"（一下电压信号就能保持开/关）。

### NMOS / PMOS

- **NMOS**：Vgs > Vth 导通（Vgs = 栅极 G 与源极 S 之间的电压；Vth = 阈值电压，"开门的最低电压"，datasheet 可查，低压 MOS 常见 1~2V）→ 源极接 GND，负载在上 → 高电平开通（和 NPN 用法类似）；
- **PMOS**：Vgs < 负阈值导通（栅极要比源极低出足够电压才开）→ 源极接电源，负载在下 → 低电平开通。

常用低压 MOS：AO3400（N，~5A）、AO3401（P）、SI2302、IRLR7843（大电流）。

### 典型应用

```
1. MCU 驱动大电流负载（电机、LED灯条）：
   MCU ──[100Ω]──G(NMOS AO3400)，S 接 GND，D 接负载下端
   栅极电阻：限制瞬间充电电流 + 防振荡
   栅源并 10kΩ 下拉：MCU 复位悬空时保证 MOS 关断！

2. PMOS 防反接 / 电源开关：
   电源+ ──S(PMOS)D── 电路电源，栅极经电阻拉到 GND 常开，MCU 拉高关断
```

**两个必记细节**：
1. 栅极**必须**加下拉/上拉电阻定死电平——MOS 栅极阻抗极高，悬空会被静电/干扰"感应"出电压而误导通；
2. 驱动感性负载（电机）仍要续流二极管（很多 MOS 管内置体二极管，但大电流续流常外加肖特基）。

### 损坏特征
- 栅极击穿（静电/过压）：不再受控或完全不开；
- D-S 击穿短路：负载常通、管子发烫；
- 好坏粗测：万用表二极管档 D-S 间应有体二极管单向导通特性（N管：红笔D黑笔S不通，反接有0.5V左右读数）。

## 4. 光耦（隔离，安全第一道墙）

> **这是什么**：光耦 = 把一颗 LED 和一颗光敏三极管封装进同一个不透光的小黑盒——左边点亮 LED，右边"看到光"就导通。信号靠**光**传过去，两边的导线完全不接触。
> **为什么需要它**：工业现场 12V/24V 信号、强电设备、干扰很大的地线，直接连进 MCU 板轻则干扰、重则烧板。光耦让"危险世界"和"单片机世界"隔着一层光说话。

**结构**：LED + 光敏三极管封在一起，靠光传信号——**电气上完全隔离**。

```
MCU侧  ──[电阻]──LED─┐        ┌─光敏管─┐
                     └(发光)──┘        ├──> 被控侧电路
             MCU_GND              被控侧_GND
```

用途：串口隔离（工业 RS485/232）、强弱电隔离（继电器驱动板）、电平转换。
关键参数：CTR 电流传输比、隔离耐压（如 3.75kV）。
嵌入式场景：驱动板与主控板共地有干扰时，光耦把"两边地"分开，噪声传不过去。

## 5. 选型速查：我要驱动 XX 用什么？

> **这是什么**：一张"对症下药"的对照表——遇到实际驱动需求直接来查行。表里的方案都是前文讲过的经典组合，查到后回对应章节复习细节。

| 负载 | 推荐方案 |
|------|----------|
| 单个 LED（≤20mA） | 直接 GPIO + 限流电阻 |
| 蜂鸣器（有源，≤30mA） | NPN 8050 + 1k 基极电阻（或大电流 GPIO 直驱，看手册） |
| 继电器（线圈 50~100mA） | NPN/NMOS + **续流二极管** + 基极电阻 |
| 直流电机/灯条（>500mA） | NMOS（AO3400 及以上）+ 续流肖特基 + 栅极下拉 |
| 12V/24V 工业信号 | 光耦隔离输入 |
| 强电通断 | 继电器模块（成品，勿自搭）【安全警示：市电侧严禁自行接线测量】 |

## 6. 章节小结

- 二极管单向导通：限压降防反接；LED=会发光的二极管；TVS 抗静电
- 三极管 = 电流控电流的水龙头，开关用法只认截止/饱和；驱动继电器**必配续流二极管**
- MOS = 电压控开关，栅极下拉电阻防悬空误导通；大电流选 MOS
- 光耦 = 光隔离，抗干扰/强弱电隔离
- 驱动电路三板斧：**基极/栅极电阻 + 下拉定电平 + 感性负载续流**

## 课后思考题

1. 为什么驱动继电器的续流二极管方向不能接反？（接反=电源经二极管直通线圈短路，管子和二极管都烧）
2. 三极管饱和导通时 c-e 压降多少？为什么说做开关要"深饱和"？（~0.3V；深饱和保证压降最小、发热最少、状态确定）
3. MOS 栅极悬空会有什么后果？（感应电压导致半开半关、发烫失控，甚至静电击穿）
4. PNP 三极管驱动负载，MCU 输出高电平为什么关不掉？（发射极接 3.3V，基极 3.3V 时 Vbe=0 不截止需要拉到接近电源电压；高电平恰好不能产生偏置差——所以 PNP 用低电平开通，且要保证"关"时基极电压≈发射极电压）
