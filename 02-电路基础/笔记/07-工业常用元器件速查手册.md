# 07 · 工业常用元器件速查手册

> 收录嵌入式开发/工业生产中**真正高频出现**的元器件型号。表中参数均为**典型值**，设计前务必以原厂 datasheet 为准（查参数渠道见文末）。
> 同一规格国内外替代型号极多，本表只列"行业里最常见的代表型号"。

---

## 1. 电源管理类

### 1.1 LDO（线性稳压）

> 这表是什么：常用线性稳压芯片的"点名册"。什么时候翻：给板子选一颗"简单、便宜、纹波小"的稳压芯片时先来对号。

| 型号 | 输出 | 特点 | 典型应用 |
|------|------|------|----------|
| AMS1117-3.3 / 1.8 / 5.0 | 固定，1A 级 | 最经典的 5V→3.3V；SOT-223 封装好焊 | 几乎所有 STM32 小板 |
| LM1117 | 同上 | AMS1117 同类，TI 版 | 同上 |
| ME6211 | 3.3V，500mA 级 | 低压差，锂电池 3.7V→3.3V | 锂电设备 |
| HT7333 | 3.3V，小电流 | 超低静态电流（μA 级），电池产品 | 电池供电传感节点 |
| LP5907 / TPS7A 系列 | 各档 | 低噪声高 PSRR（电源抑制比——"把输入端纹波衰减掉"的本事，越高输出越干净），给 ADC/射频供电 | 精密采样、射频模块 |

### 1.2 DC-DC（开关电源）

> 这表是什么：开关电源芯片清单。什么时候翻：压差大、电流大，LDO 会烫得没法用、需要"高效搬运"方案时查这表。

| 型号 | 规格（典型） | 特点 | 典型应用 |
|------|--------------|------|----------|
| MP1584EN | 降压 3A，输入至 28V | 便宜量大，小板载板通用 | 12V→3.3V/5V |
| TPS54331 | 降压 3A，输入至 28V | TI 大厂，可靠性高 | 工控板 |
| LM2596 | 降压 3A，输入至 40V | 直插经典，模块化成品多 | 教学/快速验证 |
| SY8088 | 小封装降压，SOT-23-5 | 体积极小 | 空间紧张的小板 |
| MT3608 | 升压，峰值 2A 级 | 锂电升 5V 常见 | 电池升压 |
| TP4056 | 线性充电 1A（可设） | 锂电充电标配（注意散热量） | 充电模块/手持设备 |
| IP5306 | 充电宝级 SoC（System on Chip 系统级芯片——一颗芯片把充电、升压、电量显示全包了） | 充电+5V升压一体 | 便携设备 |

## 2. 逻辑与驱动类

### 2.1 74 系列（CMOS 逻辑，选 HC/HCT 系）

> 这表是什么：74 系列 = "标准小逻辑零件"超市，每个型号做一件固定的小事（扩 IO、缓冲、译码）。什么时候翻：MCU 引脚不够用、需要信号整形/隔离时来查。

| 型号 | 功能 | 典型用途 |
|------|------|----------|
| 74HC595 | 串入并出 | IO 不够用，驱动数码管/LED |
| 74HC165 | 并入串出 | 扩展按键输入 |
| 74HC245 | 8 位总线缓冲 | 驱动力增强、电平隔离 |
| 74HC573 | 8 位锁存 | 总线复用（51 外扩经典） |
| 74HC138 | 3-8 译码 | 片选扩展 |
| 74HC14 | 六施密特反相 | 按键/波形整形 |

### 2.2 驱动器件

> 这表是什么：从三极管到电机驱动芯片的"力气工具箱"。什么时候翻：负载电流超过 MCU 引脚能力（>20mA）需要找"帮手"时查这表。

| 型号 | 类型 | 规格要点（典型） | 典型用途 |
|------|------|------------------|----------|
| S8050 / S8550 | NPN / PNP 三极管 | 500mA 级 | 蜂鸣器/继电器/LED 驱动 |
| MMBT3904 / 3906 | 贴片三极管 | 小信号 | 通用开关 |
| 2N7002 | 小功率 NMOS | 60V 小电流 | 电平转换/小开关 |
| AO3400 / AO3401 | NMOS / PMOS | 30V，5A 级 | 电机/灯条/电源开关 |
| IRLZ44N / IRF540 | 大电流 MOS | 逻辑栅/标准栅，TO-220 | 直流大负载 |
| ULN2003 | 7 路达林顿阵列（达林顿 = 两只三极管叠起来放大，放大倍数极高） | 每路 ~500mA，内置续流二极管 | 继电器组、28BYJ-48 步进电机 |
| L298N | 双 H 桥（老）（H 桥 = 四个开关围成 H 形，能控制电机正反转和刹车） | 2A 级，压降大发热高 | 教学小车 |
| TB6612FNG | 双 H 桥（主流） | 1.2A/路（峰值更高） | 小车电机 |
| A4988 / TMC2209 | 步进驱动 | 细分可调 | 3D 打印机/云台 |

| 型号 | 功能 | 要点 | 典型用途 |

| CH340G / CH340N | USB 转串口 | 国产标配，成本低 | 下载器、调试串口 |
| CP2102 / FT232 | USB 转串口 | 大厂，兼容性好 | 商用产品 |
| MAX232 | RS232 电平转换 | 经典老接口 | 工业老设备 |
| MAX485（5V）/ SP3485（3.3V） | RS485 收发 | 半双工差分 | Modbus 现场总线 |
| TJA1050 / TJA1042 | 高速 CAN 收发（5V） | 配 SJA1000 或 MCU 内置 CAN | 汽车/工控 |

| LAN8720A | 以太网 PHY（RMII）（PHY = 物理层芯片，把数字数据变成网线上的电信号；RMII = 一种精简的与主控对接的接口标准） | 配 STM32 MAC（主控里管以太网协议的控制器） | 网口板 |

## 4. 存储类

> 这表是什么：掉电不丢数据的存储芯片货架。什么时候翻：要"记住"参数、字库、采集数据时来查——EEPROM 存小参数、Flash 存大块数据、SD 卡存海量记录。

| 型号 | 接口 | 容量（典型） | 用途 |
|------|------|--------------|------|
| AT24C02 / 04 / 08 / 16 | I2C EEPROM（EEPROM = 电可擦写存储器，按字节改写、掉电不丢） | 2Kbit 起 | 存参数/校准值 |
| W25Q16 / 32 / 64 / 128 | SPI NOR Flash | 16~128Mbit | 存字库/波形/固件包 |
| SD 卡（SPI 模式） | SPI/SDIO | GB 级 | 数据记录仪 |

## 5. 传感器类

| 型号 | 测什么 | 接口 | 要点 |
|------|--------|------|------|
| DS18B20 | 温度 | 单总线 | -55~+125℃，单线多点 |
| DHT11 / DHT22 | 温湿度 | 单总线 | 便宜入门 / 精度更高 |
| SHT30 / AHT20 | 温湿度 | I2C | 工程上更常用，精度高 |
| BH1750 | 光照度 | I2C | 直接输出 lux |
| 光敏电阻 + 分压 | 光照 | ADC | 最便宜方案 |
| MPU6050 | 加速度+陀螺仪 | I2C | 平衡车/姿态 |
| ACS712 | 电流（霍尔隔离） | 模拟输出 | 5A/20A/30A 三档；更精密用采样电阻+INA 运放 |
| ADS1115 | 16 位 ADC 扩展 | I2C | 4 通道，带 PGA |
| VS1838B | 红外接收 38kHz | 数字 | 遥控器 |
| HC-SR501 | 人体感应 | 数字 | 楼道灯/安防 |
| HC-SR04 | 超声波测距 | Trig/Echo | 小车避障 |

## 12. 常用阻容值习惯（BOM 归一化，少备料）

> 这是什么：老工程师的"常用值清单"——设计时优先从这几个值里挑，别标新立异。什么时候翻：自己画原理图选阻容值时。

- **电阻**：10Ω / 100Ω / 220Ω / 470Ω / 1k / 4.7k / 10k / 100k，基本覆盖 90% 设计；上下拉统一 10k，I2C 上拉 4.7k，LED 限流 220~1k；
- **电容**：22pF（晶振）、100nF=0.1μF（去耦，标"104"）、1μF/10μF（滤波）、100μF~470μF 电解（储能）；
- **归一化意义**：物料种类少→备货/贴片成本低，工业生产的重要习惯。

## 13. 选型流程与查资料渠道

> 这是什么：从"需求"到"下单"的五步选型流程和查资料入口。什么时候翻：第一次独立选器件时照着走一遍，走熟了就是肌肉记忆。

```
① 明确需求（电压/电流/接口/精度/成本）
② 立创商城 szlcsc.com 按参数筛选 → 看库存/价格/国产替代
③ 下载原厂 datasheet → 重点看：绝对最大额定值、典型应用电路、封装热阻
④ 对比 2~3 款，留 50% 参数裕量（电流/电压/温度）
⑤ 打样验证 → 记录进个人 BOM 库
```

- datasheet 查询：立创商城（中文资料多）、原厂官网（ST/TI/沁恒等）、alldatasheet
- 电路参考：嘉立创开源广场（海量开源板，直接看别人的 BOM 和原理图）

## 14. 章节小结

- 电源：AMS1117（3.3V 小板）、TP4056（锂电）、MP1584（大压差）
- 驱动：S8050/8550 + AO3400/3401 + ULN2003 三件套覆盖大部分开关需求
- 通信：CH340、MAX485、TJA1050、ESP32 是四大"联网/组网"入口
- 传感器：DS18B20、SHT30、BH1750、MPU6050 先玩熟这四个
- 显示：SSD1306 OLED + TM1637 数码管
- 选型铁律：**参数留 50% 裕量、BOM 归一化、一切以 datasheet 为准**

## 课后思考题

1. 为什么工业设计追求"BOM 归一化"？（物料种类少→采购/仓储/贴片成本与出错率都降）
2. 同功能芯片如何判断"引脚兼容可直换"？核对哪些信息？（封装+引脚定义+关键参数裕量）
3. TVS 和自恢复保险丝为什么常一起放在电源入口？（保险防持续过流，TVS 防瞬间浪涌，分工不同）
4. ESP8266 模组供电为什么要特别注意？（峰值电流大，电源能力不足是"连不上/频繁重启"的头号原因）

> 器件参数请以立创商城（szlcsc.com）与原厂 datasheet 为准，本文为速查索引。
