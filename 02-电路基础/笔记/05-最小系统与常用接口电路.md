# 05 · 最小系统与常用接口电路

> 把笔记01~04 的零件拼成"能跑的板子"。学完这篇，你应能**看懂 STM32 开发板原理图的每个模块**。

---

## 1. MCU 最小系统（四件套 + 复位）

> **这是什么**：光有一颗 MCU 芯片它跑不起来——就像光有一颗心脏没有血管神经。最小系统就是让芯片"活过来"所需的最少外围电路：供电、心跳（时钟）、重启（复位）、启动选择（BOOT）。
> **为什么需要它**：这是看懂任何开发板原理图的第一步，也是焊自己第一块板子的检查清单——四件套缺一件，现象各不相同，排查时逐项对号。

一块 MCU 芯片想跑起来，必须补齐的外围电路：

```
┌────────────────────────────────────────────┐
│  ① 电源：VDD/VSS 各配 0.1μF 去耦 + VCAP     │
│  ② 时钟：晶振 + 负载电容（或用内部RC）        │
│  ③ 复位：NRST + RC电路 + 复位按键            │
│  ④ BOOT：BOOT0/BOOT1 启动选择（STM32特有）   │
└────────────────────────────────────────────┘
```

### ① 电源
- 每个 VDD 引脚一颗 0.1μF 去耦（铁律）；
- STM32 带 VCAP 引脚（内核稳压）接 2.2μF 低 ESR 陶瓷电容，**不能省**。

### ② 时钟电路（晶振）

```
     ┌──[8MHz 晶振]──┐
  OSC_IN           OSC_OUT
     │                │
  [20pF]           [20pF]     负载电容按晶振规格算：CL=(C1×C2)/(C1+C2)+Cstray
     │                │       典型取 20pF（晶振规格书标注 CL=20pF）
    GND              GND
```
- 图中公式符号解释：CL 是晶振要求的"负载电容"（规格书给出，如 20pF）；C1、C2 是晶振两只脚各接一颗的电容；Cstray 是 PCB 走线和引脚自带的杂散电容（一般按 3~5pF 估）。实际成品板常直接取 20pF 附近也能稳定起振；严谨设计按晶振规格书的推荐负载电容来配，这是晶振应用最常翻车的一处；
- 晶振 = 电路的**心跳**，所有时序（串口波特率、定时器）都从它分频；
- 类比：乐队的鼓手，节奏乱一切乱；
- 走线要短、包地，附近别走高速信号；
- 低成本方案可不用外部晶振（内部 HSI），但串口等精确时序场景推荐外部晶振。

### ③ 复位电路

```
3.3V ──┬──[10kΩ]──┬──> NRST
     [0.1μF]      │
       │        [复位按键]
      GND          │
                  GND
```
通电后发生了什么（一步步演）：
- 第一步：3.3V 刚接上的一瞬间，0.1μF 电容还是"空的"，电流涌向电容——NRST 引脚经它被拉到低电平，芯片进入复位状态；
- 第二步：电容慢慢充电（RC 充电曲线），NRST 电平跟着抬升；
- 第三步：电容充满（毫秒级），NRST 稳在高电平，复位释放，芯片从 0 地址开始跑程序。
- 按下复位按键：NRST 被直接按到地 → 手动复位；松开后重走一遍"充电释放"过程。
类比：闹钟响了你按"重启"键，给系统一个从头开始的信号。

### ④ BOOT 启动选择（STM32）
| BOOT0 | BOOT1 | 启动位置 |
|-------|-------|----------|
| 0 | × | 主 Flash（正常运行，拉低/下拉 10k） |
| 1 | 0 | 系统存储器（串口 ISP 下载模式） |
| 1 | 1 | 内置 SRAM（调试用） |

BOOT0 必须下拉电阻定死——**悬空 = 有时从错误区域启动，现象是"有时能跑有时不能跑"**，经典疑难杂症。

## 2. 输入接口电路

> **这是什么**：把"外部世界的动作"（人按按键、机器给信号）变成 MCU 能读的高/低电平。核心问题就两个：别让引脚悬空，别让危险电压进来。

### 按键（独立按键）

```
MCU_GPIO ──┬──[按键]──GND     （内部上拉模式，按下=低）
           └──[0.1μF 对地]    （可选：硬件消抖）
```
软件消抖：检测到按下后延时 10~20ms 再确认（笔记代码阶段实践）。

### 外部输入保护
工业输入（24V 信号）：光耦隔离 + 分压/限流，把强电世界挡在板外。

## 3. 输出接口电路

> **这是什么**：让 MCU 引脚去"点亮世界"——LED、数码管、蜂鸣器、继电器。核心问题是电流：引脚带得动的直驱，带不动的加三极管/MOS/驱动芯片（笔记03 全派上用场）。

### LED
GPIO ──[220Ω~1kΩ]──LED──GND（灌电流/拉电流都行，注意芯片单脚 25mA 上限、整脚总和限制）。

### 数码管
共阳/共阴 8 段 LED 组，串限流电阻，动态扫描（IO 复用分时点亮）；段电流大时加三极管/驱动芯片（74HC245、TM1637）。

### 蜂鸣器
- 有源蜂鸣器：给电就响，NPN 驱动（笔记03）；
- 无源蜂鸣器：需要 PWM 方波驱动，可变音调。

### 继电器模块
NPN/NMOS + 续流二极管驱动线圈；触点接强电【安全警示：触点侧 220V 严禁裸露操作，实验用 5~24V 低压灯替代】。

## 4. 通信接口电路

> **这是什么**：MCU 与 MCU、MCU 与模块之间"拉线通话"的几种制式——UART 点对点、I2C/SPI 板内短途、RS485/CAN 工业长距离。每种接口都有自己的"接线规矩"，接错了不是不通就是乱码。

### UART（串口）
- 直连：TX↔RX 交叉，共地。3.3V↔3.3V 直接接；USB 转串口模块（CH340）注意电平版本；
- 加 120Ω 串联电阻 + TVS 抗静电（对外接口标配）；
- **RS485**：差分 A/B 线 + 收发器（MAX485/SP3485），A、B 之间及到地可加 TVS，总线两端 120Ω 终端电阻。工业抗干扰标配，距离可达上千米。

### I2C
- **必须上拉**：SCL、SDA 各接 4.7kΩ 上拉到 3.3V（为什么：开漏输出 = 芯片引脚内部只有"拉到地的开关"、没有"推到电源的开关"，只能主动拉低，松手后靠上拉电阻把线"拉"回高电平——像按住弹簧再松手）；
- 多设备并联同总线，地址区分；
- 走线长/干扰大时降速（100k→10kHz）并加 TVS。

### SPI
四线（SCK/MOSI/MISO/CS），推挽输出不需上拉，速度快；多从设备各配 CS 片选。注意 MISO 在多从机时需三态/线与处理（三态 = 引脚除了输出高/低，还能"松手"变高阻态——没被选中的从机松手，免得和正在应答的从机打架）。

### CAN
收发器（TJA1050/SN65HVD230）+ 两端 120Ω 终端电阻 + 共地。差分抗干扰，汽车/工业标准。

### USB
DM/DP 差分对，等长走线；VBUS 5V 给设备供电，CC 电阻（Type-C）决定角色。

## 5. 传感器接口范式

> **这是什么**：一张"传感器怎么接"的速查表——常见传感器按接口类型归类，接法范式就这几种，以后遇到新传感器先对号入座。

| 传感器 | 接口 | 外围 |
|--------|------|------|
| DHT11/DS18B20 | 单总线 | 4.7k~10k 上拉 |
| 光敏/电位器 | ADC | 分压/RC 滤波 |
| MPU6050/OLED | I2C | 4.7k 上拉 ×2 |
| 红外接收 | 数字输入 | 需上拉+滤波电容 |
| 超声波 | Trig/PWM 输入 | 直连 |

## 6. 章节小结

- 最小系统 = 电源去耦 + 晶振 + 复位 RC + BOOT 定电平
- BOOT0 悬空是"时好时坏"经典故障源
- I2C 必上拉（开漏特性决定），RS485/CAN 有终端电阻，都是"接口电路性格"
- 对外接口三板斧：串联电阻、TVS、光耦——抗干扰与保护
- 输出看电流选直驱/三极管/MOS/驱动芯片

## 课后思考题

1. 晶振负载电容用错（如该 20pF 用了 100pF）会怎样？（振荡频率偏移甚至不起振，串口乱码、系统不跑——晶振章节最常见翻车点）
2. 为什么 I2C 用开漏+上拉而不是推挽直接输出？（多设备线与仲裁需要"只拉低"不冲突；推挽对推会短路打架）
3. NRST 上 0.1μF 太大会怎样？（复位时间过长，看门狗/启动体验变差；太小则复位不彻底）
4. RS485 总线为什么两端各 120Ω？（匹配双绞线特征阻抗，消除信号反射——不匹配则长线通信误码）
