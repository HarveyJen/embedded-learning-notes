# 01 · 电路基本概念与定律

## 1. 电流、电压、功率（用水来类比）

> **这一节是什么**：电流、电压、电阻、功率是电路的四个基本量，就像长度、重量之于日常生活——后面所有计算（LED 限流、分压、选电阻）全部建立在这四个概念上。先花两分钟把符号和单位认全。

**符号与单位速认表**（公式里的"字母"第一次出现，必须认识）：

| 符号 | 全称 | 含义 | 单位与换算 |
|------|------|------|------------|
| I（Current） | 电流 | 电荷定向移动的强弱 | 安培 A；1A = 1000mA，1mA = 1000μA（嵌入式常见 mA/μA） |
| U 或 V（Voltage） | 电压 | 两点间的电位差，是推动电流的"压力" | 伏特 V；1V = 1000mV |
| R（Resistance） | 电阻 | 对电流的阻碍大小 | 欧姆 Ω；1kΩ = 1000Ω，1MΩ = 1000kΩ |
| P（Power） | 功率 | 每秒消耗/转换的电能 | 瓦特 W；1W = 1000mW |

> 前缀规律（通用）：**k=千（×1000）、M=兆（×100万）、m=毫（÷1000）、μ=微（÷100万）**。注意大小写有区别：大 M 是"百万"，小 m 是"千分之一"——5mV 和 5MV 差了十亿倍，写错就是烧板级事故。

想象一个水塔供水系统：

| 电学量 | 水的类比 | 定义 | 单位 |
|--------|----------|------|------|
| 电流 I | 水流 | 电荷的定向移动 | 安培 A（嵌入式常见 mA） |
| 电压 U | 水压差 | 两点间的电位差 | 伏特 V（3.3V / 5V） |
| 电阻 R | 水管的阻碍 | 对电流的阻碍作用 | 欧姆 Ω |
| 功率 P | 单位时间送水做的功 | 电能消耗速率 | 瓦特 W |

- 电流方向：规定正电荷移动方向为电流方向，从"+"流向"-"（实际金属中是电子反向流动，不影响分析）；
- 电压必须有**参考点**：说"PA5 是 3.3V"，其实是"PA5 相对 GND 的电位差是 3.3V"；
- 功率公式（必背）：

```
P = U × I        （功率 = 电压 × 电流）
P = I² × R       （电阻上的发热功率——选电阻功率等级时用它）
P = U² / R
```

文字解释 + 一步步代入：一个 LED 的工作电流 20mA、压降 2V，它消耗多少功率？

- 第一步：统一单位。20mA = 20 ÷ 1000 = 0.02A（毫安换安培，除以 1000）；
- 第二步：套公式 P = U × I = 2V × 0.02A；
- 第三步：P = 0.04W，换回毫瓦 = 0.04 × 1000 = 40mW。

这 40mW 变成光和热，它决定了限流电阻的取值和功率规格（电阻还要替 LED 分担剩下的发热）。

## 2. 欧姆定律（最常用，没有之一）

> **这一节是什么**：欧姆定律是电路世界的"乘法口诀"——知道电压、电流、电阻三个量中的两个，就能算出第三个。全天下 90% 的电路计算靠它，本篇后文的分压、限流全从这里来。

```
U = I × R        （电阻两端电压 = 流过的电流 × 阻值）
I = U / R
R = U / I
```

**逐符号解释**：U（单位 V）是这只电阻两端的电压；I（单位 A）是流过它的电流；R（单位 Ω）是它的阻值。三个量必须"同属一只电阻、同一时刻"；代入时单位要用 V/A/Ω 原装组合，遇到 mA 就先除以 1000 换成 A。

生活类比：水压越大水流越大（U 越大 I 越大）；水管越细阻力越大水流越小（R 越大 I 越小）。

**嵌入式最常用：算 LED 限流电阻（一步步算）**

问题：5V 电源点亮一个 LED（压降约 2V），想让电流为 20mA，串多大的电阻？

- 第一步：想清楚"谁分掉多少电压"。LED 导通后要吃掉约 2V（这是它的"过路费"，基本固定），剩下的电压都由电阻承担——电阻分得 5V − 2V = 3V；
- 第二步：期望电流 20mA = 0.02A（除以 1000 换成安培）；
- 第三步：套欧姆定律 R = U / I = 3V ÷ 0.02A = 150Ω；
- 第四步：对照标称值选最近的常用值——150Ω 正好有，就用它；若算出 133Ω 这类别扭值，选大一档（如 150Ω），电流小一点更安全、LED 更长寿。

顺手校验电阻发热：P = U × I = 3V × 0.02A = 0.06W = 60mW，普通 0805 贴片（1/8W = 125mW）绰绰有余。

3.3V 电源的情形（STM32 板常见）：
```
3.3V 电源，LED 压降约 2V，想让电流为 10mA：
R = (3.3V − 2V) / 0.01A = 130Ω
取标称值 150Ω 或 220Ω（稍小电流更安全、LED 寿命更长）
```

> 这类"先算压差（电源电压减 LED 压降）再除电流"的思路贯穿所有驱动电路设计。

## 3. 基尔霍夫定律（电路分析的两大守恒）

> **这一节是什么**：欧姆定律管"一只电阻"，基尔霍夫两条定律管"整个电路"——分别给电流和电压立了"记账规则"，读电路、核对计算结果时全靠它们当裁判。

### KCL：电流守恒（节点定律）
流入某节点的电流之和 = 流出该节点的电流之和。
类比：水管的三通接头，进多少水就出多少水，不会凭空多出水。

### KVL：电压守恒（回路定律）
沿任一闭合回路绕一圈，所有电压降的代数和 = 0（电源电压 = 各段压降之和）。
类比：从楼上走到楼下又走回原点，高度变化总和为零。

**应用示例**：3.3V 电源 → 电阻 R → LED → GND
KVL：3.3 = U_R + U_LED，LED 压降 2V，所以电阻分得 1.3V——这就是限流电阻计算的来源。

## 4. 串联与并联（必须秒算）

> **这一节是什么**：实际电路从来不是一只电阻孤零零连电源，而是很多元件"排队"（串联）或"并排"（并联）组合。这两条组合规则 + 欧姆定律，就能手算大部分简单电路。

### 串联（一条路排到底）

```
总电阻 R = R1 + R2 + ...      （越串越大）
电流处处相等 I 相同
电压按电阻比例分配（分压）：U1 = U × R1/(R1+R2)
```

### 并联（并排两条路）

```
1/R = 1/R1 + 1/R2  → 两只并联：R = R1×R2/(R1+R2)   （越并越小）
电压处处相等 U 相同
电流按电阻反比分配（分流）
```

代入算例：10kΩ 与 10kΩ 并联 → R = 10k×10k/(10k+10k) = 5kΩ（相同阻值并联减半）；20kΩ 与 5kΩ 并联 → R = 20k×5k/(20k+5k) = 4kΩ（结果总比最小的那只还小）。

生活类比：串联像单车道，车流（电流）一样，坡度（电压）可以不一样；并联像双车道，两边路宽（电压）一样，车流随车道宽度分。

**两个特例要记住**：
- 相同电阻并联，阻值减半；
- R 串一个比它大得多的电阻，总阻 ≈ 大电阻；并联则 ≈ 小电阻。

### 分压电路（嵌入式高频应用：ADC 采集）

```
Vin(5V) ──R1──┬── Vout ──> MCU ADC 引脚
              R2
              │
             GND

Vout = Vin × R2 / (R1 + R2)
```
**逐符号解释**：Vin 是输入电压，Vout 是分出来的输出电压；R1 是"上"电阻（接电源侧）、R2 是"下"电阻（接地侧）；输出取自两只电阻的连接点——R2 分得的比例就是它占总阻值的份额。

例：R1=10kΩ，R2=10kΩ → Vout = 5×10/20 = 2.5V。
再举一例（把 5V 信号降到 3.3V 以内）：选 R1=10kΩ、R2=15kΩ → Vout = 5 × 15/(10+15) = 3.0V，留了安全裕量。
用途：把 0~5V 信号分压到 0~3.3V 给 ADC 采集（3.3V 单片机不能直接进 5V 信号）。

## 5. GND 与"地"的概念（新手最迷惑的点）

> **这一节是什么**：电压是"两点之间的差"，那量电压时第二只表笔该搭哪儿？——搭在电路里人人心照不宣的公共参考点 GND 上。这一节讲清这个参考点，顺便认下原理图上的电源符号。

**符号含义**：GND = 地（公共参考点，规定 0V）；VCC = 电路的供电正端（3.3V/5V 那根线，看到 VCC 默认"供电正极"）；VDD/VSS 是芯片引脚视角的正电源/地，初学阶段可先当作 VCC/GND 理解。

- **GND（地）**：电路的**公共参考点**，规定为 0V。电压都是相对它量的；
- 类比：海拔以海平面为 0。没有海平面，"这座山多高"就没有意义；
- 电路里所有 GND 必须**连在一起**（共地），否则电路不工作——**单片机和外设模块接线，第一件事就是共地**。

嵌入式里常见的几种"地"（先混个脸熟）：

| 名称 | 含义 |
|------|------|
| 电源地 (GND/PGND) | 功率电流回的地 |
| 信号地 (AGND/DGND) | 模拟信号/数字信号的地，抗干扰需要时可分开走线最后单点相连 |
| 大地 (PE) | 市电三孔插座的地，保护用，与电路 GND 不一定连通【涉及市电，安全警示：不懂勿接】 |

## 6. 直流与交流、模拟与数字

> **这一节是什么**：电压电流按"方向变不变"分成直流/交流，信号按"取值连续还是只有两档"分成模拟/数字——这四个词是后面所有章节的通用词汇，先在此分清，后面看到不再卡壳。

- **直流 DC**：方向不变，如 3.3V、5V、电池——嵌入式电路主体；
- **交流 AC**：方向周期变化，如市电 220V/50Hz——只出现在电源适配器之前【安全警示：市电侧禁止自拆自修】；
- **模拟信号**：连续变化，如麦克风输出、温度传感器电压；
- **数字信号**：只有 0/1 两种电平，如 UART/I2C 波形。单片机世界 = 模拟传感器 → ADC 转数字 → 处理 → DAC/PWM 还原。

常见电平标准（必记）：

| 标准 | 逻辑1 | 逻辑0 | 备注 |
|------|-------|-------|------|
| TTL (5V) | >2.4V | <0.4V | 51 单片机 |
| CMOS 3.3V | >2.0V (0.7VDD) | <0.8V (0.3VDD) | STM32 |
| RS232 | -3V~-15V | +3V~+15V | 负逻辑！与 MCU 电平相反 |

## 7. 上拉电阻与下拉电阻（嵌入式第一高频，提前建立概念）

> **这一节是什么**：单片机引脚不接东西时读数是随机的。上下拉电阻就是"用一只电阻给引脚一个默认答案"的土办法——便宜、简单，却解决嵌入式里最常见的输入悬空问题。

**问题**：单片机引脚悬空（不接任何东西）时，电平是高是低？——不确定，随风飘（受静电、干扰影响），程序读到 0 还是 1 全看运气。

**解决**：用电阻把引脚"拽"到确定电平：
- **上拉**：引脚经电阻接到 VCC → 默认高电平（比如按键接地，按下才变低）；
- **下拉**：引脚经电阻接到 GND → 默认低电平。

```
3.3V ──[R 上拉 10kΩ]──┬──> MCU 引脚
                      │
                    [按键]
                      │
                     GND
```
不按：引脚被上拉拽到 3.3V（高）；按下：引脚直通 GND（低）。R 取值 4.7k~10kΩ 常见（太小费电，太大拉不动、易受干扰）。

生活类比：没上拉的引脚像没人管的秋千，风一吹乱晃；上拉电阻像一只手一直扶着它，即使有干扰（风）也保持稳定位置，除非有更大的力（按键）掰它。

详细应用见笔记05（按键/I2C），这里先记住：**悬空=隐患，上下拉给确定电平**。

## 8. 章节小结

- 欧姆定律 + 分压公式是电路计算的 90%（U=IR；Vout=Vin·R2/(R1+R2)）
- KCL 管电流守恒，KVL 管电压守恒，两者用来"读"电路
- 串联分压、并联分流；ADC 采集、LED 限流全都从这里来
- GND 是参考点，**共地是接线第一步**
- 上拉/下拉解决引脚悬空问题

## 课后思考题

1. 5V 电源接一个 1kΩ 电阻到 GND，电流多大？电阻功率多大？（5mA；25mW，普通 0603/0805 封装都够）
2. 两个 LED 直接并联能不能正常工作？为什么？（不推荐：压降差异导致电流分配不均，亮度不同，应各自串限流电阻）
3. 为什么 MCU 引脚直连 5V 传感器输出可能烧芯片？（3.3V 系统引脚耐压有限，需分压或电平转换）
4. 上拉电阻取 100Ω 行不行？取 10MΩ 行不行？（100Ω 按下按键时电流 33mA 太费电；10MΩ 太弱抗干扰差、速度慢——I2C 场景直接影响上升沿速度）
