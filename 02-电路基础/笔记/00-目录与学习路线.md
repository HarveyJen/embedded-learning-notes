# 电路基础 · 目录与学习路线

> 目标：看懂原理图、认识元器件、会用万用表和示波器。
> 学习方式：**与 01-C语言阶段并行**，每天 20~30 分钟，共约 3~4 周过完一轮。
> 所有器件参数均以"典型值"表述，实际设计以 datasheet 为准。
> 人话版定位：这一阶段回答"板子上那些花花绿绿的小东西都是什么、怎么连、怎么量"——不深究物理推导，目标是拿到任何一块开发板原理图不犯怵。

## 学习顺序与节奏

```
第1周：笔记01 + 笔记02前半（电阻、电容）
第2周：笔记02后半（电感）+ 笔记03（二极管、三极管、MOS）
第3周：笔记04 + 笔记05（结合开发板原理图对照着看）
第4周：笔记06（万用表/示波器实操）+ 全部实操任务收尾
```

- 看不懂的公式**先记结论再回头理解**，本阶段不做数学推导；
- **必须动手**：几块钱的面包板 + 元器件包 + 万用表，比看十遍视频有用。

## 阶段验收标准

- [ ] 拿一张 STM32 开发板原理图，能说清电源、晶振、复位、BOOT 各部分的作用
- [ ] 能算：LED 限流电阻取值、分压电阻输出电压
- [ ] 能解释：去耦电容为什么放芯片旁边、I2C 为什么需要上拉电阻
- [ ] 会用万用表测电压/通断/二极管档，判断 LED 和二极管好坏
- [ ] 会用示波器测一个 PWM 波形的频率和占空比

## 常见问题 FAQ

**Q1：不学模电直接学单片机行不行？**
行，嵌入式岗位 80% 的工作不需要深入模电。但要懂"够用级电路"：上下拉、限流、去耦、驱动管。本套笔记就是这个"够用级"。

**Q2：要不要学画 PCB？**
建议阶段二 STM32 学到中期再开始（用立创EDA 画一块最小系统板）。不画板也能干活，但会画板是简历加分项。

**Q3：先买什么硬件？**
万用表（必备，几十元）→ 面包板+元器件包（十几元）→ 之后随 STM32 阶段买开发板 + ST-Link + 逻辑分析仪。
