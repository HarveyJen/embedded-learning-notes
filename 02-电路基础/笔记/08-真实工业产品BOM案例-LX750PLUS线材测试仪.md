# 08 · 真实工业产品 BOM 案例：LX-750PLUS 线材综合测试仪

> 一台真实在产工业设备的完整物料清单（BOM），分类维度：**芯片 IC / 继电器 / 分立半导体 / 无源元器件 / 晶振·电池·可调器件 / 连接器与结构件**。
> 学习价值：把 02~07 篇笔记的知识"对号入座"——看一台真机里每类元件怎么用、为什么选它、坏了是什么表现。
> 注：价格为采购参考价（¥），随行情变动；失效提示来自维修经验，供参考。

**设备简介**：线材综合测试仪——检测线束的导通/断路/短路/绝缘电阻/耐压，通道数 64~128 点。整机 = CPU 板（主控+显示）+ 功能板（继电器矩阵+测量电路）+ HV 高压板（绝缘/耐压激励，HV = High Voltage 高压）+ TypeC 子板。

> 术语先知道：**BOM**（Bill of Materials，物料清单）= 一台设备用到的所有元件的采购清单，工业上的采购、贴片、维修都围着它转；下文"易损件""停产料""红线条目"都是 BOM 管理常用词。

## 一、集成电路 IC

> 这章是什么：这台设备里所有"有型号的芯片"大盘点。什么时候翻：想看"一台真机里都放了哪些芯片、各自干什么"时通读；排查芯片故障时按分类定位。

### 1. 主控 & 存储 & 加密（CPU 板）

| 型号 | 用途 | 要点 | 单价(¥) |
|------|------|------|---------|
| LPC2478（NXP ARM7，LQFP208） | 整机主控：任务调度、LCD 控制器、USB/网口/串口 | ARM7 内核；**存量停产料**——停产芯片管理是工业 BOM 重要课题（备料/替代评估） | 37 |
| K4S561632N-LI60 256Mbit SDRAM | 显存 + 测量数据缓存 | 256Mbit=32MB；**时序敏感**（PCB 等长、端接） | 25 |
| SST39VF6401B 64Mbit NOR Flash | 固件存储 | 支持 XIP 就地执行，存固件与校准参数 | 14.26 |
| LKT4105U（凌科芯安） | 硬件加密鉴权 | **贴片前预烧密钥，焊后不可烧录**——生产流程必须先烧后焊 | 3.8 |

> 对照笔记：NOR Flash 与 W25Q 系列同族（XIP vs SPI）；SDRAM 时序要求 ↔ 笔记02"时序敏感器件"概念。

### 2. 模拟信号 IC（测量链核心）

> 这表是什么：测量仪器的"模拟发动机舱"——DDS 激励、ADC 采样、运放放大、比较器判定全在这。什么时候翻：想理解"仪器是怎么把电阻/电压测出来的"时精读。

| 型号 | 用途 | 要点 | 单价(¥) |
|------|------|------|---------|
| AD9833 | DDS 可编程激励源（DDS = 直接数字频率合成，MCU 写个寄存器就能精确改频率的"波形发生器"） | 生成正弦/方波激励，用于线束导通元件测试 | — |
| AD1674JRZ | 12 位主 ADC | 模拟信号采样数字化 | 46.5 |
| AD637JRZ | 真有效值转换 | 整机交流测量核心，**本 BOM 最贵模拟 IC** | 58 |
| AD736JRZ ×2 | HV 高压板交流有效值回采 | 高压回路采样 | 25 |
| AD7528（1~2 片） | 双路 8 位 DAC | 生成测试阈值/基准电压；U26 标配、U25 高配双片 | 原始未录入 |
| OP27 ×12 | 精密前置运放 | **绝缘电阻测量红线器件，不可随意代换** | — |
| OP07 ×9 | 低失调直流运放 | 直流微弱信号放大 | — |
| TL071 ×8 | JFET 高阻缓冲运放 | 高输入阻抗，绝缘测量防负载效应 | — |
| LM311 ×11 | 电压比较器 | 阈值判定，导通/断路快速判断 | — |
| DG211 ×5 | 四路常闭模拟开关 | 精密模拟通道切换 | — |
| CD4051 | 8 选 1 多路开关 | 低成本多路选通，继电器矩阵大量使用 | — |

> 学习点：一台测量仪器的"模拟前端"分层——**激励（DDS）→ 通道切换（模拟开关/继电器）→ 前置放大（运放）→ 判定（比较器）或数字化（ADC）→ 运算（真有效值）**。运放选型三要素正好各占一席：精密（OP27）、低失调（OP07）、高阻（TL071）。

### 3. 逻辑 / CPLD

> 这表是什么：数字"胶水"器件——74 系列缓冲/锁存 + CPLD 时序中枢。什么时候翻：好奇"几百路控制信号谁在指挥"时看这表。

| 型号 | 用途 | 要点 | 单价(¥) |
|------|------|------|---------|
| iM4A5-64（Lattice CPLD）（CPLD = 可编程逻辑器件，"可以自己编程的 74 系列"，配置后由硬件并行执行） | 功能板译码、时序中枢 | 分担主控 IO，管理模拟开关时序 | 30 |
| 74HC 系列：244/245/373/374/138/HCT03 | 总线缓冲、锁存、地址译码 | 数字总线隔离防冲突 | — |

> 对照笔记07：74HC245/138 已认识；CPLD 是"可自己编程的 74 系列"，多片 74 系列不够用时升级方向。

### 4. 电平转换 / 驱动 / 光耦

> 这表是什么：板与板之间"语言翻译 + 力气放大 + 安全隔离"三类器件。什么时候翻：看多电压域的板子怎么安全互通时查。

| 型号 | 用途 | 要点 |
|------|------|------|
| 74LVC4245（国产替代 LJ245A）×3~4 | 3.3V↔5V 双向电平转换 | CPU 板与 5V 模拟板总线互通 |
| ULN2003 / ULN2803 | 达林顿阵列 | 继电器线圈大电流驱动（内置续流） |
| COSMO4010（KP4010C，替代 PC817）×11 | 光电隔离 | 强弱电隔离，阻断地环路干扰 |

> 对照笔记：电平转换对应笔记04"3.3V/5V 共存"；ULN2803 = 笔记07 同款；光耦 = 笔记03 光耦章节，国产替代策略是工业降本常规操作。

### 5. 接口 / 复位 / 电源监控 / 音频 / 矩阵驱动

> 这表是什么：整机"服务性芯片"杂项——串口、复位监控、提示音、USB 开关、按键扫描。什么时候翻：想看一台完整设备还需要哪些"边角料"芯片时。

| 型号 | 用途 |
|------|------|
| MAX3232 | RS232 电平转换，上位机调试 |
| MAX811T | 上电复位、掉电监控（看门狗类） |
| HT82V731 | I2S 音频 DAC，提示音生成 |
| LM3526M-L | USB 电源开关控制 |
| SN7326（IS31IO7326） | 按键+LED 矩阵驱动，节省主控 IO |
| LM386 | 音频功放，驱动喇叭/蜂鸣器 |

### 6. LDO 线性电源 IC

> 这表是什么：整机各路供电的稳压芯片清单。什么时候翻：想看"一台仪器需要几种电压、各由谁产生"时。

LM3940-3.3、LM317（可调）、79L06 / L7906（**负压**）、AMS1117

> 用途：生成 3.3V、5V、**-6V** 等数字/模拟供电。
> 学习点：模拟电路（运放）经常需要**负电源**——79 系列负压 LDO 是传统方案；LM317 = 可调版 AMS1117 思想。

### 7. Type-C 子板专用 IC

> 这表是什么：TypeC 检测子板的专用芯片。什么时候翻：研究"一个产品里多个 MCU 怎么分工"时看。

| 型号 | 用途 |
|------|------|
| CH569（沁恒）×2 | USB3.0 MCU，TypeC 线材协议处理 |
| CH543 | USB 通信辅助 MCU |
| TP8485E | RS485 收发器，子板与主板总线通信 |

> 学习点：复杂设备"多 MCU 架构"——主控 ARM7 + 专用 USB3.0 MCU 子板，板间用 RS485 总线通信；国产芯片（沁恒）已进入工业量产。

## 二、继电器（通道切换核心，**整机高频易损件**）

> 这章是什么：测量仪的"换挡开关"总表——每只继电器负责把某个被测通道接进测量电路。什么时候翻：理解仪器寿命/维修重点，或想看继电器在大系统里怎么用时。

| 型号 | 用途 | 数量 | 失效风险 |
|------|------|------|----------|
| EC2-5NU | 主测试通道切换（每测试点 1 只） | 64P×64 / 128P×128 | 触点氧化 → 导通误报 |
| EA2-12NU | 量程、信号回路切换 | 650B×2、HV×1 | 线圈烧毁、触点粘连 |
| G2R-212DC | 大电流回路 K4 | 650B×1 | 大电流触点烧蚀粘连 |
| SMI-12VDC-SL-2A/-2C | 高压回路 K1/K3 耐压通路 | 650B×2、HV×1、负载板×5 | **高压打火粘连 → 高压无法断开（危险）** |
| HFD3/5 | TypeC/Apple 负载通道 | TypeC-COM×7、负载板×4 | 小信号精密回路，触点电阻敏感 |

> 学习点：继电器按"回路电压/电流"分级选型——小信号（HFD3）、通用（EC2）、大电流（G2R）、高压（SMI）。**高压继电器粘连是安全级故障**，对应笔记03 续流与感性负载知识。

> 这章是什么：不集成的"单体"器件——二极管、三极管、MOS、可控硅、高压变压器。什么时候翻：想看功率路径和易损件时，可对照笔记03 逐个对号。

### 3.1 二极管

| 型号 | 用途 |
|------|------|
| LL4148 | 小信号开关二极管：续流、钳位，**整机用量最大** |
| RS1M / FR107 | 快恢复高压整流（快恢复 = 关断后恢复"拦截"能力快的整流二极管，适合较高频率场合） |
| ESJA08-08（800V） | HV 板高压整流 |

| 型号 | 用途 |
|------|------|
| MJE3055 / MJE2955 | NPN/PNP 对管（规格相近的一对 NPN+PNP），HV 板推挽升压核心（推挽 = 两管轮流工作推拉输出） |
| 2SB857、2SC4672、2SC4678 | 中小信号放大与驱动 |
| 03N10 | N 沟道 MOS |
| NCE01P30K（负载板 Q5） | **重点易烧备件** |

### 3.3 可控硅

CS45-16（TO-247）：AC 高压相位调压（交流高压输出控制）

> 学习点：可控硅（晶闸管）= "可控制导通角的交流开关"，调光/调压经典器件，是三极管笔记的自然延伸。

### 3.4 功率变压器（磁性功率件）

180:40000 匝高压变压器（次级 1100V，¥38）——HV 板耐压测试能量源。

> 学习点：匝比 180:40000 ≈ 1:222，升压比对应 5V 级输入→千伏级输出，与"变压器匝比=电压比"原理直接对应。

## 四、无源元器件（阻容感）

> 这章是什么：不供电也"干活"的电阻电容电感在真机里的选法。什么时候翻：想看"0.1μF 去耦、精密分压、高压薄膜"这些原则在真机上长什么样时。

### 4.1 电阻

- 诺亚森 0.1% 精密电阻：1K×17、2M/5M 2W **高压分压电阻** → 绝缘电阻测量精度核心
- 0805 普通贴片电阻：通用分压/限流

> 学习点：测量精度是被"精度电阻"决定的——普通 ±1% 电阻做不了基准分压；高压分压电阻还要看 **2W 功率与耐压**。

### 4.2 电容

| 类型 | 规格 | 用途 |
|------|------|------|
| MLCC 0805 104（0.1μF） | 每颗 IC 电源脚 | **去耦铁律的真实体现** |
| 钽电容 10μF/25V | 电源滤波 | 钽的稳定 |
| 铝电解 1000μF/25V | 继电器浪涌储能 | **64~128 只继电器同时吸合的电流池** |
| CBB81 高压薄膜 471J/1600V ×3 | HV 板 | 耐高压、尖峰吸收（薄膜电容 = 塑料膜做介质的电容，耐压高损耗小；471J = 470pF、J 档 ±5% 精度） |

> 学习点：电解大电容的用量与"继电器数量"正相关——感性负载群驱动的储能设计。

### 4.3 电感 / 磁珠

- 1206 60R 磁珠：电源高频 EMI 抑制
- 工字电感 100μH/2A：DC-DC 储能

## 五、频率器件、电池、可调器件

> 这章是什么：晶振（心跳）、纽扣电池（记忆）和校准电位器（标尺）——不起眼但能"一票否决"整机的关键小件。什么时候翻：排查"时间不准、校准丢失、频率漂移"类故障时。

| 器件 | 说明 | 失效提示 |
|------|------|----------|
| 晶振 12MHz | LPC2478 主振 | 不起振=整机不跑 |
| 32.768kHz | RTC | 时间不准先查它 |
| 3.579545MHz | UART 基准 | 串口误码关联项 |
| 25MHz / 30MHz | CPLD / TypeC 子板 | 子功能失效 |
| CR1620 纽扣电池 | RTC 后备 | **没电 → 校准参数/时间丢失**（维修常见故障源） |
| 3296 多圈电位器 VR1~VR5 | 硬件出厂校准（含 8V 基准 VR2） | **维修禁止随意调整**——校准电位器动一下=整机精度漂移 |

> 学习点：①3296 多圈电位器是"出厂校准"专用件，与笔记02 电位器知识点对应；②校准数据依赖 RTC 后备电池——任何带标定的仪器，电池更换是标准保养项。

## 七、从这台设备学到的工程规律（总结）

> 这章是什么：把前面六个章节的见闻"拧成"几条工程规律。什么时候翻：读完正文后收束复盘，或做自己的 BOM 时对照检查。

1. **测量仪器 = 激励源 + 通道矩阵 + 模拟前端 + ADC + 主控**，五段式架构是所有测量设备通用骨架
2. **继电器是测量类设备寿命短板**：数量多（64~128）、动作频繁、触点氧化/粘连是头号维修项
3. **模拟器件分层选型**：精密/低失调/高阻运放各司其职，"红线条目"（OP27 不可代换）来自标定体系
4. **多电压域共存**：3.3V 数字 + 5V 模拟 + -6V 负压 + 千伏高压 → 电平转换、隔离、耐压设计贯穿全板
5. **停产料管理**（LPC2478）与**加密芯片生产流程**（先烧后焊）是量产工程课题
6. **易损件清单**就是维修优先级：继电器 > NCE01P30K > RTC 电池 > 校准电位器（禁动）> 高压继电器（安全级）

## 思考题

1. 为什么 64 通道机型要用 CPLD 管理模拟开关时序，而不是全靠 MCU 引脚？（128 只继电器+多路开关 = 数百路控制信号，MCU IO 不够且时序要求严格，CPLD 并行译码+硬件时序）
2. 绝缘电阻测量为什么必须用 2M/5M 高压分压电阻 + 0.1% 精度？（分压比直接进计算公式，1% 误差=测量结果 1% 系统误差；高压下普通电阻会过功率）
3. 1000μF 电解如果失效（容量衰减），整机什么现象？（多继电器同时吸合瞬间电源被拉垮 → 测量结果异常/复位，"时好时坏"）
4. 为什么 TypeC 子板单独用 CH569 而不并入主控？（USB3.0 高速协议处理需要专用硬件，独立子板隔离高速信号+降低主控复杂度）

> 器件参数请以立创商城（szlcsc.com）与原厂 datasheet 为准，本文为速查索引。
