# 03 · 滤波器与频率响应

> 信号里混着"不要的频率"：电源纹波（100Hz~）、开关噪声（百kHz~MHz）、传感器抖动——**滤波器只放行想要的频段**。
> 嵌入式三大应用：ADC 前抗混叠、按键/PWM 平滑、电源去耦（它的本质就是滤波）。

## 1. 频率响应与"分贝"（先建概念）

> **这是什么**：滤波器像"频率门卫"——低通只放低频进、高通只放高频进。这一节先学会"怎么描述门卫的松紧"：截止频率 fc（门框在哪）和分贝 dB（衰减多少的记分牌）。
> **为什么需要它**：后面所有滤波电路（RC、有源、去耦）都靠 fc 和 dB 这两把尺子说话，先建立概念，公式才有意义。

任何电路对不同频率的信号"态度不同"：低通滤波器对低频放行、高频衰减。

- **-3dB 点 = 截止频率 fc**：增益降到通带的 70.7%（功率减半）的点，工程上视为"通过/不通过"的分界；
- **波特图**：横轴频率（对数）、纵轴增益（dB），一眼看出通带/过渡带/阻带；
- dB 速算：−20dB = 电压×0.1（dB 是对数记分牌：每 −20dB 电压缩小 10 倍，−40dB 缩小 100 倍，省得数字写一长串）；一阶滤波器在截止频率外**每十倍频率再降 10 倍（−20dB/十倍频程）**。

## 2. 一阶 RC 低通（必须吃透，它是"最常用电路"）

> **这是什么**：一只电阻 R + 一只电容 C 组成的最简低通滤波器——两个最便宜的元件就构成"低频放行、高频拦截"的门。
> **为什么需要它**：它是 ADC 采样前抗混叠、PWM 变直流、按键消抖的万能小工具，嵌入式里的"创可贴"，到处都用。

```
Vi ──[R]──┬── Vo
          │
        [C]
          │
         GND
```

原理（频率视角）：低频时 C 容抗大（近似断路）→ Vo≈Vi；高频时 C 容抗小（近似短路到地）→ Vo≈0。**R 和 C 组成"频率相关的分压器"**。（容抗 = 电容对交流电的阻碍，频率越高阻碍越小，Xc = 1/(2πfC)——这就是 02 篇"电容通高频阻低频"的数学来源。）

**截止频率公式（背下来）**：

```
fc = 1 / (2πRC)
```

**逐符号解释**：fc（单位赫兹 Hz）= 截止频率，增益降到 70.7% 的那个临界点；R 单位欧姆 Ω；C 单位法拉 F（代入必须用"纯法拉"：100nF = 0.0000001F）；2π ≈ 6.28（由电容充放电的数学推出，记数即可）。

**一步步算**：R = 10kΩ、C = 100nF →
- 第一步：统一单位，R = 10000Ω，C = 0.0000001F；
- 第二步：先算 RC = 10000 × 0.0000001 = 0.001 秒（这个乘积叫时间常数 τ，即电容充到 63% 需要 1ms）；
- 第三步：fc = 1 ÷ (2π × 0.001) = 1 ÷ 0.00628 ≈ 159Hz。

文字拆解：R（Ω）乘 C（F）= 时间常数 τ（秒）——"电容充到 63% 所需时间"；fc 就是"每周期给电容充电时间刚好不够"的临界频率。

常用取值速查：

| R | C | fc |
|---|---|----|
| 1kΩ | 100nF | ≈1.6kHz |
| 10kΩ | 100nF | ≈160Hz |
| 1kΩ | 1nF | ≈160kHz |
| 4.7kΩ | 10nF | ≈3.4kHz |

### 高通 = R、C 位置互换

```
Vi ──[C]──┬──[R]── GND
          └── Vo
```
低频被电容挡住、高频通过。隔直电容（笔记01 的 C1/C2）本质上就是高通。

## 3. 二阶与有源滤波（斜率更陡、形状可调）

> **这是什么**：一阶 RC 的"墙"太缓（干扰衰减不够狠），二阶 = 把墙砌陡一倍；"有源" = 请运放进来，滤波的同时还能放大、隔离——这是信号链里的正式方案。

- 一阶太"缓"（−20dB/dec），要把 50Hz 工频干扰从 1kHz 信号里滤干净需要更陡的墙 → **二阶（−40dB/dec）**；
- **Sallen-Key 结构**：运放 + 2R2C 组成二阶有源滤波——同相放大器骨架上加 RC 网络，Q 值（Quality Factor 品质因数，决定"墙顶"是平是鼓的形状参数）决定通带是否隆起；
- **有源 vs 无源**：无源（纯 RLC）不供电但带负载后特性漂移；有源（含运放）可放大、可级联、输入阻抗高——信号链里默认有源；
- 类型四兄弟：**低通 LPF / 高通 HPF / 带通 BPF（高通+低通串联）/ 带阻 BEF（陷波，专杀 50Hz 工频）**。

## 4. 嵌入式实战三连

> **这是什么**：三个"马上能用"的 RC 应用——ADC 抗混叠、PWM 变 DAC、按键消抖。每个都是一两颗电容就能解决的问题，学完直接上手。

### 4.1 ADC 前抗混叠（最重要）

**混叠**：采样会"折叠频谱"——高于采样率一半的干扰被折叠成低频假信号，软件无法剔除。
规则：**ADC 采样前加 RC 低通，fc < 采样率/2**（奈奎斯特），越靠近信号带宽越好。
例：采样 1ksps 测温度（有效信号 <10Hz）→ 前端 RC 取 fc≈50~100Hz（10k+100nF 即可）。

### 4.2 PWM + RC = 贫民 DAC

MCU 输出 PWM（如 1kHz/50%）→ 二阶 RC 低通（fc≈10Hz~100Hz）→ 输出 = 占空比 × VCC 的直流电压。
**改占空比即改输出电压**——没有 DAC 外设的芯片做慢速模拟输出（背光亮度、设定电压）的标准省钱方案。

### 4.3 按键 RC 消抖

按键并联 100nF + 串联 10k（构成低通）→ 毛刺（ms 级尖峰）被吃掉。硬件消抖与软件消抖（延时确认）二选一或并用。

## 5. 电源去耦 = 最简单的低通（回望笔记02）

> **这是什么**：用一个新视角回看去耦电容——它本质就是"电容到地的低通滤波器"。看懂这一节，你就明白笔记02 那条"铁律"背后的数学原理。

去耦电容（0.1μF 贴芯片脚）就是**电容到地的低通**：电源上的高频噪声经低容抗通路被"倒进"地，芯片脚上只剩干净的直流。一颗电容一个滤波器——去耦网络=滤波器阵列。

## 6. 故障与排查

> **这是什么**：滤波电路"滤过头/滤不住"的对症表——大多是 fc 算错或阶数不够，动手前先算一遍 fc。

| 现象 | 疑凶 |
|------|------|
| 信号高频段莫名衰减 | 前端 RC 的 C 取大了（fc 太低）——算一遍 fc |
| ADC 读数跳动大、叠加"折叠"出的奇怪低频 | 没加抗混叠滤波或 fc 太高 |
| PWM 变 DAC 输出残留锯齿纹波 | RC 阶数不够/fc 偏高 → 升二阶或降 fc |
| 50Hz 工频干扰进 ADC | 布线引入 → 前端加带阻/降 fc + 差分采样 |

## 7. 章节小结

- fc = 1/(2πRC)；−3dB 是分界；一阶 −20dB/dec、二阶 −40dB/dec
- 低通/高通只差 R、C 位置；隔直电容=高通
- ADC 前必抗混叠：fc < 采样率/2
- PWM+RC=低成本 DAC；去耦电容=微型低通
- 嵌入式默认"有源滤波（运放）做信号链，无源 RC 做随手小滤"

## 课后思考题

1. 为什么抗混叠滤波必须放在 ADC 之前而不是软件里？（混叠发生在采样瞬间，折叠后干扰与真实低频无法区分，软件无能为力——物理上只能先滤）
2. 一阶 RC 想"滤干净"50Hz 干扰（信号 1kHz）为什么不行？（50Hz 与 1kHz 只差 1.3 个十倍频程，一阶仅 −26dB；需要二阶以上或带阻陷波）
3. PWM 频率取 1kHz 做 DAC 会怎样？该取多少？（纹波频率太低，RC 要极低 fc → 响应慢且纹波大；PWM 至少取几十 kHz，fc 取其 1/50 以下）
4. 去耦电容为什么用 0.1μF 而不是 100μF？（容值越大高频容抗特性越差（自谐振频率低），0.1μF 在 MHz 段阻抗最低——"高频噪声"恰好要它）
