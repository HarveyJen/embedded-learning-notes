# 05 · 负反馈、功放与嵌入式模拟前端实战

> 收官篇：负反馈是模拟设计的"总哲学"，功放是放大的"最后一公里"，最后把全部知识组装成完整的**嵌入式信号采集链**。

## 1. 负反馈：贯穿模拟设计的总哲学

> **这是什么**：负反馈 = 从输出端取一部分信号送回输入端"抵消"输入——输出想飘就拉一把，想跌就抬一把。
> **为什么需要它**：放大器天生"又猛又不稳"（增益受温度、器件差异影响极大），负反馈牺牲一部分增益，换回"稳、准、不歪"——模拟设计 90% 的稳定性都来自它。

**结构**：把输出按比例取样（反馈网络 F），送回输入端与输入信号**相减**，误差再被放大（A）。

```
Vi ──(−←[反馈 F]── Vo)──▶ [放大器 A] ──▶ Vo
```

### 负反馈换来了什么（代价是牺牲增益）

| 收益 | 一句话原理 |
|------|-----------|
| 增益稳定 | A 漂移 100 倍，闭环增益只漂百分之几（Af≈1/F 由电阻决定，电阻最稳） |
| 失真减小 | 输出的非线性被"取样-相减"抵消掉大半 |
| 带宽展宽 | 增益降 N 倍，带宽升 N 倍（呼应 GBW 常数） |
| 阻抗改造 | 输入/输出阻抗朝理想方向变（串联反馈提入阻、电压反馈降出阻） |

> 回望已学：共射电路的 Re（直流稳 Q）、运放的 Rf 网络（虚短伺候）、文氏桥稳幅、滞回窗口——**全是负反馈思想的不同马甲**。深度负反馈下 Af ≈ 1/F，运放电路增益只由电阻比决定，这就是运放精确的原因。

**负反馈的暗面——自激振荡**：反馈信号在某高频处相移累计到 180°，"负反馈"变"正反馈"，满足 |AF|≥1 → 电路自己振荡。对策：**频率补偿电容**（运放内置的 741/358 类；运放 datasheet "unity gain stable" 字样=跟随器都稳定）+ 输出容性负载串隔离电阻。顺带补个词：**相位裕度** = 反馈信号在累计到 180° 相移之前剩下的"安全余量"，余量太小就会自激——初学阶段记"按 datasheet 推荐电路用、输出别直挂大电容"即可。

## 2. 功率放大：最后一公里

> **这是什么**：电压放大完了，但驱动喇叭、电机这些"大胃口"还需要电流——功率放大（功放）就是"既有电压又有电流"的最后一级。
> **为什么需要它**：运放只能输出几十 mA，喇叭动辄几百 mA~几 A；"信号已经完美、就是推不动"的尴尬，全靠功放收尾。

信号链末端要驱动扬声器/电机/线圈——电压够了、**电流不够** → 功率级。

### 2.1 甲乙类推挽（分立方案）

```
VCC ──┬────────┐
      │c       │c
   [NPN 大管] [PNP 大管]   （MJE3055 / MJE2955 对管）
      │e       │e
      └──┬──输出──┬── 负载（喇叭/升压变压器）
   ──[偏置二极管×2]──  跨接两管基极之间
```
- NPN 推正半周、PNP 拉负半周，两管轮班 → "推挽"；
- **交越失真**：两管交接处（0.6V 死区）波形断崖 → 用两只二极管（或 Vbe 倍增电路）预先垫起 1.2V 偏置，让两管"交接班不断岗"——这就是"甲乙类"（介于全通甲类与纯推挽乙类之间）；
- > 工业案例：LX-750PLUS 的 HV 高压板用 **MJE3055/2955 对管推挽驱动升压变压器**，把几伏方波推到变压器初级，次级输出 1100V 耐压测试激励【高压安全警示：耐压输出端严禁触碰，维修必须先放电】。

### 2.2 集成功放（现代方案）

- **LM386**：单电源 4~12V、0.3~1W 增益 20~200 可调，驱动小喇叭/提示音——LX-750PLUS 提示音功放即它；
- 更大功率走 D 类功放（PWM 开关+LC 滤波，效率 90%+）——本质是"嵌入式 PWM+滤波"思想的音频版。

## 3. 电源变换拓扑速览（模电视角补完）

> **这是什么**：一张"电压变换家族图谱"——LDO、BUCK、BOOST、反激、推挽，从简单到复杂。什么时候翻：需要决定"用什么方式从 A 电压变到 B 电压"时，回来看这张图。

| 拓扑 | 结构 | 特点 |
|------|------|------|
| LDO | 可调管串联分压 | 已学（笔记04 电路基础），发热=压差×电流 |
| BUCK | MOS 高频开关 + 电感储能 + 续流 | 降压，效率 90%+ |
| BOOST | 同四件套重排 | 升压（3.7V→5V） |
| 反激（Flyback） | 开关管 + 高频变压器 | 隔离，多路输出，充电器/适配器内部就是它 |
| 推挽/半桥 | 对管驱动变压器初级 | 大功率隔离升压——HV 高压板路线 |

理解门槛：开关电源 = **负反馈（FB 分压采样）+ PWM 比较器 + 电感/变压器储能** 的组合——前三篇知识全部复用。

## 4. 组装：嵌入式模拟前端五段式（全体系收官）

> **这是什么**：把全书知识串成一条流水线——任何测量设备（万用表、示波器、温度采集器）的模拟电路都是这五段。这是模电笔记的"总装车间"，也是排查模拟故障的地图。

任何测量设备的模拟链，都是这五段（LX-750PLUS 完整对应）：

```
① 激励源 ──▶ ② 通道切换 ──▶ ③ 前端调理 ──▶ ④ ADC 前滤波 ──▶ ▶ MCU
(DDS/振荡器)  (继电器/模拟开关)  (放大/隔离/量程)  (抗混叠RC/二阶LPF)
```

各段设计要点清单：

| 段 | 要点 | 常用器件 |
|----|------|----------|
| ① 激励 | 频率/幅度程控；精密场合 DDS，简单场合 555/运放振荡 | AD9833、555、运放方波 |
| ② 通道 | 触点式（继电器，导通电阻 mΩ 级但慢/易损）vs 电子式（CD4051/DG211，快但带导通电阻） | 继电器、4051、DG211 |
| ③ 调理 | 量程匹配（分压/放大）、阻抗缓冲（跟随器）、隔离（光耦/隔离运放）、精密增益（仪表放大器——把差分放大做进一颗芯片的高精度运放组合） | TL071 缓冲、OP07/OP27 放大、INA128 |
| ④ 滤波 | 抗混叠 fc<采样率/2；共模干扰用差分 | RC、Sallen-Key |
| ⑤ ADC | 基准电压决定精度（REF3030 类基准 > VCC 直接供电）；前端运放输出阻抗低 | MCU 内置 ADC 或 ADS1115 |

**调试心法**：信号链从前往后逐段"打断点"——示波器逐段看波形，先定位坏在哪一段，再进段内查器件。模拟+数字混合板：模拟地和数字地**单点连接**，ADC 靠近模拟地布局。

## 5. 章节小结

- 负反馈四收益换一份增益；Af≈1/F；相位裕度不足→自激→补偿电容
- 推挽对管+偏置二极管消交越失真；LM386 单电源小功放；D 类=音频版 PWM
- 开关电源=负反馈+PWM+储能元件；反激/推挽走变压器实现隔离升压
- 五段式信号链（激励→通道→调理→滤波→ADC）是测量设备的通用骨架，逐段打断点调试

## 课后思考题

1. 为什么深度负反馈下增益"只看电阻比"？（Af≈1/F，F 由反馈电阻网络决定；运放开环增益越大，此近似越准）
2. 运放输出直接接长电缆（大容性）为什么会振荡？怎么救？（容性负载在输出阻抗上追加相移，吃掉相位裕度 → 串 50~100Ω 隔离电阻或改用容性负载稳定型号）
3. 推挽功放偏置二极管断开一根会怎样？（交越失真回归且更重，波形 0 附近断崖；偏置过热风险）——顺带回答：为什么偏置管常贴在功率管散热器上？（温度补偿，防热失控）
4. ADC 用 VCC 当基准 vs 用专用基准芯片，误差差在哪？（VCC 由 DC-DC/LDO 提供，±2% 且带纹波 → 换算成满量程 ±2% 系统误差；基准芯片初精度 0.05% 级且低温漂）
5. 回顾 LX-750PLUS：为什么绝缘测量段要用 TL071 缓冲 + OP27 放大两级，而不用一颗高阻运放搞定？（第一级要"不吃被测对象电流"——JFET 高阻缓冲；第二级要"低噪声低失调精确放大 μA 级泄漏电流"——分工不同，单颗难以兼得）
