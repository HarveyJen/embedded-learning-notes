# 01 · 放大电路基础：三极管与 MOS 管

> 目标：理解"放大"的本质，看懂分压偏置共射电路，会用示波器判断失真。

## 1. 为什么需要放大（嵌入式的出发点）

传感器输出往往非常微弱：热电偶 mV 级、麦克风 mV 级、电流采样几十 mV——而 MCU 的 ADC 满量程 3.3V。
**量程差几十~几百倍 → 必须放大**，否则 12 位 ADC 只用了低几位，分辨率全部浪费。

### 放大的本质（最重要的观念）

三极管/MOS **不产生能量**，它只是一个"阀门"：
**小信号（基极电流/栅极电压）控制大能量（电源经负载提供）**。
类比：水龙头手柄轻轻一转（小信号），水管里放出大量水（大电流）——能量来自水塔（电源），不是来自你的手。

## 2. 静态工作点 Q（放大的"立足点"）

> **这是什么**：Q 点（Quiescent point 静态工作点，Q 取自"安静的"）= 没有信号输入时，管子上直流电压电流的"落脚点"。
> **为什么需要它**：三极管只对"变化"响应，且只在线性区响应——必须先给它一个合适的直流"起点"，交流信号才能在这个起点上"起伏"而不越界。

三极管有三种状态：截止（不通）、放大（线性受控）、饱和（全通）。
**放大电路必须让管子预先"半开"**——这就是静态工作点 Q：

- 无输入信号时，先通过偏置电阻给管子设一个合适的直流电流/电压（比如集电极电流 1mA、Vce=3V，位于负载线中点附近——"负载线"是电源和电阻决定的、管子电压电流允许范围的连线，取中点就是往上下都留出最大摆动空间）；
- 小信号叠加在这个直流工作点上摆动，管子始终处于放大区 → 输出 = 放大后的信号。

类比：跷跷板中间的支点。Q 点太低（截止区）→ 信号负半周被削（**截止失真**，削底）；Q 点太高（饱和区）→ 正半周被削（**饱和失真**，削顶）。

**Q 点为什么会漂移**：温度升高 → β 和 Icbo 增大 → Ic 增大 → Q 点上移趋于饱和。解决方案见第 4 节发射极电阻。

## 3. 三极管放大三种组态

> **这是什么**：三极管三个脚，信号"从哪进、从哪出、谁是公共端"有三种接法（组态）——各有专长，像三种不同用途的变速箱。

| 组态 | 输入→输出 | 特点 | 用途 |
|------|-----------|------|------|
| **共射 CE** | 基极入、集电极出 | 电压电流都放大，增益高，**反相**，输入/输出阻抗中等 | 通用电压放大主力 |
| **共集 CC（射随器）** | 基极入、发射极出 | 电压增益≈1，**电流放大**，输入阻抗高、输出阻抗低 | 缓冲/阻抗匹配 |
| **共基 CB** | 发射极入、集电极出 | 电压增益高、不反相，高频特性好 | 高频电路（嵌入式少用） |

记忆：**"共 X" = X 极是输入输出的公共端**。

## 4. 经典电路：分压偏置共射放大（必须吃透）

文字描述电路连接：

```
VCC(12V) ──┬──[Rc 集电极电阻]──┬──── C2 ──> 输出 Vo
           │                   │c
          [R1 上偏置]        NPN 管 Q1
           │                   │e
基极 b ────┤                  [Re 发射极电阻]
           │                   │
          [R2 下偏置]          GND
           │
C1 <── 输入 Vi（经耦合电容进基极）
Re 两端并联旁路电容 Ce（可选）
```

各元件职责（口诀级记忆）：

| 元件 | 职责 |
|------|------|
| R1、R2 分压 | 固定基极电位 → 设定 Q 点（分压偏置名由此来） |
| Re | **直流负反馈稳 Q 点**：Ic↑ → Ve↑ → Vbe↓ → Ib↓ → Ic 回落，自动刹车（温度漂移的天敌） |
| Rc | 把"电流变化"翻译成"电压变化"（集电极电流流过 Rc 产生压降摆动）——没有 Rc 就没有电压输出 |
| C1/C2 耦合电容 | 隔直通交：只让交流信号进出，保住两侧的直流工作点互不干扰 |
| Ce 旁路电容 | 交流下把 Re 短路 → 交流增益大幅提高（直流靠 Re 稳 Q、交流不让它拖累增益） |

**信号从头到尾怎么走（脑子里演一遍）**：
- 第一步：直流上电——VCC 经 R1、R2 分压定出基极电位，产生基极电流，管子进入"半开"状态，Re 上建立起发射极电位，Q 点就位（此时输出端 C 点只是稳定直流电位，被 C2 挡着，输出为 0）；
- 第二步：小信号进来——Vi 经 C1 耦合，"骑"在基极直流电位上微微起伏，基极电流随之变化；
- 第三步：放大——基极电流的起伏被 β 倍放大成集电极电流起伏，流过 Rc 变成 C 点电位的大幅摆动（反相：基极电压升高 → 电流变大 → Rc 压降变大 → C 点电位变低）；
- 第四步：输出——C 点的"直流 + 交流"经 C2 隔直，只把交流摆动送给负载。若接了 Ce：交流起伏绕过 Re 直接落地，增益大幅提高；直流仍被 Re 稳住。

### 增益估算（结论版，够用）

- 带 Ce（旁路）：**Av ≈ −Rc / re**，其中 re ≈ 26mV / IE（re 是发射结的"内阻"，由发射极静态电流 IE 决定；26mV 来自 PN 结的物理常数，室温下记 26 即可；Av 是电压增益，负号 = 输出与输入反相）
  一步步算：IE = 1mA → re ≈ 26mV ÷ 1mA = 26Ω；Rc = 5.1kΩ → Av ≈ −5100 ÷ 26 ≈ −196（放大近 200 倍且反相！）
- 不带 Ce：**Av ≈ −Rc / Re**（Re 的负反馈牺牲增益换稳定）
- 射随器：Av ≈ 1

## 5. MOS 管放大（共源电路）

- 结构对应：共源（≈共射，反相放大）、共漏/源随器（≈射随器）、共栅（≈共基）；
- 核心差异：**栅极几乎不取电流**（电压控制），输入阻抗极高——适合直接接高阻传感器；
- 放大能力用**跨导 gm** 描述：gm = ΔId/ΔVgs（Δ 读"德尔塔"，表示"变化量"；即栅压每变 1V、漏极电流变多少，单位 mS 毫西门子——跨导就是"电压转电流的效率"）；
- 增益估算：**Av ≈ −gm × Rd**（Rd 为漏极电阻，角色同 Rc）。

> 工业案例对应：LX-750PLUS 中 2SC4672/2SC4678 做小信号放大，MJE3055/2955 做推挽功率输出——小信号放大管与功率管的分工。

## 6. 失真判断（示波器实操重点）

> **这是什么**：输出波形"不像输入"了（削顶、削底）就叫失真。示波器一看波形形状，就能反推 Q 点是高了还是低了——这是放大电路最重要的现场诊断技能。

| 现象 | 原因 | 处理 |
|------|------|------|
| 输出正半周削顶 | Q 点过高/输入过大 → 饱和失真 | 减小 Rc 或增大 Re，或减小输入 |
| 输出负半周削底 | Q 点过低 → 截止失真 | 减小 Re / 调分压抬高基极电位 |
| 大信号才失真、小信号正常 | 动态范围不足 | 正常现象，减小输入幅度 |
| 波形完整但幅度小 | 增益不够 / Ce 失效 | 查旁路电容 |

## 7. 故障排查与损坏特征

> **这是什么**：放大电路"没声、失真、发烫"三类毛病的对诊表——先量三个电极的直流电压，再对号入座。

- **无声/无输出**：耦合电容开路（电解老化常见）、管子 b-e 开路；
- **输出失真且 Q 点跑偏**：Re 虚焊（负反馈失效后温度漂移放大）、旁路电容短路；
- **烫**：Q 点设置在饱和区附近（偏置电阻取错值）；
- 万用表在路速判：测 Vbe≈0.6~0.7V（硅管导通）说明管子基本活着；Vce≈0 → 饱和/击穿；Vce≈VCC → 截止/开路。

## 8. 章节小结

- 放大 = 小信号控制电源能量，管子是"阀门"
- Q 点是放大区里的立足点：截止削底、饱和削顶
- 分压偏置共射：R1/R2 定 Q、Re 稳 Q、Rc 出电压、C 隔直、Ce 提增益
- 三组态：共射放大、共集缓冲、共基高频
- 增益结论：Av ≈ −Rc/re（带旁路）或 −Rc/Re（不带）；MOS：Av ≈ −gm·Rd

## 课后思考题

1. 为什么射随器电压增益≈1 还有人用？（电流/功率放大 + 高入低出阻抗变换——传感器高内阻直接驱动低阻负载会衰减，加一级缓冲解决）
2. Re 越大 Q 点越稳，为什么不全用大 Re？（Ve 占用电压空间，Vce 余量变小，动态范围缩水；且交流增益若不旁路会降为 −Rc/Re）
3. 温度从 25℃ 升到 75℃，没有 Re 的共射电路 Q 点会怎样？（Ic 显著增大 → Q 点移向饱和，信号正半周先失真）
4. 用 3.3V 单电源还能搭共射放大吗？（可以，VCC=3.3V，但动态范围只有 ~3V，Q 点要放中间，Re/Rc 按比例缩小）
