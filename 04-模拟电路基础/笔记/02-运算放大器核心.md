# 02 · 运算放大器核心：虚短虚断与基本电路

> 运放是现代模拟设计的"乐高积木"——分立三极管放大如今主要留给功率级，信号调理 90% 用运放。
> 目标：掌握虚短虚断分析法，四大基本电路信手拈来，会按参数选运放。

## 1. 运放是什么

> **这是什么**：运放（运算放大器，Op-Amp）是把一大堆三极管"集成"进一颗芯片的高增益放大器——你不用操心内部电路，只管三个引脚：同相输入 +、反相输入 −、输出 Vo。
> **为什么需要它**：它把"设计放大电路"从"算一堆三极管偏置"变成"接两个电阻定倍数"——像乐高积木，模块化、可预测、随便拼。

**集成的高增益差分放大器**（差分 = 只放大"+ 端与 − 端的电压差"）：两个输入端（同相 +、反相 −）、一个输出端。

```
        V+（正电源）
         │
Vi+ ──▶ (+) \
              \ ──── Vo
Vi− ──▶ (−) /          （内部把差值 (V+ − V−) 放大 A 倍输出）
         │
        V−（负电源或地）
```

理想运放三大假设（分析所有电路的起点）：
1. **开环增益 A → ∞**（A = 不接反馈时的放大倍数，真实运放十万级；"开环" = 输出不送回输入的状态）；
2. **输入阻抗 → ∞**（输入端不吸电流——像电压表测电压，不"抽走"信号）；
3. **输出阻抗 → 0**（输出是理想电压源，带什么负载都不掉压）。

## 2. 虚短与虚断（分析法灵魂）

> **这是什么**：两条"心算规则"——虚断：两个输入端不吸电流，就当它们悬空；虚短：负反馈下两个输入端电压几乎相等，就当它们被短接。
> **为什么需要它**：它是运放分析的"九九乘法表"，下面四大电路的公式全部由这两条两步推出来——不用背公式，会推才是真的会。

- **虚断**：输入端不取电流（假设 2）。→ 电阻串联分压计算不受运放干扰。
- **虚短**：Vo = A(V+ − V−)，A 是十万级巨数，而 Vo 最大不过电源轨 → **V+ − V− ≈ 0**，两输入端电压几乎相等，像短接但并非真短路（假设 1）。
- 使用前提：**运放工作在线性区（必须负反馈！）**。开环或正反馈时虚短不成立（见笔记04 比较器）。

类比：负反馈像一个每秒百万次的自动调节员——输出稍高就压回来、稍低就抬上去，最终把两个输入端"伺候"得几乎相等。虚短就是这个伺候的结果。

## 3. 四大基本电路（必须能默画+推导）

> **这是什么**：四种"电阻 + 运放"的标准搭配——反相放大、同相放大、跟随缓冲、加减运算。90% 的传感器调理电路都是它们的直接组合，必须练到"闭眼能画、张口能给公式"。

### 3.1 反相放大器

```
Vi ──[Rin]──┬──(−) 
            │   [Rf 从输出反馈回 − 端]
(+) ── GND  │
Vo <────────┘（输出端）
```

推导：虚断 → Rf 与 Rin 串联分压且 − 端电位 = + 端 = 0（**虚地**）；虚短 → V−=0。
`Vi/Rin = −Vo/Rf` → **Av = −Rf/Rin**

- 反相（负号）、输入阻抗 = Rin（不高）；
- **代入算例**：传感器给 0.1V，Rin = 10kΩ、Rf = 100kΩ → Av = −100k/10k = −10，输出 Vo = 0.1V × (−10) = −1V（若板上只有单电源、出不来负压，输出会被"削"在 0V——正信号想放大后仍是正的，用同相放大，或见第 5 节加偏置）；
- 取值习惯：Rin=Rf=10k → −1 倍（反相器）；Rf=100k/Rin=10k → −10 倍。电阻别用太大（>1M 噪声/偏流误差明显）。

### 3.2 同相放大器

```
Vi ──(+) 
(−) ──┬──[Rg]── GND
      └──[Rf]── Vo
```

推导：虚断 → Rf/Rg 分压把 Vo 的一部分送回 − 端；虚短 → V− = Vi。
`Vi = Vo × Rg/(Rg+Rf)` → **Av = 1 + Rf/Rg**

- **不反相、输入阻抗极高**（信号直进 + 端，不吃信号源电流）——高内阻传感器首选；
- **代入算例**：想放大 11 倍 → 取 Rg = 1kΩ、Rf = 10kΩ，Av = 1 + 10k/1k = 11；输入 0.3V → 输出 0.3 × 11 = 3.3V，正好顶满 3.3V ADC 满量程（实战中要留裕量，实际取增益 8~10 倍更稳）；
- 最小增益 1 倍（Rf=0，即跟随器）。

### 3.3 电压跟随器（同相放大 Rf=0 的特例）

`Vo = Vi`，电压增益 1，但**输入阻抗极高、输出阻抗极低**。
用途：**缓冲**——高阻信号源与低阻负载之间的"忠诚传令兵"。
> 工业案例：LX-750PLUS 用 8 片 TL071（JFET 输入高阻运放）做缓冲，防止测量电路给被测线束"添负载"影响精度——跟随器价值的真实体现。

### 3.4 加法器与差分放大器

**反相加法器**（多路信号在虚地叠加）：
`Vo = −Rf × (V1/R1 + V2/R2 + ...)` —— 多传感器信号合成、直流偏置叠加。

**差分放大器**（放大"两点的差"、抑制"共同的干扰"）：
```
V1 ──[R1]──(−)──[R2]── Vo
V2 ──[R3]──(+)──[R4]── GND     （R1=R3, R2=R4 时）
Vo = (R2/R1) × (V2 − V1)
```
用途：**电流采样**——采样电阻两端微小压差放大后进 ADC；抑制共模干扰（两根线一起混进的噪声被抵消）。

## 4. 实际运放的"不理想"（选型必看参数）

> **这是什么**：真实运放不是理想运放——有失调（0 进不为 0 出）、有偏流、有带宽限制。选型 = 想清楚你的应用"最怕哪种不理想"，就挑那个参数最好的型号。

| 参数 | 含义 | 什么时候在意 |
|------|------|--------------|
| 失调电压 Vos | 输入为 0 输出不为 0 的等效输入误差（μV~mV） | 直流微弱信号放大（**OP07 存在的意义：Vos 低至 μV 级**） |
| 失调温漂 | Vos 随温度变化 | 高精度仪器 |
| 输入偏置电流 | 输入端吸的微小电流（fA~nA） | 高阻源、大电阻反馈（**TL071 JFET 输入偏流极小**） |
| 增益带宽积 GBW | 增益×带宽≈常数 | 放大 100 倍还要 100kHz 带宽 → 至少 10MHz GBW |
| 压摆率 SR | 输出最大变化速率 V/μs | 大幅度高频信号（方波变梯形=SR 不够） |
| 噪声 | 输入噪声密度 nV/√Hz | 前置放大第一级（**OP27 低噪声**） |
| 单/双电源 | 负电源需求 | 见第 5 节 |

**GBW 算例**：GBW（增益带宽积）= 增益 × 可用带宽 ≈ 常数。比如 GBW = 1MHz 的运放：做 10 倍放大 → 带宽 ≈ 1MHz ÷ 10 = 100kHz；做 100 倍 → 只剩 10kHz。若信号只有几 kHz、要 100 倍增益，它够用；若要放大 100kHz 的信号还要 100 倍，就得换 GBW ≥ 10MHz 的型号。

### 常见运放速查（呼应 BOM）

| 型号 | 定位 | 典型用途 |
|------|------|----------|
| LM358 | 便宜双运放（5V 单电源） | 一般性放大/比较，精度一般 |
| TL071/072 | JFET 高阻、低偏流 | 缓冲、音频 |
| OP07 | 超低失调 | 直流精密放大 |
| OP27 | 低噪声+低失调 | 仪器前置放大 |
| AD637/AD736 | 真有效值转换专用 IC | 交流测量（LX-750PLUS 核心） |
| 轨到轨（Rail-to-Rail）系列 | 输入输出可到电源轨 | 3.3V 单电源低压系统首选 |

## 5. 单电源 vs 双电源（嵌入式最常踩的坑）

> **这是什么**：运放的输出只能在"电源轨之间"摆——双电源（如 ±6V）输出能正能负，单电源（0~3.3V）输出最低只能贴地。放大"有正有负"的交流信号时，这个差别就是新手第一大坑。

运放输出**只能在电源轨之间摆**。放大交流信号（有正有负）：
- **双电源**（±6V、±12V）：输出天然有负半周能力——LX-750PLUS 板上有 79L06 专门产生 **−6V** 给运放，就是这个原因；
- **单电源**（0/3.3V）：输出最低到 0，负半周直接削掉 → 方案：
  1. 把输入**抬到中点**（VREF=1.65V）：信号叠加在直流偏置上摆动，输出后用隔直电容取出交流，或 ADC 双边采样软件去偏置；
  2. 选"轨到轨输入输出"运放，尽量贴近 0V/3.3V。

**检查清单**：单电源电路输出"只有上半波/一直贴地" → 90% 是忘了加 VREF 中点偏置。

## 6. 章节小结

- 虚断（不吸电流）+ 虚短（两端等电位，前提是负反馈）= 分析一切运放电路
- 四大电路：反相 −Rf/Rin（虚地）、同相 1+Rf/Rg（高入阻）、跟随（缓冲）、差分（抗共模/电流采样）
- 选型五参数：Vos、偏流、GBW、SR、噪声；OP07 管失调、TL071 管高阻、OP27 管噪声
- 单电源放大交流必须加 VREF 中点偏置

## 课后思考题

1. 虚短为什么在比较器电路中不成立？（比较器无负反馈、开环工作，输出只到饱和轨，A×ΔV 不可能被拉回有限值）
2. 反相放大器输入阻抗为什么是 Rin 而不是"极高"？（信号经 Rin 进入虚地节点，虚地≈0V，源看到的就是 Rin 接地）
3. 100mV 传感器接 ADC，用 10 倍同相放大，3.3V 单电源，电阻怎么取、要不要偏置？（Rf=27k/Rg=3.3k≈9.2 倍；信号是直流单向则不用交流偏置，但要确认运放输入输出范围覆盖 0~1V；若含负半周则加 VREF）
4. GBW=1MHz 的运放做 100 倍放大，带宽还剩多少？（约 10kHz——超过此频率增益开始滚降，这就是"增益带宽积是常数"的工程含义）
