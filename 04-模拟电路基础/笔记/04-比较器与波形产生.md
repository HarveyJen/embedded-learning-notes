# 04 · 比较器、振荡器与波形产生

> 两大主题：**判定**（比较器：电压比大小给 0/1 结论）与**产生**（振荡器：无中生有造波形）。
> 嵌入式关联：阈值检测/欠压报警用比较器；时钟、提示音、示波器校准用振荡器；高配方案用 DDS 芯片。

## 1. 比较器：运放的"放弃线性"用法

> **这是什么**：比较器是"只回答大小、不负责放大"的器件——+ 端电压比 − 端高，输出顶到高；反之压到低。输出永远只有两个极端，像裁判只吹哨不解说。
> **为什么需要它**：欠压报警、过流保护、信号整形、判断传感器有没有越限——嵌入式里一切"过阈值就动作"的场合都是它。

**比较器 = 开环工作的运放**：不做放大，只回答"+端大还是 −端大"——
V+ > V− → 输出顶到正轨；V+ < V− → 输出压到负轨/地。

**虚短在这里不成立**（没有负反馈伺候），这正是它与放大电路的本质区别。

### 比较器 vs 运放（选型区别）

| | 运放 | 比较器 |
|---|------|--------|
| 工作区 | 线性（负反馈） | 开关（开环） |
| 内部补偿 | 有（内置电容防负反馈自激，代价是响应慢） | 无（求快，响应 ns~μs 级） |
| 输出级 | 推挽模拟输出 | 常为**集电极开路 OC**——**必须外接上拉电阻** |
| 典型型号 | LM358/TL071 | **LM311**、LM393（双）、LM339（四） |

> 工业案例：LX-750PLUS 用了 **11 片 LM311** 做"导通/断路"阈值判定——每路通道一个比较器，实测电阻过阈值立刻翻转电平，MCU 只管收结论。OC 输出配合上拉，还能方便线与并联。

### 过零比较与欠压检测

```
          VCC
           │
Vi ──(+)   [R上拉]        （LM311 OC 输出）
      \    │
       ────┴── Vo
      /
Vref ──(−)
```
工作过程（一步步演）：Vi 从低往高爬——
- 第一步：Vi < Vref 时，+ 端电位低于 − 端，输出压到低；
- 第二步：Vi 越过 Vref 的那一瞬间，+ 端反超，输出立刻翻到顶（OC 输出经上拉电阻拉到 VCC）；
- 第三步：Vi 回落再次低于 Vref 时，又翻回低电平。整个电路把"模拟量的比较"变成"数字结论"。
欠压检测：Vi 接分压的电池电压，Vref 接基准（TL431，一种便宜的可调基准芯片，输出一个稳定电压供比较用），低于阈值 → 输出翻转 → MCU 中断/点灯。

### 滞回比较器（施密特）：抗噪声必备

**问题**：输入信号带噪声，在阈值附近抖动 → 输出反复翻转（振荡）。
**解决**：加正反馈（Rf 从输出回 + 端），让翻转阈值随输出状态移动，形成两个门限：

```
VTH = Vref × (1 + R1/Rf) − Vo_LOW × R1/Rf   （上限阈值）
VTL = VTH − ΔV    （ΔV = 滞回窗口，由 Rf/R1 决定）
```

**逐符号解释**：VTH/VTL 是"翻转"的上/下两个门限（Threshold 阈值）；Vref 是基准电压；R1 是输入端串联电阻、Rf 是从输出拉回 + 端的正反馈电阻；Vo_LOW 是输出低电平时的电压（OC 输出 ≈ 0V）；ΔV（德尔塔 V）= 两个门限的间距，即滞回窗口宽度——窗口越宽抗噪越强、但翻转越"迟钝"。

**代入算例**：Vref = 2.5V、R1 = 1kΩ、Rf = 100kΩ（R1/Rf = 0.01）、Vo_LOW ≈ 0V → 按公式 VTH ≈ 2.5 × 1.01 ≈ 2.53V；窗口 ΔV 在几十 mV 量级。信号在门限附近 ±几十 mV 内怎么抖，输出都纹丝不动——窗口就是"防抖缓冲带"。

效果：输入在窗口内怎么抖，输出都纹丝不动；必须**穿越整个窗口**才翻转。
类比：空调温控——25 度开空调、23 度关，避免在 24 度反复启停。

## 2. 方波发生器（运放/比较器 + RC）

> **这是什么**：把滞回比较器的输出经 RC 接回输入，电路就"自问自答"永动起来，源源不断输出方波——不需要任何信号源，这是"振荡器"最简单的形态。

结构：滞回比较器 + RC 定时（输出经 R 给 C 充电，C 上电压回送输入端，到达阈值翻转，如此往复）。
`f ≈ 1/(2.2RC)`（对称滞回时；f 单位 Hz，R 单位 Ω，C 单位 F，2.2 是由阈值和充放电曲线推出的系数）——输出稳定方波，C 上是三角波（充电曲线）。
**代入算例**：R = 10kΩ、C = 0.1μF → RC = 10000 × 0.0000001 = 0.001s → f ≈ 1 ÷ (2.2 × 0.001) ≈ 455Hz。想改频率只动 R 或 C：R 加 10 倍，频率就降 10 倍。
用途：低成本时钟、提示音源、给 ADC 提供测试信号。

## 3. 正弦振荡：文氏桥（RC 振荡经典）

> **这是什么**：让电路自己"唱"出干净正弦波的经典电路——放大器 + 一套"只对某个频率手下留情"的选频网络，两者互相成就，选出哪个频率就唱哪个音。

**自激振荡两条件**（背下来）：
- 幅度条件：环路增益 |A×F| = 1（起振时略 >1，稳定后=1）；
- 相位条件：环路总相移 = 360°（反馈回来"恰到好处地火上浇油"）。

**文氏桥** = 同相放大器（增益设为 1+Rf/Rg ≈ 3）+ RC 串并联选频网络（在 f=1/(2πRC) 处相移恰好 0°、反馈系数 1/3）→ 两条件同时满足，输出干净正弦。
起振后幅度会涨 → 用热敏/二极管**稳幅**，|A| 回落到 3。
频率示例：R=10k、C=16nF → f≈1kHz。

> LC 振荡（电容三点式等）用于高频（MHz 级），嵌入式阶段了解即可。

## 4. 555 定时器（模电入门的"瑞士军刀"）

> **这是什么**：一颗 8 脚的"万能节奏芯片"——内部自带比较器、触发器和分压电阻，外接两三个阻容就能造方波、延时、PWM。几毛钱一颗，诞生 50 多年还在量产。

内部：两比较器 + RS 触发器 + 放电管 + 三只 5kΩ 分压电阻（名字由来：1/3、2/3 VCC 两阈值）。

| 模式 | 接法 | 输出 | 用途 |
|------|------|------|------|
| 无稳态（astable） | 2 只电阻 + 1 电容 | 连续方波 | 呼吸灯、蜂鸣音、时钟 |
| 单稳态（monostable） | 1 电阻 + 1 电容 + 触发脚 | 按触发输出定宽脉冲 | 消抖、延时 |
| 频率公式 | f ≈ 1.44/((R1+2R2)·C) | 占空比 = (R1+R2)/(R1+2R2) | — |

优点：便宜、皮实、驱动力强（200mA）；缺点：频率精度/稳定性一般（±几%，受 VCC 影响）——精密场合用 MCU 定时器或专用晶振时钟。

## 5. DDS：现代方案（软件造波形）

> **这是什么**：DDS（Direct Digital Synthesis 直接数字频率合成）= 用数字手段"查表"生成波形——芯片里存着一张正弦表，按设定步进逐点读出、经 DAC 输出。频率精度高，改频率就像改一个数字。

**DDS（直接数字频率合成）**：相位累加器查正弦表 → DAC 输出——一颗芯片输出任意波形，频率精度毫赫兹级，MCU 用 SPI 改一个寄存器就换频率。
代表芯片：**AD9833**（正弦/三角/方波，25MHz 主频，SPI 接口）。
> 工业案例：LX-750PLUS 用 **AD9833 做激励源**给线束注入测试信号——比 RC/文氏桥灵活得多（频率程控、扫频测试）。这就是"传统振荡器 → 数字合成"的换代方向，也说明模电与嵌入式不是替代而是分工。

## 6. 故障排查

> **这是什么**：比较器/振荡电路"不翻、狂抖、不起振"的疑凶速查表——照着从上往下对症状。

| 现象 | 疑凶 |
|------|------|
| 比较器输出恒高/恒低 | OC 输出忘了上拉；输入端接反；阈值设置在信号范围外 |
| 阈值附近输出疯狂抖动 | 没加滞回 → 补正反馈电阻 |
| 文氏桥不起振 | 增益 <3（Rg 太大）；RC 网络参数错；稳幅太强压死起振 |
| 555 频率漂移 | 电阻电容精度差；VCC 波动（换稳压或改 MCU 定时器方案） |

## 7. 章节小结

- 比较器=开环运放，OC 输出必上拉；LM311/LM393/339 常用
- 滞回=正反馈造双阈值，抗噪核心手段（空调温控类比）
- 振荡两条件：|AF|≥1 且相移 360°；文氏桥增益 3 + RC 选频
- 555：1.44/((R1+2R2)C)，三模式；精密波形走 DDS（AD9833）
- 造波形三层方案：RC/555（粗）→ MCU 定时器+PWM（中）→ DDS（精）

## 课后思考题

1. 比较器能不能当运放用？运放能不能当比较器用？（比较器无补偿开环不稳、不能线性放大；运放可当低速比较器，但响应慢且有相位反转风险——应急可以，正式设计各用各的）
2. 滞回窗口取大取小各有什么代价？（窗口大→抗噪强但判定精度差；窗口小→精度高但易抖动；按噪声幅度留 2~3 倍裕量）
3. 为什么 555 精度差而晶振+分频精度高？（555 靠 RC 充电，R/C 温漂大；晶振靠机械谐振，Q 值极高、稳定性 ppm 级）
4. DDS 输出为什么要后接低通滤波？（相位累加查表输出是台阶状阶梯波，含时钟频率谐波，低通平滑取基频）
