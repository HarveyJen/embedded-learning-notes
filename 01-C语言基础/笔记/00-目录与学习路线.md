# C 语言学习笔记 · 目录与学习路线

> 面向嵌入式方向的 C 语言系统笔记
> 定位：自学入门笔记 + 复习工具书——各篇按"可独立自学"标准整理（有定义、有算例），卡壳或想学更细时再看视频课与各篇文末的深入资料
> 配套资料：B站「比特鹏哥」C语言完整版 + 浙大翁恺 MOOC + 《C Primer Plus》
> 嵌入式补充：embeddedpathashala《C Programming for Embedded Systems》

**这份文件是什么**：它是整个笔记库的"地图"。下面列出了 13 篇笔记分别讲什么、按什么顺序学、每一阶段学到什么程度算过关。第一次使用建议：先花 10 分钟通读本页，再按"学习路线"一节开始第 01 篇。

**小白先看这里——几个会反复出现的词**：
- **嵌入式**：把计算机"藏"进设备里为其专门服务，如电饭煲、遥控器、汽车里的控制板。跑程序的那颗小芯片叫单片机（MCU），常见的有 STM32 系列。
- **固件**：烧录（"下载"）进单片机 Flash 芯片里的程序，相当于设备的"灵魂"。
- **RAM / Flash**：可以理解为芯片里的"内存条"（RAM，断电丢数据）和"硬盘"（Flash，断电保留程序）。
- 遇到不认识的术语，查根目录《00-嵌入式术语小词典》。

## 二、学习路线（约 4~6 周，每天 1.5~2 小时）

### 阶段一：初阶语法（第 1~2 周）
对应笔记 01~05，鹏哥视频 P1~P60 左右。

- [ ] 环境搭建完成，跑通第一个程序
- [ ] 变量、常量、数据类型（理解补码存储）
- [ ] 分支与循环（能写：判断素数、九九乘法表、求最大公约数）
- [ ] 函数（能写：递归求阶乘/斐波那契）
- [ ] 数组与字符串（能写：冒泡排序、二分查找、自己实现 strlen/strcpy）

**阶段验收**：不看书写出「三子棋」或「扫雷」小程序。

### 阶段二：进阶核心（第 3~4 周）
对应笔记 06~09 与 12 篇，鹏哥视频进阶部分（数据的存储、指针进阶、结构体、动态内存、文件、预处理）。

- [ ] 指针完全理解（能画出每道题的内存示意图）
- [ ] 结构体内存对齐能口算 sizeof
- [ ] 理解内存分区，规范使用 malloc/free
- [ ] static/const/volatile 三大关键字能脱稿讲清
- [ ] 文件操作（fgets+sscanf 解析配置/日志；fwrite/fread 二进制记录读写）

**阶段验收**：不看书实现「通讯录」（动态内存版，含增删改查、排序、保存）。

### 阶段三：嵌入式衔接（第 5 周）
对应笔记 10~11。

- [ ] 位运算宏：置位/清零/翻转/检查
- [ ] 手写寄存器映射结构体、模拟 GPIO 操作
- [ ] 单链表增删改查 + 反转
- [ ] 状态机写法（switch-case 版本）

**阶段验收**：读得懂 STM32 标准库源码中寄存器操作与结构体定义。

## 三、嵌入式 C 面试高频考点速览

1. `volatile` 的作用和三个使用场景（中断共享变量、寄存器、多线程共享）
2. `static` 的三种用法（局部变量 / 全局变量 / 函数）
3. `const` 修饰指针的区分（`const int *p` vs `int * const p`）
4. 结构体内存对齐规则，手算 sizeof
5. 大小端判断（联合体 / 指针法）
6. 位操作宏：置位、清零、翻转、判断某位
7. 指针与数组区别；`sizeof(arr)` 与 `sizeof(p)`
8. 补码：`-1` 的 8 位表示；`unsigned char` 的回绕
9. malloc/free 注意事项，内存泄漏
10. 函数指针与回调函数的用法
