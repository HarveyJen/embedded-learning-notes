# 06 · 指针（重中之重）

> 指针 = 嵌入式的命根子。寄存器操作、回调、链表、RTOS 全靠它。
> 学习方法：**每道题画出内存示意图**（地址 + 内容 + 指向关系）。

**这一篇讲什么**：程序里所有数据都住在内存里，内存的每个字节都有编号（地址）。**指针就是一个存"地址"的变量**——它本身不装数据，装的是"数据在哪里"。类比：指针是一张写着门牌号的纸条，顺着纸条找上门，才能看到屋里的人。嵌入式为什么离不开它？因为操作芯片外设，本质就是"往某个固定地址读写数据"——没有指针寸步难行。

## 1. 内存与地址

**这是什么**：先把"内存长什么样"想清楚。把内存想象成一栋超大楼房：**每个字节是一个房间，房间号就是地址**。变量（int、char 等）是房间里的家具，可能占 1 个房间（char），也可能占 4 个连号房间（int）。而"指针"，就是写有房间号的纸条。

内存像一排带编号的房间：**地址**是房间号，**变量**是房间里的东西。
- 每个字节有唯一地址；32 位系统地址是 32 位 → 指针大小恒为 **4 字节**；64 位 PC 上是 8 字节（与类型无关）；
  - 为什么？地址本身也是数字，要用二进制表示。32 位二进制能表示 2^32 个不同编号（约 42.9 亿个房间），所以"存一个房间号"固定需要 32 位 = 4 字节。**不管指向的是 int、char 还是 double，纸条大小都一样**——变的只是"这号房间里有几个字节的货"；
- 两个符号记牢（本章出现频率最高）：
  - `&x`：取地址——"把 x 家的门牌号抄下来"；
  - `*p`：解引用——"按纸条上的门牌号找上门，看/动屋里的东西"。
- 取地址：`&x`；解引用（按地址取内容）：`*p`。

**这段代码要做什么**：让指针 p 记下 a 的地址，然后"隔空"修改 a 的值。

```c
int a = 10;
int *p = &a;      // p 存的是 a 的地址
*p = 20;          // 等价 a = 20
printf("%d %p %p\n", a, (void*)p, (void*)&a);
```

运行逻辑逐段拆解：
- `int *p`：声明一个指针，指向的类型是 int——意思是"这张纸条上记的门牌，屋里住的是 int"；
- `&a`：抄下 a 的门牌号，存进 p；
- `*p = 20`：顺着 p 里的门牌号找上门，把屋里改成 20——改的就是 a 本尊，所以之后打印 a 是 20。

## 2. 指针变量与类型

**这是什么**：既然纸条都一样大，为什么还要区分 `int *`、`char *`？因为类型告诉两件事：**解引用时一次读几个字节**、**指针 +1 跳过几个字节**。类比：同样拿着"1000 号房间"的纸条，仓库管理员按你开的提货单规格发货——int 单一次搬 4 格，char 单一次搬 1 格。

- 指针变量本身也是个变量，有自己的地址（`&p`）；
- 指针的**类型决定了：解引用时读几个字节、+1 跨多少字节**。

```c
int    *pi = (int *)0x1000;    pi + 1 → 0x1004   // +4
char   *pc = (char*)0x1000;    pc + 1 → 0x1001   // +1
double *pd = (double*)0x1000;  pd + 1 → 0x1008   // +8
```

`void *`：万能指针，只存地址、不知道大小，使用前必须转回具体类型（`malloc` 返回值就是 `void*`）。
白话：`void*` 是一张"没写货物规格的提货单"——门牌号有，但不知道屋里住的是什么、有几个字节，所以不能直接 `*p` 读写，必须先转成具体类型（相当于补上规格）。它的好处是"什么地址都能装"，常用在通用接口里（如 malloc 不知道你要装什么，统一返回 void*，你自己转）。

## 3. 野指针与 NULL

**这是什么**：**野指针 = 写着乱七八糟/过期门牌号的纸条**。按它找上门，可能进的是别人家（改坏别人的数据），可能是拆迁的空地（程序崩溃）。它是 C 程序里最危险的东西之一，而且出事点往往离闯祸点很远，极难排查。三个来源：
1. **未初始化**：`int *p; *p = 1;`（指向随机地址，可能写坏任意数据）；
2. **指向已销毁的局部变量**（函数返回栈变量地址）；
3. **free 之后继续用**。

规范：定义指针**立刻初始化**，不确定指向就先 `= NULL`；使用前判空；free 后立即置 NULL。

`NULL` 白话：一个专门的"空号"，约定俗成表示"这张纸条故意留白，别按它找门"。判空就是用纸条前先看一眼是不是空号。

**这段代码要做什么**：演示指针的"先判空、再使用"安全套路。

```c
int *p = NULL;
if (p != NULL) { *p = 10; }
```

## 4. 指针与数组

**这是什么**：数组是连号储物柜，数组名在大多数场合就等于"第一格柜子的门牌号"。所以指针和数组天生一家——拿着首格门牌号 + 偏移量，就能走遍所有柜子。

**这段代码要做什么**：验证"数组名 ≈ 首元素地址"，以及 a[i]、*(a+i) 两种写法完全等价。

```c
int a[5] = {1,2,3,4,5};
int *p = a;              // a 退化为首元素地址

// 四种等价写法
a[i]  *(a+i)  p[i]  *(p+i)
```

为什么等价：`a[i]` 的本质就是"从 a 的地址出发偏移 i 个元素"= `*(a + i)`。p 存的也是这个首地址，所以 `p[i]`、`*(p+i)` 一样成立。注意 `*` 和 `+` 的优先级：`*a+1` 是"先取 a[0] 再加 1"，`*(a+1)` 才是 a[1]。

指针运算：
- `p+1`：前进一个元素；`p2-p1`：两指针间元素个数（必须指向同一数组才有意义）；
  - 注意"前进一个元素"不是"前进一个字节"：int 指针 +1 就是 +4 字节（见第 2 节）；
- 遍历惯用法：

**这段代码要做什么**：用"移动指针"的方式遍历数组并打印——q 从首格开始，每轮打印当前格再前进一格，直到走出数组。

```c
for (int *q = a; q < a + 5; q++) printf("%d ", *q);
```

**指针数组 vs 数组指针（必考）**

**这是什么**：两个名字只差一个字，意思天差地别。拆词法：**指针数组**=主体是数组，每个格子里装的是指针（"一柜子纸条"）；**数组指针**=主体是指针，指向一整个数组（"写着整排柜子起始号的纸条"）。看 `[]` 和 `*` 谁跟 p 先结合：`int *arr[5]` 中 arr 先和 [5] 结合是数组；`int (*p)[5]` 括号强行使 p 先和 * 结合是指针。

```c
int *arr[5];      // 指针数组：5 个 int* 变量（字符串表常用于菜单/命令解析）
int (*p)[5];      // 数组指针：指向"含5个int的数组"，&a 的类型
```

```c
// 指针数组典型应用：字符串命令表（嵌入式 CLI 雏形）
const char *cmds[] = { "help", "version", "reboot" };
for (int i = 0; i < 3; i++)
    if (strcmp(input, cmds[i]) == 0) run(i);
```

```c
// 数组指针访问二维数组
int m[3][4];
int (*p)[4] = m;          // p 指向第一行
printf("%d\n", p[1][2]);  // 等价 m[1][2]
```

## 5. 二级指针

**这是什么**：纸条上写的不是货物位置，而是**另一张纸条的存放位置**。`int **pp` 意思是：pp 指向的地方，住着一个"指向 int 的指针"。类比：你不知道客户家在哪，但你知道"通讯录放在抽屉里"——打开抽屉（第一次解引用）找到写着客户地址的纸条，再按纸条找（第二次解引用）才见到客户。

```c
int a = 10;
int *p = &a;
int **pp = &p;      // pp 存 p 的地址

*pp  == p    (&a)
**pp == a    (10)
```
读法：`*pp` 拆开第一层——"抽屉里的东西"= 纸条 p；`**pp` 拆开第二层——"按纸条找到的客户"= a。两个 * 就拆两层。

典型用途：函数内**修改指针本身**：

**这段代码要做什么**：在函数内部分配内存，并让函数外面的指针指向它——直接传指针做不到（传的是复印件），必须传"指针的地址"。

```c
void alloc(int **pp, int n) { *pp = malloc(n * sizeof(int)); }
int *arr = NULL;
alloc(&arr, 10);        // 传指针的地址才能改变指针
```
拆解：若只传 `arr`（int*），alloc 拿到的是复印件，改复印件无效；传 `&arr`（int**），函数内 `*pp` 就是 arr 本尊，`*pp = malloc(...)` 等于"arr = malloc(...)"在函数外生效——还是第 3 节那句口诀：**想改变谁，就传谁的地址**，这里想改变的是"指针"，所以要传"指针的地址"。

## 6. const 与指针（面试必考）

**这是什么**：const 是"封条"。贴在货物上（*p）还是贴在纸条上（p），效果完全不同，这是面试超高频考点。类比：const 贴货物上=这箱货不能换（但你可以去看别的柜子）；贴纸条上=这张纸条不能改写门牌（只能盯这一家，但这家货随便动）。

**这段代码要做什么**：展示 const 三种贴法的读法与限制。

```c
const int *p;        // 指向常量的指针：*p 不能改，p 能改  —— 保护数据
int * const p;       // 常量指针：p 不能改，*p 能改    —— 锁定指向
const int * const p; // 都不能改
```
口诀：**const 在 `*` 左边 → 内容不可改；在 `*` 右边 → 指向不可改**。
读法技巧：从右往左念——`const int *p` 念作"p 是指针，指向 int，const 的"（货物被封）；`int * const p` 念作"p 是 const 的指针，指向 int"（纸条被封）。

嵌入式扩展：`const` 全局数据通常放 **Flash（ROM）**，省 RAM —— 查表、字库、菜单文本一律加 const。

## 8. 字符串：数组 vs 指针

**这是什么**：两种"装字符串"的方式长得像，性质完全不同：`char arr[]` 是把货复制一份到自己家（可改）；`char *ptr` 只是一张纸条，指向只读仓库里的原件（货不能改，但纸条可以改指别家）。

**这段代码要做什么**：对比两种写法分别能不能改内容、能不能改指向。

```c
char arr[] = "hello";     // 栈/数据区，内容可改：arr[0]='H' √
char *ptr  = "hello";     // 指向常量区，内容不可改：ptr[0]='H' ×（段错误）
                           // 但 ptr 本身可重新指向别处
```

## 9. 嵌入式专属：指针访问寄存器（核心）

**这是什么**：本篇最重要的实战应用，也是整个嵌入式 C 的基石。**寄存器（Register）** 是芯片内部用来控制硬件的"开关面板"，每个寄存器固定住在某个地址上。操作硬件 = 读写这些地址。指针恰好就是"读写任意地址"的工具——两者一拍即合。

MCU 的外设寄存器就是**固定地址上的内存**。把地址转成指针即可读写：

**这段代码要做什么**：定义 GPIOA 某个输出寄存器的地址宏，然后用它点亮/熄灭 PA5 引脚上的 LED。

```c
#include <stdint.h>

#define GPIOA_BASE   0x40010800UL
#define GPIOA_ODR   (*(volatile uint32_t *)(GPIOA_BASE + 0x0C))

GPIOA_ODR |=  (1u << 5);    // PA5 输出高（点亮LED）
GPIOA_ODR &= ~(1u << 5);    // PA5 输出低
```

运行逻辑逐段拆解（从里往外读宏）：
1. `GPIOA_BASE + 0x0C`：算出目标寄存器的物理地址 0x4001080C（外设区的一间"房"）；
2. `(volatile uint32_t *)`：把这串数字强转为"指向 32 位无符号数"的指针——等于把房号写在一张规格为 uint32 的纸条上；`volatile`（详见笔记09）是给编译器的禁令："这屋里的东西随时会被硬件改动，不许偷懒缓存"；
3. 最外层 `*( )`：解引用——把纸条变成可读写的"房间本体"。此后 `GPIOA_ODR` 用起来就像一个普通变量；
4. `|= (1u << 5)`：把第 5 位单独置 1，其他位不动（位操作详见笔记10）——这一位连着 PA5 引脚的电平。

一句话总结：**数字 → 纸条（强转指针）→ 房间（解引用）→ 操作硬件**。

`volatile` 三大作用（笔记09细讲）：防止编译器优化掉对寄存器/中断变量的读写。

> 这段代码就是 STM32 标准库 `((GPIO_TypeDef *)GPIOA)->ODR` 的原型——看懂它，库源码就不神秘了。

## 10. 指针经典笔试题

**这是什么**：下面几道题专门考"你有没有真的理解指针类型和运算"，出现率极高。别死记答案，画内存图推一遍。

**这段代码要做什么**：考"&a + 1 跳多远"。

```c
int a[5] = {1,2,3,4,5};
int *p = (int *)(&a + 1);
printf("%d", *(p - 1));     // 输出 5
// &a 类型是 int(*)[5]，+1 跨整个数组(20B)，p 指向 a[5] 后面一格
```
画图推一遍：`&a` 是"整排柜子"的地址（类型 int(*)[5]），+1 直接跨过整排 20 字节，落在 a[4] 之后一格；强转回 int* 后 `p-1` 退回一个 int（4 字节），正好落在 a[4]，即 5。关键：**+1 跨多大由指针类型决定**，不是永远 +4。

```c
// sizeof 相关
int a[10];  int *p = a;
sizeof(a) = 40;   sizeof(p) = 4或8（指针本身大小）
```

判断下列含义（背下来，拆词法：从 p 出发，先和谁结合就是什么主体）：
```c
int *p[10];            // 指针数组：p 先和 [10] 结合 → 10 个格子的数组，每格装 int*
int (*p)[10];          // 数组指针：(*p) 先结合 → 一个指针，指向 10 个 int 的数组
int (*p)(int, int);    // 函数指针：(*p)(...) → 指向"两个 int 进、int 出"的函数
int *(*p[10])(int);    // 函数指针数组：10 个函数指针，每个函数收 int、返回 int*
```
