# 03 · 运算符与流程控制

**这一篇讲什么**：程序 = 数据 + 对数据的操作 + 操作的先后顺序。运算符就是"操作"（加减判断等），流程控制就是"先后顺序"（什么条件走哪条路、一件事重复几次）。学会这两样，你就能写出真正"有逻辑"的程序，而不只是打印几行字。

## 1. 运算符分类

**这是什么**：和小学数学一样，先学加减乘除，再学比大小、并且/或者。C 的运算符就是这些动作的符号化写法。

### 1.1 算术运算符
`+ - * / %`
- 整数除法**向零截断**：`7/2=3`，`-7/2=-3`；取余 `%` 只能用于整数，`-7%2=-1`；
  - "向零截断"白话：小数部分直接砍掉、不四舍五入，7÷2 本来是 3.5，砍掉 .5 剩 3。**两个整数相除商还是整数**，这是新手最常踩的坑（算平均值算出 0）；
  - `%` 是"取余数"：7 % 2 = 1（7 除以 2 商 3 余 1）。判断奇偶、判断倍数全靠它：`x % 2 == 0` 即偶数；
- 浮点除法至少一方是浮点：`7.0/2=3.5`。

### 1.2 赋值运算符
`= += -= *= /= %= &= |= ^= <<= >>=`
```c
cnt += 5;     // 等价 cnt = cnt + 5
flags |= 0x80; // 嵌入式常用：把最高位置 1
```

### 1.3 自增自减
`++i`（先加后用）与 `i++`（先用后加）：

**这段代码要做什么**：对比 i++ 和 ++i 在同一个 printf 里的不同表现。

```c
int i = 5;
printf("%d\n", i++);   // 输出 5，之后 i=6
printf("%d\n", ++i);   // 先加再输出 7
```

逐行拆解：`i++` 是"先把 i 当前的 5 拿去用（打印），然后自己悄悄加到 6"；`++i` 是"先加到 7，再拿去打印"。记法：**符号在后 = 先用后加（后置的"懒"，先交作业再加班）；符号在前 = 先加后用（前置的"勤"，先加班再交作业）**。

> 嵌入式写法建议：单独一行用 `i++;`，避免在复杂表达式里混用（可读性 + 避免未定义行为，如 `i++ + ++i`）。

### 1.4 关系与逻辑运算符
- 关系：`== != > < >= <=`，结果 1（真）或 0（假）；
- 逻辑：`&& || !`。
  - 白话：`&&` 是"并且"（两边都成立才算成立），`||` 是"或者"（有一边成立就成立），`!` 是"取反"。C 语言里 **0 是假、非 0 都是真**，比较的结果用 1 表示真。

**短路求值**（重要）：

**这是什么**：`&&` 和 `||` 都"够用就停"——`&&` 左边已经是假，右边不用看（整体必假）；`||` 左边已经是真，右边也不用看（整体必真）。类比：招聘要求"本科**且**三年经验"，你没本科，HR 根本不会去看你的工作经历。

**这段代码要做什么**：利用短路特性写出"先确认安全、再使用"的判断。

```c
if (p != NULL && *p > 0)   // p 为 NULL 时不会解引用，安全写法
int a = (x != 0) && (100 / x > 2);  // x==0 时右边不算，防除零
```
坑：`==` 写成 `=`（赋值）不报错：`if (x = 5)` 恒真。习惯把常量写左边：`if (5 == x)`。

### 1.5 条件运算符与逗号运算符
```c
max = (a > b) ? a : b;
// 逗号：从左到右依次计算，取最后一个的值（少见，for 里常用）
for (i = 0, j = 9; i < j; i++, j--)
```

## 2. 位运算符（嵌入式重点，详见笔记10）

`& | ^ ~ << >>`——本笔记只需知道：`&` 按位与、`|` 按位或、`^` 异或、`~` 取反、`<<` 左移（×2）、`>>` 右移（÷2）。

## 3. 优先级速记

口诀（从高到低）：
1. 括号、下标 `[]`、成员 `.` `->`、后置 `++ --`
2. 单目：`! ~ ++ -- (类型) * & sizeof`（**右结合**）
3. 算术：`* / %` 高于 `+ -`
4. 移位 `<< >>`
5. 关系：`< <= > >=` 高于 `== !=`
6. 位：`&` > `^` > `|`
7. 逻辑：`&&` 高于 `||`
8. 三目 `?:`（右结合）→ 赋值 `=`（右结合）→ 逗号

> 实用原则：**记不住就加括号**，如 `(a & mask) == value` 不能写成 `a & mask == value`（== 优先级更高，结果完全不同）。

## 4. 分支结构

**这是什么**：让程序学会"看情况办事"——满足条件走 A 路，不满足走 B 路。生活里全是分支："如果下雨带伞，否则戴墨镜"。C 里分支有 if/else 和 switch 两种。

### if / else
```c
if (score >= 90) {
    grade = 'A';
} else if (score >= 60) {
    grade = 'P';
} else {
    grade = 'F';
}
```
- 悬空 else：`else` 总和**最近的未匹配 if** 配对 → 写代码永远带 `{}`；
- 嵌套别超过 3 层，深了用提前返回：

```c
// 防御式写法（嵌入式驱动代码常见风格）
int check(int *p)
{
    if (p == NULL)  return -1;
    if (*p < 0)     return -2;
    /* 正常逻辑 */
    return 0;
}
```

### switch / case

**这是什么**：if/else 的"多选一快捷版"。当你要把一个变量和一堆固定值挨个比较时（比如菜单选项 1/2/3），switch 写出来更整齐。类比：餐厅点餐按编号——"1 号菜走 1 号窗口，2 号菜走 2 号窗口"，`default` 就是"没有这个编号"的兜底窗口。

**这段代码要做什么**：根据按键值分发到不同处理函数，并演示多个 case 共用一段代码。

```c
switch (key) {
case '1':
    func1();
    break;          // 没有 break 会"穿透"继续执行下一个 case
case '2':
case '3':           // 共用一段：key 为 2 或 3 都执行这里
    func23();
    break;
default:            // 兜底，养成必写 default 的习惯
    break;
}
```
- 条件必须是**整型表达式**（char/int/enum），case 必须是**编译期常量**（为什么限定整型：switch 底层靠"按编号跳转"——用条件值算出偏移直接跳到对应分支，浮点数和字符串没有天然编号，跳不了）；
- 嵌入式里 switch 是**状态机**的标准写法（见笔记10）。

## 5. 循环结构

**这是什么**：让程序重复干活——打印 100 行、遍历 1000 个数据，不可能复制粘贴 100 遍代码。循环就是"设定好开始条件和结束条件，让一段代码自己重复跑"。类比：操场跑圈——for 是"跑满 10 圈自动停"，while 是"教练喊停才停"，do-while 是"先跑一圈再说"。

### 三种循环
```c
while (cond) { }        // 先判断后执行，可能一次不执行
do { } while (cond);    // 先执行一次再判断（菜单循环常用）
for (init; cond; step) { }   // 循环次数明确时首选
```
读法：for 括号里三段——`init` 出发前做一次（通常是 i=0），`cond` 每圈跑之前检查（不满足就停），`step` 每圈跑完做（通常是 i++）。

### break 与 continue
- `break`：跳出**本层**循环（或 switch）——直接离开操场回家；
- `continue`：结束本次循环进入下一轮（for 会先执行 step）——这一圈作废，回到起点跑下一圈。

### 嵌套循环与标志位
```c
int found = 0;
for (int i = 0; i < N && !found; i++) {
    for (int j = 0; j < M; j++) {
        if (arr[i][j] == target) { found = 1; break; }
    }
}
```

### 嵌入式专属：死循环的三种写法
```c
while (1) { }    // 推荐，可读性最好
for (;;) { }
do { } while (1);
```
> 主循环 `while(1)` 是裸机程序的骨架；裸机里"顺序执行一遍就结束"是错的，main 里必须有死循环（或由 RTOS 调度器接管）。

### goto：嵌入式里的合理用法
平时禁用 goto，但驱动/内核代码中用它**统一跳到错误清理**是被认可的：

**为什么这里 goto 反而好**：初始化 A、B、C 三个设备，C 失败时要按顺序拆掉 C、B、A。不用 goto 就得层层嵌套 if 写"成功 1 才试 2"，缩进越来越深、极易写漏。goto 统一跳到"清理出口"，每种错误只拆自己之前装好的——这是 Linux 内核代码的标准风格，属于 goto 唯一被业界认可的场景。

**这段代码要做什么**：依次初始化串口、SPI、传感器，任一步失败就逆序清理已初始化的资源。

```c
int init_all(void)
{
    ret = uart_init();
    if (ret) goto err_uart;
    ret = spi_init();
    if (ret) goto err_spi;
    ret = sensor_init();
    if (ret) goto err_sensor;
    return 0;

err_sensor:
    spi_deinit();
err_spi:
    uart_deinit();
err_uart:
    return ret;
}
```

## 6. 循环与分支经典练习

1. 判断一个数是否为素数（试除到 √n 即可。为什么够：若 n = a×b，a 和 b 必有一个不超过 √n，√n 以内找不到因子，后面也不会有）；
2. 输出 100~200 的所有素数；
3. 九九乘法表（双层 for，控制 `%2d` 对齐）；
4. 求最大公约数：辗转相除 `while (b) { t = a % b; a = b; b = t; }`（原理：gcd(a,b) = gcd(b, a%b)——余数不断当新除数，越除越小，余到 0 时除数就是答案）；
5. 猜数字游戏（do-while + 二分）；
6. 打印菱形/空心三角形（循环控制空格与星号）；
7. 计算阶乘及 1!+2!+...+n!；
8. 三次密码验证登录（for + break + 标志位）。
