# 01 · 数据结构与算法（嵌入式视角）

> 定位：四大件之一，**在 C 语言阶段末启动，贯穿刷题**。目标：嵌入式常用结构信手拈来 + 力扣 100~150 题打底。书：《大话数据结构》入门 → 《数据结构与算法分析：C 语言描述》（Weiss）进阶。

**先说人话**：数据结构就是"数据的摆放方式"，算法是"摆好之后怎么高效取用"。类比：数据结构是**厨房的收纳术**——砧板（数组）、挂钩排（链表）、摞盘子（栈）……收纳方式决定了找东西和放东西的速度。嵌入式里内存小、实时性要求高，所以本篇只精讲"最划算"的几个结构，不贪全。

## 1. 嵌入式最常用的五个结构（优先级排序）

**这是什么/解决什么问题**：面对"数据来了往哪放、怎么取"，嵌入式有五个高频答案。怎么读这张表：左列结构、中列它解决的实际场景、右列出处——按优先级从上往下学，前两个（环形缓冲/链表）不熟就先别往下走。

**五个结构的白话定义**（粗体术语逐个过）：

- **环形缓冲区**：一段首尾相接的数组（指针走到尾就绕回头），像**体育场环形跑道**——写的人（中断收数据）在前跑，读的人（主程序）在后追，各走各的、互不打断；
- **链表**：每个数据元素带着"下一个在哪"的地址，像**寻宝游戏**——找到一张纸条才知道下一张在哪；插删灵活（改地址即可），但找第 n 个必须一张张摸；
- **栈**：只从一端进出的结构，像**摞盘子**——后放的在上、先取的也是上；函数调用就是靠它记住"一层层调进去、一层层退回来"；
- **状态机**：不是存数据，是**组织逻辑**——把系统分成有限几个状态（如"等帧头/收数据/校验"），按事件在状态间跳转，像地铁线路图只停固定几站；
- **哈希表**：给每个数据算一个"柜子编号"（哈希函数），存取都直达——像**寄存包柜**，报密码直接开对应柜子，不用挨个翻。

| 结构 | 嵌入式场景 | 出自笔记 |
|------|-----------|----------|
| **环形缓冲区** | 串口/ADC/DMA 数据流，无条件首选 | 01-C 11 篇 |
| **链表** | 任务队列、内核对象链（FreeRTOS 链表）、配置项 | 01-C 11 篇 |
| **栈** | 函数调用（硬件栈）、表达式解析、回溯 | 系统自带 |
| **状态机** | 协议解析、按键消抖、模式切换（嵌入式"结构之王"） | 01-C 10 篇 |
| **哈希表** | 命令表、AT 命令匹配、参数查找 | 本篇 |

**嵌入式特殊性**：内存受限 → 静态分配优先（数组实现的环形缓冲/栈 > 动态链表）；实时性 → O(1) 操作的结构优先；不用复杂平衡树（红黑树内存换收益不划算，除非路由表类场景）。

## 2. 复杂度速查（能口算就够）

**这是什么/解决什么问题**：复杂度 O(x) 是"操作次数随数据量增长的趋势"，用来**在写代码前预估快慢**。白话：O(1)=次数固定不变（不管多少人排队，你查你自己座位）；O(n)=数据翻倍、耗时翻倍（挨个点名）；O(logn)=数据翻倍、只多一步（每次排除一半的二分法）；O(n²)=数据翻倍、耗时翻四倍（两两比较的冒泡）。

```
数组随机访问 O(1) / 插删 O(n)      链表插删 O(1)（已知位置）/ 查找 O(n)
环形缓冲进出 O(1)                  哈希表均摊 O(1)
二分查找 O(logn)（有序数组）        快排 O(nlogn) 均摊
```

**面试话术**：说复杂度必须说"时间/空间、最好/最坏"，如快排最坏 O(n²)（有序数组+首元素基准）——嵌入式里最坏情况更重要（实时性看最坏）。

## 3. 本阶段必会手写（对应 01-C 11 篇已有代码）

**这是什么/解决什么问题**：这五项是嵌入式数据结构的"基本功考核"——面试手撕和实际开发都从这里出题。判断掌握标准：**白板上无提示写出静态内存版**（不 malloc、不崩溃、边界正确）。

1. 单链表：头插/尾插/删除/反转/判环（快慢指针）；
2. 环形缓冲区：满/空判断（留空位法=牺牲一个格子：head==tail 判空、tail 的下一格追上 head 判满；计数法=另设一个计数变量直接数）、多字节读写；
3. 双缓冲（DMA 场景）：准备两块轮换的缓冲区——DMA 往 A 写时 CPU 处理 B，A 半满/全满了就互换，收发互不停摆；
4. 简单哈希：BKDR 哈希 + 拉链法命令表；
5. 排序：冒泡（会讲优化）、快排（分治思路）——嵌入式实际多用插入排（n 小快且稳定）。

## 4. 刷题策略（力扣，嵌入式口味）

**这是什么/解决什么问题**：力扣题海无边，嵌入式岗只考一个子集——这里把范围、语言、节奏、深度四件事定死，防止"刷了 500 题还是不会写环形缓冲"的错位努力。

- **范围**：100~150 题，聚焦：链表 20 + 栈队列 15 + 哈希 10 + 双指针 15 + 二分 10 + 简单 DP 15 + 字符串 15；
- **语言**：C 或 C++（面试嵌入式岗就写 C，展示内存意识：malloc 检查/free 对称）；
- **节奏**：C 语言阶段末起每天 1~2 题；面试冲刺期（10-就业篇 30 天清单）每天 3 题+复盘；
- **深度>数量**：每题写完问自己"边界条件齐了吗、复杂度能降吗、嵌入式里这题对应什么场景"。
