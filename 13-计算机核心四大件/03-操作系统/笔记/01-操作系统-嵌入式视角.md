# 03 · 操作系统（嵌入式视角）

> 定位：四大件之一，**边学 FreeRTOS 边对照理论，Linux 阶段前补完**。书：《操作系统导论》（OSTEP，免费英文电子版+中文版）精读前三部分；王道考研 OS 视频查漏。

## 2. 四大理论块（精读重点）

### 2.1 进程与调度

**这是什么**：进程是"程序的运行实例"（菜谱 vs 正在炒的菜），调度是"一个 CPU 多个进程，轮到谁跑"的裁决规则。类比：调度=**单车道十字路口的红绿灯**——规则设计决定整体通行效率。

- 并发 vs 并行（单核 MCU 只有并发——"交替"而非"同时"，讲清这个=秒杀一半面试题）；
- 调度指标：吞吐/周转/响应；实时系统的核心是**截止期**而非平均速度（FreeRTOS 优先级抢占正是 RMS 思想的简化——RMS=Rate Monotonic：周期越短的任务优先级越高的静态分配法）；
- 上下文切换成本：寄存器组+栈指针（MCU 十几 μs）vs Linux（+TLB/Cache 刷新，μs 级）——"任务为什么不能切太碎"的量化依据。

**术语白话**：并发=一个人**交替吃两碗面**（宏观同时、微观轮流）；并行=两个人各吃一碗（真同时）；上下文切换=换人上场前**把记分牌和球拍都交接清楚**；截止期=实时任务的"交卷时间"——晚交的满分卷不如准交的及格卷。

### 2.2 同步与死锁

**这是什么**：多个执行流抢同一份资源时怎么不出乱子（同步互斥），以及乱子中的极端形态——互相卡死（死锁）。类比：同步=**共用卫生间的门锁**（进去反锁、出来开锁）；死锁=两人各持一把钥匙、都在等对方开门。

- 竞态条件三要素：共享资源/并发访问/非原子操作——volatile 只保证可见性（改动立即被别人看见）不保证原子性（i++ 的读-改-写三步仍可能中途被切走）（01-C 09 篇辨析闭环）；
- 死锁四条件（互斥/持有等待/不可剥夺/循环等待）+ 破坏法（顺序加锁）——08-FreeRTOS 03 篇"分级加锁"的理论根；
- 经典模型：生产者-消费者（你写过三遍：C 环形缓冲/FreeRTOS 队列/Linux SQueue）。

### 2.3 内存管理

**这是什么**：OS 怎么给每个进程分内存、护内存（隔离）——从"一刀切整块分"进化到"切片+账本"（分页+页表）。

- 连续分配→分页→虚拟内存的演进逻辑；为什么要有虚拟地址（隔离/重定位/超额分配）；
- **嵌入式对照**：Cortex-M 无 MMU（MPU 仅权限）→ 裸映射+链接脚本定地址（10-Bootloader 分区）；Cortex-A 有 MMU → 页表/缺页/swap（内存不够时把不常用的页暂搬到磁盘腾地方）；
- malloc 的碎片问题：外部碎片/内部碎片——heap_4 合并策略 vs 静态池（01-C 08 + 08-FreeRTOS 05）。

**术语白话**：分页=把内存切成**固定大小的格子**按格分配（像停车场统一车位尺寸）；虚拟内存=给每个进程一张**"假装独占全部内存"的幻象地图**（页表负责幻象↔真实地址的翻译）；外部碎片=格子间的**零散空隙**（总空间够、连续空间不够）；内部碎片=**格子没装满浪费的部分**（要 3KB 却占了 4KB 的格子）。

### 2.4 I/O 与中断

**这是什么**：CPU 怎么把数据搬进搬出外设、中断怎么变成应用程序能感知的事件——这是"硬件事件→软件响应"的完整链路。

- I/O 控制方式演进：轮询→中断→DMA（你从 51 到 STM32 刚好重演一遍）；
- 缓冲的意义：速度解耦（环形缓冲）+ 一次搬运摊薄开销（块设备）；
- 硬件中断→软件事件的完整链：向量表→ISR→唤醒进程（RT 委托/Linux waitqueue）。

**术语白话**：轮询=**每隔几秒去门口看一眼快递到没到**（费人）；中断=**快递到了按门铃**（省人、及时）；DMA=**请搬运工直接把货从车上搬进仓库**，主人（CPU）继续干自己的活；缓冲=**门口的临时收货台**，快件多了先堆着再慢慢入库。

## 5. 章节小结

- OS 理论四块：调度/同步/内存/中断 I/O——每块在 FreeRTOS 和 Linux 各有一个"实体亲戚"
- 嵌入式三大兑现：并发≠并行、死锁破除=顺序加锁、无 MMU vs 有 MMU 的世界分野
- 学法：OSTEP 精读并发篇+调度篇 → 每理论找 FreeRTOS/Linux 双对照
