# 07 · EMC 与防护基础

> 定位：主线讲了"怎么让电路工作"，本篇讲"怎么让电路在恶劣现场**继续**工作"——静电、浪涌、继电器电弧、电源毛刺是工业设备的日常。触发点：学完 [06-PCB设计进阶](../../05-EDA与生产工具/笔记/06-PCB设计进阶.md) 之后；做带继电器/电机/长线缆的工业设备（LX-750PLUS 这类）之前**必读**。

**先说人话**：本篇讲什么，学完能做什么——

用一个"三要素"框架（干扰源 → 耦合路径 → 敏感设备）把 EMC 所有手段装进一张地图，再重点拆四个高频实战点：ESD 静电防护（TVS 选型原则与布局纪律）、继电器线圈续流二极管与触点 RC 吸收（含时间常数代入算例，LX-750PLUS 继电器矩阵的"触点粘连"维修高频故障根源就在这）、电源入口防护组合拳、接地与排查流程。学完你能给自己的板子配一套"接口防护清单"，并能在"现场动一下就复位/数据跳"类故障上按流程定位。

硬约束先立：**涉及市电（220V AC）侧的防护器件选型与改动属强电作业，本篇只讲原理认知与弱电侧防护，市电侧动手必须由持证专业人员操作。**

## 1. 三要素框架：所有 EMC 问题的通用地图

> **这是什么**：干扰要造成问题，三个角色必须凑齐——**干扰源**（谁在发）、**耦合路径**（怎么传过去）、**敏感设备**（谁受影响）。缺一个，问题就不成立——这也意味着你有三条破解路线。

类比：邻居家电钻（源）吵到你午睡（敏感），声音穿墙（路径）。你可以：让他换时间装修（治源）、给墙加隔音（断路径）、自己戴耳塞（加固敏感）。

| 路线 | 手段举例 | 什么时候优先 |
|------|----------|--------------|
| 治源 | 继电器加续流/吸收、电机加缓冲、慢边沿驱动 | 能碰到源就先治源，性价比最高 |
| 断路径 | 屏蔽、滤波（共模电感/电容）、隔离、良好接地 | 源是别人的设备/环境时 |
| 加固敏感 | 接口 TVS、软件滤波、看门狗兜底 | 最后防线，永远要留 |

工程次序铁律：**先治源、再断路、最后加固**——只做第三条等于"戴耳塞睡在电钻房"。

## 2. 干扰怎么进出：传导与辐射、差模与共模

- **传导**：沿电源线、信号电缆"坐车"进出设备——长电缆是传导干扰的高速公路；
- **辐射**：空间电磁波耦合——高频才容易飞：线长接近 λ/4 就是好天线（算例见 [04-高速通信与信号完整性](04-高速通信与信号完整性.md) 第 3 节：100MHz 时 75cm 线缆即成天线）；
- **差模**：两根信号线之间的干扰（火-零、A-B 之间）——"有用信号的仿冒者"；
- **共模**：线对地（或对参考）共同抬起——"全家人一起漂"。**共模是工业现场的头号大敌**（长线缆与地电位差天然制造共模），后面的共模电感、隔离、屏蔽全在治它。

排查视角：示波器看波形时，单端探头看到的"毛刺"混合了两种模——测不准就想想"这是差模毛刺还是地本身在跳"（后者要差分探头或换参考点，仪器口径见 [06-测量仪器与调试排障](../../02-电路基础/笔记/06-测量仪器与调试排障.md)）。

## 3. 静电（ESD）防护

> **这是什么**：人体/物体摩擦带的静电（可达数 kV）从接口灌进芯片打穿栅氧——冬天摸门把手的那种放电，对芯片是死刑。

放电有多猛（标准模型口径）：ESD 测试常用**人体模型（HBM）**——等效 100pF 电容串 1.5kΩ 电阻【标准模型参数】；带上数 kV 电荷放电，峰值电流安培级、边沿亚纳秒级。芯片内部虽有二极管自保，但只防"小剂量"，接口级防护必须外置。

**TVS（瞬态电压抑制二极管）三参数**（选型三兄弟，关系背下来）：

```
VRWM（最高工作电压）< VBR（击穿电压）< VC（钳位电压）
```

- 选型原则：**VRWM 略高于线路最高正常工作电压**（含信号摆幅）——选低了常态漏电发热，选高了钳位太晚保护不到；
- 双向 TVS 用于对称信号线（RS485 A/B、CAN H/L），单向用于已知极性的电源/单端信号；
- 具体型号不在此列——按系统电压与接口类型查 TVS 厂商官网选型表（如 Littelfuse 等厂商的低容 ESD 阵列/功率 TVS 分级），高速线选**低结电容**款（容效影响见 [04-高速通信与信号完整性](04-高速通信与信号完整性.md)）。

**布局纪律（比选型更容易错）**：ESD 管**紧贴连接器**放，泄放路径"接口 → TVS → 地"短而直，**不许绕穿核心电路区**——TVS 放板子中间等于保安站在办公室里面：电已经进屋了。

三道防线总结：外壳/间距让静电"尽量不来"（远离）→ 接口 TVS 把进来泄放掉（泄放）→ 芯片内部保护兜底（容忍）。

## 4. 继电器防护：线圈续流与触点吸收（工业设备必修）

> **这是什么**：继电器两边都要防——**线圈侧**防断电感生高压（打驱动管），**触点侧**防负载电弧（烧蚀粘连）。LX-750PLUS 这类继电器矩阵设备，"触点粘连"是维修高频故障（见 [08-真实工业产品BOM案例](../../02-电路基础/笔记/08-真实工业产品BOM案例-LX750PLUS线材测试仪.md) 与 [05-电路板维修实战](../../05-EDA与生产工具/笔记/05-电路板维修实战.md)），根源就是本节。

### 4.1 线圈侧：续流二极管

**机理**：线圈是电感，断电瞬间电流被强行掐断，V = L·di/dt 产生反向感生高压——可达电源电压的数十倍以上（视线圈参数与开关速度），直接击穿驱动三极管/MOS。

**解法**：线圈两端**反并联**一只二极管（**阴极接电源正端**——工作时二极管反偏不通，断电时给线圈电流"泄洪通道"），把感生电压钳位在二极管导通压降（约 0.7~1V）附近。

**代价**：释放变慢。代入算例（数值为演示假设，实际查所用继电器线圈参数）：

```
设线圈：24V、20mA → R = 24V ÷ 20mA = 1.2kΩ
设线圈电感 L = 0.3H（小功率继电器线圈量级，假设值）
加续流二极管后电流按 RL 时间常数衰减：τ = L/R = 0.3 ÷ 1200 = 0.25ms
→ 触点释放延迟毫秒级，一般应用无感；快速切换场景嫌慢，改用
  "二极管+稳压管串联"抬高钳位电压加速泄放（原理：钳位越高泄放越快）
```

### 4.2 触点侧：电弧与吸收

**机理**：触点断开感性负载瞬间，感生高压在触点间隙**拉出电弧**——电弧高温烧蚀触点表面镀层，反复烧蚀 → 触点氧化粗糙 → 接触电阻增大 → 发热粘连。你听到的"啪"声轻响，就是电弧在烧钱。

**解法按负载类型分**：

| 负载 | 吸收方案 | 要点 |
|------|----------|------|
| 直流感性（DC 电磁阀/电机） | 触点两端并联二极管（或 TVS） | 极性与续流二极管同理 |
| 交流负载（AC 电磁阀/市电接触器） | 触点两端并联 **RC 吸收**（常见范围 0.01~0.1µF + 47~100Ω【经验值范围】） | **交流不能用二极管**（极性每半周反转，二极管直接导通短路） |
| 交流浪涌环境 | 触点/负载两端并联压敏电阻（MOV） | 钳位浪涌，选持续工作电压高于线路电压 |

RC 取值思路（不背公式，讲方法）：C 用来"接住"断开瞬间的能量（把电压爬升放缓），R 用来限制触点重新闭合时 C 的放电电流——两者是"先缓后限"的搭档；精确值按负载电流与触点材质查继电器厂商应用笔记，常用范围已给出，够大多数选型起步。

### 4.3 驱动侧一句话

MCU 不直接驱动继电器线圈——三极管/MOS 加基极/栅极电阻与下拉，光耦隔离驱动是工业惯例（隔离原理见 [05-最小系统与常用接口电路](../../02-电路基础/笔记/05-最小系统与常用接口电路.md)）；驱动管本体选型与失效特征在 [07-工业常用元器件速查手册](../../02-电路基础/笔记/07-工业常用元器件速查手册.md)。

## 5. 电源入口防护组合拳

> **这是什么**：外部电源是干扰与浪涌的"正门"，进门按"先保命、再干净"排队安检。

```
外部电源 → 保险丝(过流保命) → TVS(浪涌钳位) → 共模电感(滤共模)
        → X/Y 电容(滤差模/共模) → 后级 DC-DC/LDO（选型见 14/01 电源篇）
```

排队逻辑（为什么是这个顺序）：

1. **保险丝最前**——后级任何器件失效短路，先熔断保电线；
2. **TVS 跟上**——保险丝熔断前的窗口期里，TVS 把浪涌钳住（TVS 会"牺牲自己"扛到保险丝动作，属可消耗防护件）；
3. **共模电感**——同一磁芯上两绕组**同向绕制**：差模电流磁场相消（低阻抗通过），共模电流磁场叠加（高阻抗阻挡）——专为工业共模干扰准备；
4. **X 电容**（跨在两线之间）滤差模，**Y 电容**（线对地）滤共模——安规口径：X 电容失效模式是短路（靠保险丝兜底），Y 电容必须失效开路（否则漏电伤人），两者是专用安规电容，**不可用普通电容替代**；
5. 自恢复保险丝（PPTC）适合接口/可插拔场合——过流变高阻，断电恢复，免换。

布局衔接：这排"安检门"按信号流向**一字排开**，防护地在入口就近接地，别让浪涌泄放电流绕行信号区（与 ESD 布局纪律同理）。

## 6. 接地与整体布局要点

- **功率地与信号地单点汇接**：继电器/电机的大电流回流不许穿过小信号区——分区布板、单点连接，防止"大电流在地线上写字"（共阻抗耦合）；
- **屏蔽线缆接地原则**：屏蔽层要接地才起作用；低频单点接地、高频多点接地——方向性原则记住即可，具体接法随频段与场合，深究查 EMC 专著；
- **金属外壳**：既是屏蔽也是 ESD 的"接客大厅"——静电先打外壳，泄放路径要短到地；
- 手法细节（铺铜、分区、过孔缝合）在 [06-PCB设计进阶](../../05-EDA与生产工具/笔记/06-PCB设计进阶.md)，本篇不重复。

## 7. 排查流程：现场故障按三要素套

```
现场故障（复位/数据跳/通信断）
① 定位源：能断开实验就断开——拔掉电机/继电器负载再试（治源线索）
② 断路径：换短屏蔽线、隔离后试、改接地方式（断路线索）
③ 加固敏感：接口加 TVS/滤波、软件滤波+看门狗兜底（加固线索）
④ 复现验证：改动一次只动一处，每处必复现对比——EMC 排查最忌"一次改三个"
```

定性排序经验：工业现场十有八九的"莫名其妙复位/跳变"，答案是"继电器/电机/静电 + 没做 4.x 节防护"的组合——先查最便宜的解释，再怀疑玄学。

## 工程实操任务

- [ ] 继电器线圈示波实验：无续流二极管时（低压安全实验，如 5V 线圈）抓断电尖峰，装上二极管再抓——亲眼看 L·di/dt 与钳位效果；
- [ ] 触点电弧观察：继电器切换小电机负载，串 LED/示波器看电源纹波跳动，加 RC 吸收前后对比；
- [ ] 给自己板子的外部接口（RS485/USB/按键）各配一只 TVS（按 VRWM 原则选型），检查布局是否紧贴连接器；
- [ ] ESD 演练：干燥天隔着绝缘物用人体静电打接口（远离核心板先做备份），对比加防护前后的复位现象；
- [ ] 电源入口按第 5 节搭一版"安检队列"，用示波器对比加共模电感前后的纹波形态。

## 常见坑（新手必看）

1. **TVS 的 VRWM 选低了**：常态漏电发热甚至发烫——VRWM 必须略高于线路最高工作电压（第 3 节三参数关系）；
2. **续流二极管方向焊反**：上电即导通短路驱动管——记住"阴极接正端"，焊前用万用表二极管档验一遍；
3. **交流负载并了二极管**：每半周反向导通 = 相间短路——交流负载只用 RC 吸收/压敏电阻（4.2 节表格）；
4. **ESD 管放板子中央**：泄放路径穿过全板，等于没保护——紧贴连接器，短直入地；
5. **Y 电容用普通瓷片凑数**：安规电容的失效模式是标准要求，普通电容失效短路会漏电伤人——市电侧器件必须安规认证件；
6. **一次改三处"优化"**：改完好了不知道谁起作用，坏了不知道谁闯祸——单变量原则（第 7 节流程）；
7. **市电侧自己动手**：再次强调硬约束——市电防护选型与接线属强电作业，本篇市电内容仅作原理认知，动手必须专业人员。

## FAQ

**Q：磁珠和电感什么区别？什么时候用哪个？**
A：电感储能（LC 滤波、防止电流突变），磁珠呈高频损耗电阻特性（把高频噪声"耗成热"而非反弹）——电源滤波用 LC，抑制高频噪声传导用磁珠；两者常搭配出现。选用按目标频段阻抗曲线查厂商 datasheet。

**Q：加了续流二极管，继电器释放明显变慢怎么办？**
A：这是续流钳位太低的副作用（4.1 节算例）——改"二极管+稳压管串联"抬高钳位电压，泄放电流变大、τ 变小，释放加快；快速场景也可选带内置吸收的继电器驱动 IC。具体组合按继电器规格核算。

**Q：软件能做什么防护？**
A：接口数据加校验与重传（协议层在 [02-串口通信与自定义协议设计](../../09-通信协议/笔记/02-串口通信与自定义协议设计.md)）、采样值滑动平均/限幅滤波（方法见 [02-传感器应用专题](02-传感器应用专题.md)）、看门狗兜底复位（配置见 [08-系统功能与项目实战](../../07-STM32/笔记/08-系统功能与项目实战.md)）——软件是最后防线，不能替代本篇硬件防护。

**Q：示波器看到地"在跳"怎么确认是共模？**
A：换差分探头或"两通道相减"测两线间差值：差值干净而单端看毛刺 → 共模主导。没有差分探头时，把探头参考点改到"干净地"再对比，也能定性——仪器口径以 [06-测量仪器与调试排障](../../02-电路基础/笔记/06-测量仪器与调试排障.md) 为准。
