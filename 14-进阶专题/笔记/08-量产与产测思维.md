# 08 · 量产与产测思维

> 定位：从"做出能跑的板子"到"交出稳定的产品"之间的**最后一公里认知**——产线怎么加工你的设计、怎么测试你的板子、你的设计怎么决定产线效率。触发点：求职冲刺前补认知（面试通识加分项）；或第一次把板子送出去打样/小批量贴片之前（提前知道要交什么文件、留什么接口）。

**先说人话**：本篇讲什么，学完能做什么——

一块 PCB 从 Gerber 文件变成出货产品，要经过 SMT 贴片 → 焊接检测 → ICT → 烧录 → FCT → 老化 → 终检的完整流水线，每一站都有它存在的理由和对应的"验收语言"（FPY、DPPM、8D）。本篇把这条流水线一次讲透，配三个代入算例（直通率、返修成本、老化加速），最后用 14 模块做过的恒温采集器做沙盘推演：如果要量产它，你要留什么接口、配什么测试固件。学完你能看懂 BOM 三件套的产线用途、面试能讲清 ICT/FCT 区别、画板时会顺手留出测试点和烧录口。

硬约束先立：本篇讲的是**通用产线认知**；不涉及具体代工厂的报价、产能与商业条款（随市场变动，一律以厂商为准）。LX-750PLUS 真机仅作认知挂钩，不虚构其内部产线信息。

## 1. 原型思维 vs 量产思维

> **这是什么**：做 1 块板子和做 1000 块板子，是两种工程观。原型的对手是"未知的技术问题"，量产的对手是"确定性的重复成本"。

类比：原型像**手冲一杯咖啡**（现磨现做，随便调整）；量产像**开一家 200 家门店的连锁咖啡**（每一杯的配方、流程、失败率都要可复制、可统计、可改进）。

| 维度 | 原型（1~5 块） | 量产（100 块起） |
|------|----------------|------------------|
| 目标 | 证明"能工作" | 证明"每块都一样地工作" |
| 手段 | 万用表+示波器逐块调 | 治具+测试程序流水化 |
| 容错 | 手焊飞线都行 | 工艺参数、元件来料都要受控 |
| 关键指标 | 功能对 | 直通率/不良率/返修成本 |

**工程师在产线里的角色**：设计测试方案与治具需求、写生产测试固件、分析不良品根因、把产线问题反哺回设计。这是"嵌入式工程师"和"会点灯的爱好者"最直接的分水岭之一。

## 2. 从文件到产品：PCBA 流程地图

> **这是什么**：你的设计交给代工厂（EMS 电子制造服务商，即"代工+代料"的工厂模式；另有 OEM 来料加工、ODM 代设计+制造等模式，区别在"谁出设计、谁买料"）后，板子经历的标准旅程。

```
 Gerber / BOM / 坐标文件 三件套
        ▼
① 锡膏印刷（钢网）─→ ② SPI 锡膏检测 ─→ ③ SMT 贴片机贴装
        ▼
④ 回流焊（整炉融化定形）─→ ⑤ AOI 自动光学检测（焊点外观）
        ▼                          （BGA 封装另加 X-ray 查内部焊球）
⑥ THT 插件（人工/机器插直插件）─→ ⑦ 波峰焊 或 手焊
        ▼
⑧ ICT 电路测试（治具顶针刺点）─→ ⑨ 烧录固件 ─→ ⑩ FCT 功能测试
        ▼
⑪ 老化（可选，视产品等级）─→ ⑫ 终检外观与包装出货
```

三件套的产线用途（对应你在 [02-立创EDA-PCB设计](../../05-EDA与生产工具/笔记/02-立创EDA-PCB设计.md) 导出的文件）：

| 文件 | 内容 | 给谁用 |
|------|------|--------|
| Gerber（光绘） | PCB 各层图形 | 制板厂：造裸板 |
| BOM（物料清单） | 位号/型号/封装/数量（完整案例见 [08-真实工业产品BOM案例](../../02-电路基础/笔记/08-真实工业产品BOM案例-LX750PLUS线材测试仪.md)） | 贴片厂：采购与上料核对 |
| 坐标文件 | 每个贴片元件的 X/Y 位置与旋转角 | 贴片机：编程吸放路径 |

三站检测的分工直觉：SPI 管"锡膏印得对不对"（焊接的前置条件）、AOI 管"焊点长得好不好"（外观层）、X-ray 管"看不见的焊球"（内部层）——**越早发现问题返工成本越低**，这正是层层检测存在的原因。

## 3. ICT 与 FCT：两大测试环节的分工

> **这是什么**：ICT 查"零件装对没装对"，FCT 查"板子干活干得对不对"——一静一动，互不替代。

### 3.1 ICT（In-Circuit Test，在线测试）

- **手段**：针床治具（数百根弹簧顶针按测试点位图同时压上板面）或飞针机（2~8 根探针逐点移动，省治具费但慢）；
- **测什么**：不通电/低电压下测——短路、开路、电阻/电容/电感实际值、二极管/晶体管极性与增益，部分网络可做上电电压校验；
- **价值**：把"焊错、装错、元件错值"这类**制造缺陷**在通电前抓出来，避免坏板进 FCT 浪费测试工时；
- **对设计的要求**：预留**测试点（test point）**——常用量级：直径 1mm 上下、间距 1.27mm 量级【经验值，以治具厂商要求为准】，关键网络（电源、地、总线、关键 IO）都要有可刺探的点；打样机（飞针）对测试点要求更宽松，是"小批量不想开针床"的折中。

### 3.2 FCT（Functional Test，功能测试）

- **手段**：功能治具——板子卡进定位槽，pogo pin（弹簧顶针）连接到实际接口，治具内置或外接"模拟真实工作条件"的电源/信号/负载；
- **测什么**：通电跑**生产测试固件**，验证整机行为——各路电压是否达标、按键是否响应、显示是否点亮、通信口是否回环正常（按产品功能定制，与 ICT 的"元件级"完全不同）；
- **治具构成三件套**：机械定位（决定放板快慢）+ 电气接口（pogo pin 排）+ 上位机判定（测试项 PASS/FAIL 自动记录）。

### 3.3 烧录：量产环节的固件写入

- **在线烧录**：板上预留 **SWD 口**（SWDIO/SWCLK/GND/3.3V 四线为主，NRST 可选——F103 口径，见 [07-调试实战](../../07-STM32/笔记/07-调试实战.md)），治具探针顶住焊盘/插排线写入；
- **离线烧录器**：母片先考入烧录器，产线脱机批量复制，不依赖 PC——适合产线无电脑环境与高节拍产线；
- **与 OTA 的衔接**：量产烧录只负责"出厂第一版固件"，出厂后的更新走 OTA（双分区升级与回滚设计见 [02-OTA设计与实战](../../10-Bootloader与OTA/笔记/02-OTA设计与实战.md)）——两者是"首次写入"和"生命周期更新"的分工；
- **设计要求**：烧录口靠近板边、预留丝印标注、**别让外壳遮死**——真有产品是整机装配完才发现烧录口被壳盖住的。

## 4. 老化测试：用时间钓出"短命鬼"

> **这是什么**：老化（Burn-in）= 让产品在通电工作（常配合高温环境）下连续运行一段时间再出货——目的不是"练产品"，而是**把早期失效的个体在厂内钓出来**，别流到客户手里。

**理论依据：浴盆曲线**（可靠性经典）：

```
失效率
  │＼                    ／
  │ ＼  ①早期失效期    ／ ③损耗期
  │  ＼（工艺缺陷、    ／（元件寿命
  │   ＼ 虚焊、来料   ／  到期，年计）
  │    ＼ 瑕疵）/   ／
  │     ＼＿＿＿＿／＿＿＿＿＿＿＿＿
  │       ②稳定期（失效率低且平稳）
  └──────────────────────────────→ 时间
```

- **①早期失效期**：头几十到几百小时失效率陡降——坏的都是"天生带病"的个体。老化就是在这段区间里"陪跑"，让它们在厂内暴露；
- **②稳定期**：正常使用寿命主体，失效率低而平稳；
- **③损耗期**：元件寿命到期，失效率回升——这是保修期设计要考虑的事，不是老化要解决的事。

**高温加速**（经验法则）：工作温度每升高约 10°C，失效加速约一倍（Arrhenius 加速思想的工程近似【经验法则】，精确系数按产品类别与失效模式查可靠性手册）——所以工业产品常做**高温老化**（如整机组在约 50~60°C 环境通电跑，具体温度与时长按产品规格与客户要求定，常见时长 24~72h【经验值】）。

**老化的纪律**：老化必须**通电且带工作负载**（空跑晾板不是老化）+ 期间有监测（电流/功能心跳记录）——"烘箱里堆一晚上没人管"等于白老。

## 5. 品质语言：FPY、DPPM 与不良分析

> **这是什么**：产线的"验收通用语"——面试聊到量产，听得懂、说得出这些词，才算进了话场。

**FPY（First Pass Yield，一次直通率）**代入算例：

```
投料 1000 块，第一轮全测通过 950 块
FPY = 950 ÷ 1000 = 95%
```

**返修成本算例**（全部为演示假设值，量级供体感）：

```
FPY 95%：每千块返修 50 块，单块返修工时按 15min 假设
  → 返修工时 = 50 × 15min = 750min = 12.5 人时/千块
FPY 99%：  每千块返修 10 块
  → 返修工时 = 10 × 15min = 150min = 2.5 人时/千块
```

同样 1000 块板，直通率差 4 个点，仅返修工时就差 **5 倍**——这还没算报废物料与延期交期。所以"提高直通率"从来不是口号，是直接的人民币。

**DPPM**（Defective Parts Per Million）：百万分之不良数——950/1000 口径即 50000 DPPM，消费品量产通常按千级~百级 DPPM 管理（具体目标随行业与客户，无统一标准）。

**不良四分类与闭环**：每块不良品归因到 **来料**（元件本身坏）/ **工艺**（虚焊、立碑、连锡）/ **设计**（原理错误、布局缺陷）/ **操作**（人为失误）四类之一，统计占比 → 占大头的一类触发改善动作；正式的品质问题答复走 **8D 报告**（八步纪律法：成立小组→描述问题→临时围堵→根因→纠正措施→效果验证→预防推广→结案，概念了解即可）。

**产线 ESD 纪律**：手环/脚环接地、离子风机中和、周转用防静电袋——你在 [07-EMC与防护基础](07-EMC与防护基础.md) 学的 ESD 是"产品怎么防"，产线这层是"人怎么别把静电带进产品"，两道防线缺一不可。

## 6. DFM/DFT：把"产线的活"前置到画板阶段

> **这是什么**：三个面向设计（Design for X）概念——**DFM**（可制造：工艺做得出来）、**DFT**（可测试：治具测得到）、**DFA**（可装配：装得顺、装不错）。对嵌入式工程师，最实用的是给画板阶段留一份"为产线设计"检查单。

| 检查项 | 要点 | 漏掉的后果 |
|--------|------|-----------|
| 测试点 | 电源/地/总线/关键 IO 每网可测，直径与间距按治具口径（3.1 节） | ICT 治具做不了或扎不准 |
| 烧录口 | SWD 靠板边+丝印标注+壳不遮挡（3.3 节） | 量产烧录费时或拆壳 |
| 状态指示 | 电源 LED + 自检结果 LED/蜂鸣 | 产线无屏也能快速判活 |
| 调试串口 | 预留 UART 焊盘，生产固件可输出自检日志 | 不良品无话可说 |
| 定位孔 | 板边定位孔与治具滑槽匹配，防呆不对称 | 放反、放偏、压伤 |
| 连接器方向 | 防呆缺口，插错即物理不可能 | 产线插反烧板 |
| 元件高度 | 大高件避让治具顶针区 | 顶针被架空，ICT 全 FAIL |
| 单板自检 | 固件上电跑自检序列，结果经串口/LED 可读 | FCT 判定逻辑复杂易错 |

布局手法细节（回流地、分区、阻抗）在 [06-PCB设计进阶](../../05-EDA与生产工具/笔记/06-PCB设计进阶.md)，本节不重复——本节讲的是"给机器和治具留位置"，那篇讲"给电流和信号留路径"。

## 7. 实例沙盘：把恒温采集器推上小批量

以本模块已实现的恒温采集器（NTC + PWM 加热 + OLED + 串口上报，见 [05-PID控制算法](05-PID控制算法.md) 与 [06-OLED点阵屏驱动](06-OLED点阵屏驱动.md)）为例，推演"100 块小批量"要做的事（示例口径，非任何真实产品数据）：

**交厂三件套**：Gerber + BOM（含替代料标注）+ 坐标文件（对接贴片厂，流程参照嘉立创 SMT 页面口径）。

**生产测试固件设计**（与正式固件区分，测试逻辑写成分支可裁剪）：

```
上电 → ① 3.3V/5V 电源点电压自测（ADC 读，容差±5%）
     → ② NTC 读取合理性（室温 0~50°C 窗口内，超窗判来料/工艺）
     → ③ 加热回路短促试开（10% 占空比 0.5s，看电流采样是否响应）
     → ④ OLED 自检（显存 CRC + 逐段点亮）→ ⑤ 串口回环（TX↔RX 对接治具）
     → ⑥ 结果编码：LED 慢闪=PASS；快闪次数=FAIL 项编号
```

**测试项清单与判据**（FCT 治具按此逐块判定）：每项一个判据、一个记录字段——直通率按天统计，哪项 FAIL 集中就优先归因（第 5 节四分类）。

**迭代闭环**：首 100 块 FPY 假设 92% → 不良统计发现"NTC 虚焊"占 6 成 → 归因焊盘设计（钢网开口/焊盘尺寸）→ 改版 v1.1 → 复测 FPY 目标 ≥98%。这个"FPY 统计 → 归因 → 设计改善"的循环，就是量产思维的日常。

## 8. 职业视角：为什么面试官爱问产测

- **考设计闭环意识**：能说出"我留了测试点和烧录口、写了生产自检固件、首批量直通率多少、怎么改善的"——证明你考虑的是产品，不是作业；
- **简历落地句式**（套用 [03-项目复盘与迭代方法论](../../12-项目实战与就业/笔记/03-项目复盘与迭代方法论.md) 的"发现→定位→解决→量化结果"）："小批量 100 块直通率 92% → 统计发现 NTC 虚焊集中 → 优化焊盘与钢网开口 → 复测直通率 98%+"（数字换你自己的真实数据）；
- 作品集展示时，README 里放一段"生产与测试"小节（规范见 [01-作品集打造与简历项目化](../../12-项目实战与就业/笔记/01-作品集打造与简历项目化.md)）——哪怕只是打样 5 块 + 手动 FCT，也立刻和 90% 的"只跑通 demo"的作品拉开差距。

- [ ] 给一块板子做 24h 通电老化（带真实负载 + 每小时记录一次电流/心跳日志），统计期间有无异常——亲手感受"老化在钓什么鱼"；
- [ ] 面试自测：脱稿讲清 ICT 与 FCT 的区别、浴盆曲线三阶段、FPY 怎么算——讲不顺就回对应节重读。

## 常见坑（新手必看）

1. **测试点漏留**：原型阶段没影响，一上 ICT 就"治具顶不到"——画板时按第 6 节检查单过，别等治具报价单提醒你；
2. **烧录口被结构件遮死**：整机组装完才发现没法烧录——烧录口位置要在结构评审时一起看；
3. **生产固件忘恢复正式固件**：测试分支的"永远输出 PASS"逻辑留在了出货固件里——生产固件与正式固件用编译开关严格区分，出货前核对版本号；
4. **老化不监测**：烘箱堆一晚没人看电流、没记心跳——钓不到早期失效，只算给板子蒸了个桑拿（第 4 节纪律）；
5. **不良品随手报废不归因**：直通率永远上不去——每块不良必须四分类（第 5 节），大头才有改善方向；
6. **防呆缺失**：连接器无防呆、治具定位不对称——产线插反一批烧一批，返工成本远大于两个定位柱；
7. **把打样当量产练手**：打样厂的工艺窗口比量产厂宽松，打样没问题 ≠ 量产没问题——小批量转量产要重新确认工艺（钢网、炉温曲线由厂方管控，你管"交对文件+验对结果"）。

## FAQ

**Q：我只有打样 5~10 块的量，还需要懂这些吗？**
A：需要认知、暂不需要治具——5 块板手动 ICT（万用表测电源网络）+ 手动 FCT（烧录自检固件跑序列）就是你的"产线"；但检查单（第 6 节）从第一版板就该照做，因为改版比留测试点贵十倍。

**Q：飞针和针床治具怎么选？**
A：经验口径：小批量（几十块）或试产选**飞针**（免治具费、交付快、慢）；稳定量产选**针床**（单板秒级、治具费一次性投入）——交叉点在"批量 × 节拍节省 vs 治具费用"，报价找厂商要，无固定分界。

**Q：老化做多久、多高温度合适？**
A：没有统一答案——按产品等级（消费/工业/车规要求差异大）、客户协议与失效历史定；本篇只给体感锚点：常见 24~72h、高温 50~60°C 量级【经验值】，正式定案以产品可靠性规格为准【待查证】。

**Q：ICT 能测出固件 bug 吗？**
A：不能。ICT 查的是硬件制造缺陷（元件/焊接），固件逻辑问题要靠 FCT 测试项与后续 OTA 修复覆盖——这也解释了为什么 OTA 设计（10 模块）与产测是互补关系。

**Q：没有示波器/产线设备，怎么在家做"准产测"？**
A：把 FCT 固件做足：自检序列 + LED/串口结果编码，配万用表量电源点——单板判定闭环就有了；仪器升级路径与用法见 [06-测量仪器与调试排障](../../02-电路基础/笔记/06-测量仪器与调试排障.md)。
