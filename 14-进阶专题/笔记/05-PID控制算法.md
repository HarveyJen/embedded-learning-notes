# 05 · PID 控制算法

> 定位：主线 [07-STM32/03 定时器与PWM](../../07-STM32/笔记/03-定时器与PWM.md) 教你"能输出 PWM"，本篇教你"让 PWM 干智能活"——把被控量（温度/转速/电流）稳稳拉到目标值并稳住。触发点：学完定时器 PWM 与 ADC 采集（[05-DMA与ADC](../../07-STM32/笔记/05-DMA与ADC.md)）之后，手里有一个"想让某个量稳定在目标值"的活（恒温台、风机调速、恒流源）。

**先说人话**：本篇讲什么，学完能做什么——

PID 用三股力气（当前偏差的"猛劲"、历史偏差的"补账"、偏差趋势的"刹车"）合成一路控制量去驱动 PWM。本篇把 P、I、D 三项各配一个代入算例讲透，给一段可直接抄的结构体版 C 实现（含抗积分饱和），再用"现场手感四步法"教你不用背公式也能整定参数，最后落到"NTC + 加热膜 + PWM"完整温控链路。学完你能独立做出一版恒温控制：温度曲线从"上蹿下跳"变成"平稳收敛"。

为什么不只讲公式：本篇整定方法以"看现象、动旋钮"的现场手感为准——嵌入式的 PID 是调出来的，不是推出来的。

## 1. 从"开关控制"到 PID

> **这是什么**：最原始的控制叫开关控制（bang-bang）：温度低了全开、高了全关。PID 是它的进化版——不是"开/关"两档，而是"出多大力气"连续可调。

类比（贯穿全篇）：**淋浴调水温**。

- 开关控制 = 龙头只有全开全关两档：烫了关到底，冷了开到最大，水温永远坐过山车；
- P = 看当前水温和目标的差距调龙头：差得多调大点，差得少调小点；
- I = 一直偏冷就慢慢再加大一点热水：**记仇**，把历史欠账一点点补回来；
- D = 水温正在快速变烫就先别再加：**预判**，提前刹车防冲过头。

开关控制的两个痛点（也是 PID 的两大动机）：

1. **来回摆**：全开→过冲→全关→下探→再全开，温度在目标附近荡秋千，继电器/加热膜寿命也遭罪；
2. **到不了**：环境一直在散热，开关控制只在"两个极端"之间跳，给不出"刚好抵消散热的中间功率"。

## 2. 术语白话

| 术语 | 大白话 | 类比 |
|------|--------|------|
| 目标值 setpoint | 你想要的稳定值 | 想要的 50°C 水温 |
| 测量值 | 传感器实际读到的值 | 温度计读数 |
| 偏差 err | 目标值 − 测量值 | 还差多少度 |
| Kp | 比例系数：对当前偏差出多大力气 | 手感猛不猛 |
| Ki | 积分系数：对历史累计偏差补多少账 | 记仇程度 |
| Kd | 微分系数：对偏差变化趋势踩多少刹车 | 刹车提前量 |
| 超调 | 冲过目标再回来的幅度 | 先烫一下才稳下来 |
| 稳态误差 | 稳定后仍差的那一小截 | 永远差 5°C 上不去 |
| 采样/控制周期 | 每隔多久算一次 PID 并更新输出 | 多久看一眼表盘 |

## 3. 闭环框图

```
 目标值(50°C)
     │
     ▼
  [+/-]──偏差 err──► PID 计算 ──► PWM 占空比 ──► MOS 驱动 ──► 加热膜
   ▲   │                                                        │
   │   └───────────────(被控对象温度)◄─────────────────────────┘
   │
   └── NTC/ADC 采样 ◄──────── 温度传感器
```

流程：目标 − 测量 = 偏差 → PID 算出占空比 → PWM 驱动加热 → 温度变化 → 传感器回采 → 修正下一拍。ADC 采集链路在 [05-DMA与ADC](../../07-STM32/笔记/05-DMA与ADC.md)。

## 4. P 项：当前偏差说了算

**公式**：`输出_P = Kp × err`。

代入算例：目标 50°C，当前 30°C，err = 20，Kp = 2 → P 项 = 40% 占空比。差越大出力越猛，合理。

**但只用 P 有个致命伤：稳态误差。** 推一遍：

- 假设温度到某一值时，环境散热刚好相当于"10% 占空比的加热量"在漏；
- 要顶住这 10% 的漏，P 项必须输出 10% → 需要 err × Kp = 10 → err = 10 ÷ 2 = **5°C**；
- 于是温度永远停在 45°C——差 5°C 时 P 项出的力刚好补漏，再多一分力都没有了。

**P 独木难支的结论**：加大 Kp 能压小稳态误差，但 Kp 太大会引起振荡（第 9 节整定的核心权衡）。要"归零稳态误差"，得请出 I。

## 5. I 项：把历史欠账补上

**公式**：`输出_I = Ki × Σ(err × dt)`——把每拍偏差按时间累积起来（dt = 控制周期，秒）。

代入算例（接上例：稳态卡在 45°C、err = 5°C 不动；dt = 0.1s）。看两种 Ki 的表现：

- **Ki = 0.01**：每拍 I 项输出增量 = 0.01 × 5 × 0.1 = 0.005%——100 拍（10 秒）才涨 0.5%，补完 10% 的漏热缺口要约 200 秒：稳态误差终会归零，但太慢，Ki 偏小；
- **Ki = 1.0**：每拍增量 = 1.0 × 5 × 0.1 = 0.5%——10 秒补 50%，账还得飞快，但惯性巨大：温度冲过目标后积分还在高位，要靠负偏差把它"往回还"，表现为来回摆，Ki 偏大；
- **工程取法**：取"能接受的收敛速度下尽量小"——本篇示例取 Ki = 0.1 起步（每拍 0.05%，10 秒补 5%，经验值）。

**I 的副作用**：它有惯性——欠账还清了它还在累，目标到达后"刹不住车"造成超调，这就是第 8 节"抗积分饱和"要治的病。

## 6. D 项：提前踩刹车

**公式**：`输出_D = Kd × (err_本拍 − err_上拍) ÷ dt`——偏差变化越快，刹车越狠。

代入算例（dt = 0.1s，Kd = 0.5）：

- 上拍 err = 8，本拍 err = 6 → 变化率 = (6 − 8) ÷ 0.1 = −20 °C/s；
- D 项 = 0.5 × (−20) = **−10% 占空比**——温度正快速逼近目标（err 在缩小），提前收油门 10%，压制超调；
- 温度离目标还远、err 还在变大时，D 项为正——帮着一起加速，不拖后腿。

**D 的弱点**：对测量噪声极其敏感——NTC 读数抖 ±1°C，差分项就疯狂跳（坑 2）。真实工程里 D 项系数保守，或先对测量值滤波再喂 PID。

## 7. 合体：位置式与增量式

**位置式（本篇主线）**：

```
u = Kp×err + Ki×Σ(err×dt) + Kd×(Δerr/dt)
```

输出 u 直接就是"执行器该处的位置"（PWM 占空比 0~100%），嵌入式温控/调速的大多数场景用它。

**增量式**：每次只算"输出该变多少"（Δu = 本拍输出 − 上拍输出），适合执行器只吃增量（如步进电机脉冲），或希望积分饱和处理更简单时。两者本质等价，嵌入式先用位置式跑通，够用了。

| 对比 | 位置式 | 增量式 |
|------|--------|--------|
| 输出含义 | 直接给占空比 | 给"相对上一拍的增量" |
| 积分饱和 | 要显式处理（第 8 节） | 天然较弱 |
| 适用 | PWM/阀门开度类 | 步进/增量执行器 |

## 8. 代码逐段拆解（可直接抄的结构体版）

```c
typedef struct {
    float kp, ki, kd;        /* 三个系数 */
    float setpoint;          /* 目标值 */
    float integral;          /* 积分累计 Σ(err×dt) */
    float last_err;          /* 上一拍偏差（供 D 项差分） */
    float out_min, out_max;  /* 输出限幅（0~100 口径） */
    float int_max;           /* 积分限幅（抗饱和） */
} PID_t;

float PID_Update(PID_t *p, float measured, float dt)
{
    float err = p->setpoint - measured;              /* ① 当前偏差 */

    p->integral += err * dt;                         /* ② 积分累加 */
    if (p->integral >  p->int_max) p->integral =  p->int_max;  /* ③ 抗饱和 */
    if (p->integral < -p->int_max) p->integral = -p->int_max;

    float deriv = (err - p->last_err) / dt;          /* ④ 差分近似求导 */
    p->last_err = err;

    float out = p->kp * err
              + p->ki * p->integral
              + p->kd * deriv;                       /* ⑤ 三项加权合成 */

    if (out > p->out_max) out = p->out_max;          /* ⑥ 输出限幅 */
    if (out < p->out_min) out = p->out_min;
    return out;
}
```

逐段为什么：

- ② 累加的是 `err × dt` 而不是裸 err——dt 写进积分里，换控制周期时 Ki 语义不漂移；
- ③ **抗积分饱和**：开机时 err 很大（比如 30°C），积分一路狂涨；等温度到了，光"还账"就要很久 → 冲过头（超调元凶）。int_max 把积分封顶，饱和期间不许再涨；
- ④ 用差分代替真实求导——离散系统没有"连续导数"，差分就是工程近似；
- ⑥ 输出限幅别省——算出 137% 的占空比写进 CCR 会溢出成诡异值。

调用示例（100ms 控制周期）：

```c
PID_t heater = { .kp = 2.0f, .ki = 0.1f, .kd = 0.5f,
                 .setpoint = 50.0f, .integral = 0, .last_err = 0,
                 .out_min = 0, .out_max = 100, .int_max = 60 };

/* 每 100ms 调用一次（定时器中断或 RTOS 周期任务均可），dt 固定传 0.1f */
float duty = PID_Update(&heater, ntc_temp, 0.1f);
__HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1,
                      (uint32_t)(duty / 100.0f * __HAL_TIM_GET_AUTORELOAD(&htim3)));
```

PID_Update 三要素：不阻塞（纯计算，µs 级）；时间单位由 dt 决定（本篇口径为秒）；可在 ISR 中调用（但要快，且若任务与 ISR 共用同一实例需临界区保护——保护手段与语义见 [03-信号量与互斥量](../../08-FreeRTOS/笔记/03-信号量与互斥量.md)）。

## 9. 参数整定：现场手感四步法

> **这是什么**：不背公式、看现象调参数的土办法——嵌入式现场大多数 PID 就是这么调出来的。

| 步骤 | 动作 | 看什么现象 | 判据 |
|------|------|-----------|------|
| 1. 只留 P | Ki=0、Kd=0，Kp 从小往大加 | 逼近目标的速度 vs 振荡 | 温度开始小幅振荡 → Kp 回退到约 6 成 |
| 2. 加 I | Ki 从很小起步 | 稳态误差是否消除、是否来回摆 | 误差归零且不摆；摆了就减 Ki |
| 3. 加 D | Kd 从很小起步 | 冲过目标的幅度（超调） | 超调收窄；输出发抖就减 Kd |
| 4. 复验 | 目标值突跳一次（50→60°C） | 全程曲线 | 快、稳、超调小，按项目取舍 |

整定口诀（经验值）：**P 管快慢、I 管归零、D 管刹车；先 P 后 I 再 D，一次只动一个。**

延伸：教科书还有 Ziegler-Nichols 临界比例法等公式化整定（临界振荡后按公式配参）——知道名字即可，真到需要时再查【延伸自查：Ziegler–Nichols tuning】；工业温控器产品里封装的"自整定"本质也是这类方法的自动化。

## 10. 全链路落地：NTC + 加热膜 + PWM

把三块主线知识串成一台恒温台：

1. **测温**：NTC 分压 → ADC 采样（选型与接入在 [02-传感器应用专题](02-传感器应用专题.md)；ADC+DMA 在 [05-DMA与ADC](../../07-STM32/笔记/05-DMA与ADC.md)）；每拍采多次做滑动平均再喂 PID（治 D 项噪声敏感）；
2. **执行**：PWM 输出 → MOS 驱动加热膜（PWM 配置与占空比计算在 [03-定时器与PWM](../../07-STM32/笔记/03-定时器与PWM.md)；MOS 选型在 [07-工业常用元器件速查手册](../../02-电路基础/笔记/07-工业常用元器件速查手册.md)）；
3. **周期**：热惯性大，控制周期 100ms~1s 都行（经验值）——不是越快越好（坑 5）；用定时器中断或 RTOS 周期任务固定节拍，dt 与节拍严格一致；
4. **验证**：串口每秒把"目标值 + 实测值"发到 PC，Excel/串口示波器画曲线——**没有曲线就没有整定**，肉眼盯数字调不出 PID。

若整机是电池供电，加热是耗电大头，控制策略与睡眠调度的衔接在 [03-低功耗设计实战](03-低功耗设计实战.md)。

## 工程实操任务

- [ ] 搭最小温控台：NTC + 加热膜（或大功率电阻）+ PWM 驱动 MOS；先只用 P（Ki=Kd=0），观察并记录稳态误差，验证第 4 节推导；
- [ ] 加入 Ki 直到稳态误差消失，记录"开始来回摆"的 Ki 临界值；
- [ ] 加入 Kd 压超调，串口输出温度曲线，对比加 D 前后的超调幅度；
- [ ] 做一次"目标值 50→60°C"突跳实验，观察超调，再清零积分重跑对比差异；
- [ ] 把 PID_Update 移植到你的现有项目（风机调速/舵机保持/恒流源任选），从 Kp=1 起步整定。

## 常见坑（新手必看）

1. **dt 与实际调用周期不一致**：定时器周期改了、dt 没改——I/D 项数值含义全变，PID 第一大坑；dt 必须严格等于真实节拍；
2. **噪声把 D 项打疯**：NTC 读数抖 ±1°C，差分项疯狂跳——先滑动平均/一阶低通滤波再喂 PID，或减小 Kd；
3. **没有抗积分饱和**：开机大偏差让积分狂涨，到温后"还账"造成大超调——int_max 限幅是标配；
4. **输出没限幅**：137% 的占空比写进 CCR 直接溢出——out_min/out_max 必须设；
5. **控制周期盲目求快**：热惯性大，10ms 控一次没意义还放大噪声——温控 100ms~1s（经验值），匹配对象惯性；
6. **目标值突变不清积分**：改 setpoint 后旧积分"拉后腿"——大阶跃切换时清零 integral 再跑；
7. **中断里干重活**：浮点 PID 放高频中断挤崩实时性——控制计算放任务，ISR 只做节拍标记（ISR 纪律见 [05-内存管理与中断处理](../../08-FreeRTOS/笔记/05-内存管理与中断处理.md)）。

## FAQ

**Q：为什么不直接用开关控制？**
A：简单场景（水族箱加热棒）开关控制完全够用。PID 换来的是"平稳曲线 + 执行器寿命 + 无稳态误差"——需要控温精度，或执行器娇贵（继电器频繁通断伤触点）时上 PID。

**Q：Ki 的单位到底是什么？**
A：取决于公式写法：本篇代码积分用 Σ(err×dt)，Ki 量纲是"输出单位/（被控量单位·秒）"——工程上别死抠量纲，按第 9 节现场手感调出来就是对的；换写法（如积分不乘 dt）时 Ki 数值含义会变，抄代码要连口径一起抄。

**Q：微分先行、不完全微分是什么？**
A：进阶改进：前者对测量值而非偏差做微分（避免目标突变时 D 项打满），后者给 D 项串一阶低通（治噪声）。先把本篇基础版跑通，确有需要再升级。

**Q：PID 能用于电机调速吗？**
A：能，同构：目标转速 − 编码器实测转速 = 偏差，输出 PWM。速度环 PID 是电机控制的地基；电流环/位置环是更快的内环，属进阶方向。
