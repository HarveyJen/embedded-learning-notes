# 01 · 电源设计进阶

> 定位：[04-电源与稳压电路](../../02-电路基础/笔记/04-电源与稳压电路.md) 讲了 LDO 和 DC-DC "是什么、为什么"，本篇讲"怎么选、怎么算、怎么测"——给你一套能直接用在项目里的计算和实测流程。

**先说人话**：本篇讲什么，学完能做什么——

主线篇告诉你"12V 转 3.3V 别用 LDO，会烫"；本篇回答接下来的问题：**那 DC-DC（Buck）外围那些电感、二极管、电容到底怎么算出来的？** 本篇用 12V→3.3V/1A 一个例子把 Buck 外围五步算完，再补上锂电池充电、多路电源的电源树画法、纹波和效率的实测手法。学完你能：拿到一个供电需求，自己算出一版 Buck 外围器件清单、画出电源树、用示波器测出可信的纹波和效率数据。

## 1. LDO vs DC-DC：四维深化选型表

> **这是什么**：选供电方案就像选交通工具——LDO 是"直达慢车"（省事、安静/干净，但费油=发热），DC-DC 是"换乘快车"（高效，但一路叮咣响/有纹波）。四维对比看清楚谁上场。

| 维度 | LDO | DC-DC（Buck） |
|------|-----|---------------|
| 效率 | ≈ Vout/Vin，压差大时惨（12V→3.3V 只有 27%） | 85~95%（典型经验值） |
| 纹波/噪声 | 极小（µV~几十µV 级），最干净 | 几十~几百 mV 开关纹波 + 开关噪声 |
| 成本/外围 | 便宜，外围只需输入输出电容 | 稍贵，外围需电感+二极管/MOS+多颗电容 |
| 热 | 压差×电流全部变热 | 热小，大电流也扛得住 |

**什么时候死守 LDO**：压差小（≤1V 级）、电流小（几百 mA 内）、给 ADC 基准/射频/运放供电要"干净"——干净这一条 DC-DC 换不来。锂电池 3.7~4.2V → 3.3V 用 LDO 就是经典好场景。

**什么时候必须 DC-DC**：压差大（12V→3.3V 这类）、电流大（≥0.5~1A）、对效率敏感（电池续航）——发热这条 LDO 物理上过不去。

一板多轨的常见套路（工程常用组合）：DC-DC 先把大压差砍下来，LDO 在后级"精修"给敏感电路——前级效率归 DC-DC，后级干净归 LDO。

典型场景对号入座：

| 场景 | 方案 | 一句话理由 |
|------|------|-----------|
| USB 5V → 3.3V，几百 mA | LDO | 压差小，LDO 便宜又干净 |
| 12V 适配器 → 3.3V，1A | Buck | LDO 方案发热 (12−3.3)×1 = 8.7W，物理不可行 |
| 锂电 3.7~4.2V → 3.3V | LDO（低压差型） | 压差仅 0.4~0.9V，LDO 效率也不差 |
| 12V → 3.3V 的 ADC 基准/运放供电 | Buck 后接 LDO | 效率给 Buck，干净给 LDO |
| 电池供电续航优先 | Buck 为主，休眠策略配合 | 效率每一分都是续航 |

## 2. Buck 外围计算五步法（12V→3.3V/1A 完整算例）

> **这是什么**：Buck 就是"高频开关 + 电感储能 + 电容稳压"的搬运工。外围器件不是抄别人的板子抄来的，五步能全算出来。以下开关频率按 f = 500kHz 举例【示例值，实际以所选芯片 datasheet 为准】。

**题目**：输入 12V，输出 3.3V / 1A，纹波目标 ≤50mV（经验目标值）。

### 第一步：占空比估算

理想 CCM（连续模式）下 D ≈ Vout / Vin = 3.3 / 12 ≈ **0.275**。含义：开关管每个周期约 27.5% 时间导通"灌能量"，剩下时间电感续流。实际因管子压降会略大一点，估算够用。

### 第二步：电感选型（纹波电流法）

电感电流是带纹波的三角波：波峰 = 负载电流 + 一半纹波，波谷 = 负载电流 − 一半纹波。**纹波电流取多大是设计选择**：经验值取输出电流的 20%~40%，我们取 30%：

```
ΔIL = 0.3 × 1A = 0.3A
L = Vout × (1 − D) / (f × ΔIL)
  = 3.3V × (1 − 0.275) / (500kHz × 0.3A)
  = 2.39 / 150000
  ≈ 16µH  → 取标准值 15µH 或 22µH
```

选 22µH 复核：ΔIL = 2.39 / (500kHz × 22µH) ≈ 0.22A（约 22%，在 20%~40% 内，合理）。

**峰值电流**：IL_peak = Iout + ΔIL/2 = 1 + 0.11 ≈ 1.11A。电感规格里"额定电流"和"饱和电流"是两回事，**按饱和电流选且留余量**：取 ≥1.5 倍 ≈ 1.7A 以上（经验值）。电感一饱和感值骤降，纹波飙升，下一秒炸管。

### 第三步：续流二极管（非同步 Buck）/ 同步 MOS

开关管关断时，电感电流得有路走——这条路就是续流二极管（同步 Buck 用低边 MOS 替代它，效率更高）。

- **类型**：必须肖特基——正向压降低、几乎没有反向恢复时间。拿整流管 1N4007 来当续流管 = 发热大王；
- **反向耐压**：按 ≥2 × Vin 取 ≥30V（经验余量，以 datasheet 为准）；
- **平均电流**：≈ Iout × (1 − D) = 1 × 0.725 ≈ 0.73A → 选 3A 级（如 SS34 这类 40V/3A 规格档，具体型号以 datasheet 为准）。

### 第四步：输出电容（纹波与 ESR）

输出纹波 = 电容充放电分量 + ESR 分量（文字解释：三角波电流流进电容，一半时间充电一半放电，容量决定"水位"涨落；同时纹波电流流过 ESR 直接产生压降；系数 1/8 来自三角波积分）：

```
ΔVout ≈ ΔIL / (8 × f × Co) + ΔIL × ESR
容量项：Co ≥ ΔIL / (8 × f × ΔVout) = 0.3 / (8 × 500kHz × 0.05V) ≈ 1.5µF
ESR 项：ESR ≤ 0.05V / 0.3A ≈ 0.17Ω —— 陶瓷电容轻松满足
```

结论：容量项算出来不大，但那是"刚好及格"——考虑负载瞬态、温度、老化，实取 **22µF~47µF 陶瓷电容**（经验值），并优先低 ESR。

### 第五步：输入电容与布局注意

输入侧电流是矩形脉冲（开关通断），输入电容负责"就近供水"，免得脉冲电流长途跋涉把输入线变成辐射天线：常用 **10µF~22µF 陶瓷贴 VIN-GND**【经验值，大电流时按 datasheet 加电解】。

布局铁律：VIN → 输入电容 → 芯片 → SW 节点 → 电感 → 续流管/MOS 回到地，这条**"热回路"面积最小化**；输入电容与输出电容的接地就近汇合，别隔着长走线。细节原理见 05-EDA [06-PCB设计进阶](../../05-EDA与生产工具/笔记/06-PCB设计进阶.md) 的回流路径一节。

> 以上五步是"手算版"工程流程；实际选型时把算出的 L、Co、耐压、电流拿去对芯片 datasheet 推荐值和电感/电容规格书复核。

## 3. 锂电池管理入门

> **这是什么**：锂电池是"脾气大但能干"的电芯：充电要按曲线伺候，用过界会闹脾气（鼓包甚至起火）。所以给它配"保姆"：充电管理芯片 + 保护板。

**三段充电曲线**（典型值，以电芯规格书为准）：

```
电压低于约 2.9~3.0V：涓流预充（小电流"唤醒"，约 0.1C）
        ↓
恒流段 CC：约 0.5C 充到 4.2V（0.5C 是常用经验值）
        ↓
恒压段 CV：顶住 4.2V，电流自然衰减到截止电流（约 C/10~C/20）即充满
```

**保护板三大保护**：过充保护（约 4.25~4.3V 断充电）、过放保护（约 2.4~2.8V 断放电）、过流/短路保护——三道保险丝逻辑，任何一个缺了都可能出安全事故。

学习项目常见组合（泛化描述，具体型号以 datasheet 为准）：线性充电芯片（如 TP4056 一类 1A 档【参数以 datasheet 为准】）负责三段曲线 + 外置/板载保护板负责三大保护——两颗料各干各的活，别指望充电芯片兼任安全员。

```
USB 5V ──> 充电管理芯片（三段曲线）──> 电芯 ──> 保护板 ──> 系统负载
                                              │
                              （过充/过放/过流时切断）
```

**电量显示两种路线一句话**：粗略法 = 测电池电压查"电压-容量"曲线（便宜，但锂电池中段电压平台太平，40% 和 70% 电压差不多，不准）；库仑计 = 串联采样电阻积分电流算消耗（准，但要校准、有累积误差）。学习项目用电压粗略法够用，正经产品用库仑计芯片。

## 4. 电源树设计方法

> **这是什么**：一块板要好几路电压（3.3V 的 MCU、5V 的外设、1.8V 的 Flash……），先画一棵"树"理清谁从哪来，再逐级选型——这棵树就叫电源树。类比家里的电路箱：进线总闸 → 各支路空开 → 各房间，先画图再布线。

四步画法：

1. **画树干**：输入（如 12V 适配器）→ 保护（保险丝 + 防反接 + TVS）→ 各级转换 → 各轨。一级一级往下画，不许跳级凭空出电压；
2. **列需求表**：每轨一行——电压 / 最大电流 / 喂给谁 / 纹波要求 / 上下电有无顺序要求；

| 轨 | 电压 | 电流 | 负载 | 纹波要求（经验） |
|----|------|------|------|------------------|
| 主控轨 | 3.3V | 1A | MCU/数字外设 | ≤50mV 可接受 |
| 外设轨 | 5V | 0.5A | 显示/传感器/运放 | 敏感负载 ≤20mV 或后级 LDO |

3. **逐级选型**：大压差、大电流 → DC-DC；小压差、敏感轨 → LDO（或 DC-DC 后加 LDO 精修）；
4. **复查三件事**：每级功率与热是否超标、纹波逐级叠加后敏感端是否达标、上电顺序是否满足（有的芯片要求内核先于 IO 上电，以 datasheet 为准）。

以本篇实操任务为例的树图骨架（供对照，答案自己做）：

```
12V 输入 ──> 保险丝 + 防反接 + TVS（保护级）
                │
                ├──> Buck1 ──> 3.3V/1A（主控轨：MCU/数字外设）
                │
                └──> Buck2 ──> 5V/0.5A（外设轨：显示/传感器）
                                  └──（可选）LDO ──> 敏感模拟供电
```

注：12V→5V/0.5A 若用 LDO，发热 = (12−5)×0.5 = 3.5W——又一个"物理不可行"案例，所以两轨都指向 Buck；具体论证写进你的实操笔记。

## 5. 纹波与效率实测

> **这是什么**：算得再好也要实测说话。纹波 = 输出电压上的"高频小抖动"（mV 级）；效率 = 输出功率 ÷ 输入功率，衡量"搬运工偷了多少油钱变成热"。

**纹波实测四步（示波器）**：

1. 探头打 ×10 挡；**带宽限制设 20MHz**——原因：挡掉示波器前端和环境的高频毛刺，只关心电源本身频段的纹波，否则读数被无关高频污染；
2. **耦合方式设 AC**——原因：纹波是叠加在直流上的 mV 级交流，DC 耦合时直流分量占满量程，mV 级纹波被压成一条线看不清；AC 耦合隔掉直流，专看抖动；
3. **接地用接地弹簧，别用长地线夹**——原因：长地线绕成环像一圈天线，捡起空间磁场，读出"假纹波"；
4. 探针点在**输出电容两端**，满载下读 Vpp。

**效率实测步骤**：

```
效率 η = (Vout × Iout) / (Vin × Iin)
四只万用表（或两只有功率读数的）分别测：Vin、Iin、Vout、Iout
分别测：空载、半载（0.5A）、满载（1A）三组——效率是随负载变的曲线，不是一个数
```

数值合理性自查：12V→3.3V/1A 若实测效率 60% 以下，先查是不是二极管用了慢管、电感饱和了——实测数据是排障线索，不是终点。

## 常见坑（新手必看）

1. **电感饱和**：只看"额定电流"不看"饱和电流"，满载一上感值骤降、纹波飙升、管子过流——按饱和电流选并留 1.5 倍余量（经验值）；
2. **续流二极管选慢管**：拿 1N4007 整流管当续流管，反向恢复慢，每周期"白烧"一段功率，发热严重还拖垮效率——必须肖特基；
3. **示波器地线环引入假纹波**：长地线夹绕成一圈天线，测出的"纹波"其实是捡来的干扰——用接地弹簧短接地，读数立刻可信；
4. **钽电容耐压顶格用**：钽电容过压失效模式是短路起火，耐压按降压 50% 用（6.3V 轨选 10V 以上，经验值），别学陶瓷电容"留 20%"那套；
5. **地弹 / 接地混乱**：大电流地（DC-DC、继电器）与敏感地（ADC 基准）共用一段细长地线，开关噪声窜进模拟端——大电流地就近单点汇接，别串联长线；
6. **只看输出不看输入**：输入电容不贴 VIN 或容量不够，输入线变成发射天线，整板 EMI 变差——热回路面积最小化是布局第一原则。

## FAQ

**Q：Buck 开关频率越高越好吗（体积小）？**
A：频率高电感电容可以小，但开关损耗上升、对布局更苛刻；常见芯片几百 kHz~2MHz 档【以具体芯片为准】，新手选厂商推荐值即可，别贪高频。

**Q：既然 DC-DC 效率高，为什么还留 LDO？**
A：效率是 DC-DC 的强项，"干净"是 LDO 的强项。ADC 基准、射频、运放供电对噪声敏感，DC-DC 的开关纹波会直接进信号链——前级 DC-DC、后级 LDO 是标准组合。

**Q：用了 DC-DC 还需要去耦电容吗？**
A：需要，而且不能省。DC-DC 只是"稳住大轨"，芯片脚上的高频抽电仍要就近去耦电容兜底，两件事管不同频段。

**Q：电感是不是越大纹波越小越好？**
A：纹波确实变小，但大电感体积大、直流电阻大（更热）、瞬态响应变差——纹波 20%~40% 这个经验区间是平衡点，别走极端。

**Q：保护板和充电管理芯片是一回事吗？**
A：不是。充电管理芯片按曲线"伺候充电"；保护板是"出事时拉闸"的安全员（过充/过放/过流）。正经设计两者都要有。
