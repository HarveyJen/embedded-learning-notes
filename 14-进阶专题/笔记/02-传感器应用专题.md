# 02 · 传感器应用专题

> 定位：把散在各主线笔记里的传感器知识收拢成一张网——选型有流程、接入有清单、参数有速查表，做采集类项目前先翻这一篇。

**先说人话**：本篇讲什么，学完能做什么——

主线里你零散见过它们：02-电路基础讲过热敏电阻和元器件速查，07-STM32 讲过 ADC 采它，03-模电讲过前端调理。但真做"环境监测小站"这种项目时，一开口就卡住：**SHT30 和 DHT11 选哪个？I2C 地址撞了怎么办？模拟传感器数值乱跳怪谁？** 本篇把这些问题收成一张网：五大指标看懂 datasheet、三类输出信号决定接入方式、一张速查表+一套选型五问+一份接入 Checklist。学完你能给自己的项目写出一张有理有据的传感器选型表。

## 1. 传感器五大指标大白话

> **这是什么**：datasheet 第一页那几个词，决定你选的传感器"能不能干这活"。用一台电子秤类比最直白。

| 指标 | 大白话 | 电子秤类比 |
|------|--------|-----------|
| 量程 | 能测的范围，超出会坏或读不准 | 这秤能称多重（超了直接压坏） |
| 精度 | 测出来离真值差多少（±0.5°C 这种） | 称得准不准：标 500g 实际是不是 500g |
| 分辨率 | 能读出多细的差别 | 能分出 0.1g 还是一格就是 1g |
| 灵敏度 | 被测量动一点，输出动多大 | 放 1g 砝码，指针跳几格 |
| 响应时间 | 输入变了，多久给出稳定读数 | 放上去多快数字停稳 |

最容易混的是**精度 vs 分辨率**：分辨率是"刻度多细"，精度是"刻度准不准"——能显示 0.01°C 不代表准到 0.01°C，可能显示细但偏差 ±2°C。**量程顶格选**是另一大误区：经常测 40°C 却买 0~150°C 的，把你需要的区间"挤"在量程一小段里，白白浪费分辨率（选型按需求留 20%~30% 余量即可，经验值）。

**分辨率代入算一算**（数字总线类）：12 位 ADC、基准电压 3.3V，一格 = 3.3V ÷ 2¹² ≈ 3.3V ÷ 4096 ≈ **0.81mV**——NTC 分压后想分辨 0.1°C 的温差，先算出 0.1°C 对应多少 mV 的电压变化，再和 0.81mV/格对照：变化量不足一格，读数就"抖不出来"，要么换更高位数的 ADC，要么用放大环节把信号先拉开。

**这五个数在 datasheet 里去哪找**：通常在首页的"特性（Features）"或正文第一张"电气特性表（Electrical Characteristics / Performance）"——注意分清"典型值（Typ）"和"最大/最小值（Max/Min）"：选型时按 Max/Min 留余量，Typ 只作参考。环境相关的指标（如湿度传感器的响应时间）常注明测试条件（如"63% 阶跃响应"），换了自己的工况要重新审视。

## 2. 输出信号三类型与接入方式对照

> **这是什么**：传感器再花哨，输出就三种"说话方式"：给一个电压（模拟）、给一串脉冲（数字脉冲）、通过总线报数（数字总线）。说话方式决定你怎么"听"（接入方式）。

| 输出类型 | 接入方式 | STM32 侧用什么 | 典型代表 |
|----------|----------|----------------|----------|
| 模拟电压 | 分压/放大/滤波等调理后进 ADC | ADC（+DMA 连续采样） | NTC 热敏电阻、光敏电阻、MQ 系列、运放调理后的信号 |
| 数字脉冲 | 计数或测脉宽 | 定时器计数/输入捕获/编码器模式 | HC-SR04 回波、霍尔开关、增量编码器 |
| 数字总线 | 写驱动按协议读数 | I2C / SPI / 单总线（GPIO 模拟或外设） | SHT30、BH1750、MPU6050、DS18B20 |

- 模拟链路的调理电路（放大、滤波、阻抗匹配）在 [05-负反馈与模拟前端实战](../../04-模拟电路基础/笔记/05-负反馈与模拟前端实战.md) 展开，ADC+DMA 的采法在 [05-DMA与ADC](../../07-STM32/笔记/05-DMA与ADC.md) 展开，本篇负责"选型与接入总图"；
- 三类型选择直觉：要绝对数值且省事 → 总线型；要快且便宜 → 模拟型；要测转数/距离事件 → 脉冲型。

一个例子串起三类：同一辆小车上——NTC（模拟）测电池温度进 ADC；HC-SR04（脉冲）测前方障碍用定时器捕获回波；MPU6050（总线）走 I2C 报姿态。三路数据互不干扰，是因为接入方式天然隔离：ADC 通道、定时器通道、I2C 总线各走各的口——选型时"接口资源够不够"问的就是这些口还剩几个。

三种类型的代价对比（选择时心里有杆秤）：

| 对比项 | 模拟电压型 | 数字脉冲型 | 数字总线型 |
|--------|-----------|-----------|-----------|
| 器件成本 | 通常最低 | 低~中 | 中 |
| 硬件开发量 | 大（调理+滤波+标定） | 中（计数/捕获配置） | 小（拉上拉接总线） |
| 软件开发量 | 中（采样+滤波+换算） | 中（捕获/解码） | 中（写驱动+校验） |
| 抗干扰 | 弱（线上一路捡噪声） | 中（脉冲也怕耦合） | 强（有校验和/协议帧） |
| 多点扩展 | 每路占一个 ADC 通道 | 每路占一个定时器通道 | 一条总线挂多颗（注意地址） |

## 3. 常用传感器速查表

> **这是什么**：学习项目最常碰头的十位选手一张表。**表中参数均为典型值，选型下单前一律以原厂 datasheet 为准**。接口协议基础在 [07-工业常用元器件速查手册](../../02-电路基础/笔记/07-工业常用元器件速查手册.md) 有元器件级速查，本表是"整机传感器"视角。

| 型号 | 测什么 | 接口 | 量程/精度（典型值，以 datasheet 为准） | 典型应用 |
|------|--------|------|----------------------------------------|----------|
| DS18B20 | 温度 | 1-Wire 单总线 | -55~+125°C；±0.5°C（-10~85°C 段）；9~12 位可配 | 多点测温（一根总线挂多颗）、水温土壤温 |
| SHT30 | 温度+湿度 | I2C | 0~100%RH，±2~3%RH；-40~125°C，±0.2~0.3°C 档 | 室内环境监测、加湿器 |
| BH1750 | 光照度 | I2C | 1~65535 lx | 自动调光、日照记录 |
| HC-SR04 | 距离 | GPIO 触发 + 回波脉宽（定时器捕获） | 2~400cm 标称 | 倒车雷达、避障小车 |
| MPU6050 | 三轴加速度+三轴角速度 | I2C | 加速度 ±2/4/8/16g；陀螺 ±250~2000 dps | 姿态检测、平衡车、计步 |
| MQ-2 / MQ-135 | 可燃气体/烟雾；空气质量综合 | 模拟电压（分压输出） | 相对浓度指示（无绝对 ppm 精度），需预热 | 烟雾报警、空气质量站 |
| A3144（霍尔开关） | 磁场有无 → 转速/位置 | 数字开关量 | 开关型输出，需配磁钢 | 转速计、门磁限位 |
| 增量编码器 | 转角/转速 | AB 正交脉冲 | 分辨率看线数（PPR） | 电机测速、旋钮输入 |
| NTC 热敏电阻 | 温度 | 模拟（分压 → ADC） | B 值 3435/3950 常见；非线性需查表/公式换算 | 成本敏感测温、电池包测温 |
| 光敏电阻 | 光照强弱（相对） | 模拟（分压 → ADC） | 无绝对 lux 值，只判相对亮暗 | 光控灯、昼阴判断 |

**这张表怎么用**：按"测什么"竖着找候选 → 对着"接口"列问自己"我板子上还有这种口吗" → 看量程精度是否罩住需求 → 最后用选型五问（下一节）正式过一遍。表里没有的型号，也按同样列信息自己补一行——你自己的速查表才是最好用的。

接线速记图（以 I2C 数字型与模拟分压型为例）：

```
I2C 数字型（如 SHT30/BH1750）            模拟分压型（如 NTC/光敏电阻）
  MCU VDD(3.3V) ─┬─ 传感器 VCC            3.3V ──[10kΩ]──┬── ADC 引脚
                 │  0.1µF 去耦到 GND                     │
  MCU SDA ──[4.7kΩ 上拉到 3.3V]──┬─ 传感器 SDA        NTC/光敏      │
  MCU SCL ──[4.7kΩ 上拉到 3.3V]──┼─ 传感器 SCL           │          │
                                │                      GND ────────┘
  MCU GND ───────────────── 传感器 GND
```

快速选型直觉：要"绝对数值"选 I2C 数字型（SHT30/BH1750）；要"便宜量大"选模拟型（NTC/光敏电阻，代价是自己做调理+标定）；要"事件与转速"选脉冲型（霍尔/编码器）。

每类挑一个代表，记"接入要点"各一条：

- **NTC（模拟代表）**：分压电阻选值接近 NTC 标称阻值时，中段灵敏度最好；换算用 B 值公式或查表，别手搓线性拟合——它天生非线性；
- **HC-SR04（脉冲代表）**：回波脉宽用定时器输入捕获测，超时保护必须加（没测到物体时回波不会来，程序会卡死在等待）；
- **SHT30（总线代表）**：I2C 地址由 ADDR 引脚决定（0x44/0x45 两个可选，典型值），读数前先"扫地址"确认器件应答；
- **MQ 系列（预热代表）**：上电加热丝先工作，几分钟到几十分钟内读数不可信，程序里先跳过或标注"预热中"。

## 4. 选型五问流程

> **这是什么**：买传感器前过五关，一问一分钟，避免"买回来才发现接不上"。像相亲前先问清楚五件事，别见面了才谈条件。

1. **测什么**：物理量是什么？温度还是湿度还是"空气质量"这种模糊量？（模糊量先定义成可测代理量，比如 MQ-135 的相对浓度）；
2. **量程与精度**：实际要测的范围内、要多准？（把最恶劣工况列出来，量程留 20%~30% 余量，经验值）；
3. **接口资源够不够**：MCU 还剩几路 ADC、几路 I2C？I2C 地址会不会撞？（板上已有两颗 I2C 器件，第三颗地址冲突了没）；
4. **功耗与环境**：电池供电要算每个传感器的平均功耗；高温高湿/户外环境看工作温度范围和封装防护；
5. **价格与供货**：能买到吗？什么时候有货？有没有可替换型号？（学习项目优先选立创商城等常备货型号）。

五问全部通过才下单——任何一问卡住，回到上一步换方案，别硬上。

**五问实战示例（室内温湿度，30 秒演算）**：

| 问 | 回答 | 结论 |
|----|------|------|
| 1 测什么 | 室内温度 + 相对湿度 | 要"绝对数值"，倾向数字型 |
| 2 量程精度 | 室内 0~40°C、10~90%RH；精度 ±1 级够用 | 候选：SHT30 / DHT11 / DHT22 |
| 3 接口 | 手头板子 I2C1 还有空位 | SHT30（I2C）OK；DHT 系列占一根 GPIO 单总线协议 |
| 4 功耗环境 | 室内常供电，不苛刻 | 都可 |
| 5 价格供货 | SHT30 几元、DHT11 更便宜 | 要精度选 SHT30，要极致便宜且精度无所谓选 DHT11 |

结论示范："要 ±2%RH 以内湿度精度 → SHT30；只做'干湿有无'指示 → DHT11"——五问走完，理由自然浮出来，这就是"有理有据的选型表"。

## 5. 接入 Checklist

> **这是什么**：传感器到手接线时的"起飞前检查单"，五项全打勾再上电，能避开一大半"读数乱跳/读不到"问题。

1. **供电与去耦**：供电电压对不对（3.3V 还是 5V 器件）？VCC-GND 就近 0.1µF 去耦了吗？（检查方法：万用表量 VCC-GND 电压，示波器看 VCC 上有没有毛刺）；
2. **电平匹配**：5V 传感器输出进 3.3V MCU，要不要分压/电平转换？I2C 器件混压时上拉接到哪条轨？（检查方法：查 MCU 引脚"耐 5V 否"这一栏，引脚级以 datasheet 为准）；
3. **上拉电阻**：I2C 的 SDA/SCL 上拉（常用 4.7kΩ 级经验值）；单总线 DS18B20 的 DQ 上拉（4.7kΩ 级）；开漏输出同理；（检查方法：扫地址/单总线搜索，有应答才算通）；
4. **滤波**：模拟线靠近 MCU 入口加 RC 低通（kHz 级截止，经验值）；软件上配均值/中值滤波，别指望一次采样就准；（检查方法：同一静态点位连读 10 组，看跳动范围）；
5. **校准方法**：有没有已知基准可对？（温度用体温/冰水混合物粗校，光照用手机照度计 App 粗对，湿度这类难校的就选出厂标定的数字型）。（检查方法：和基准并排测 3 个点位，记录偏差）。

### 附：读数乱跳排查流程（文字版）

```
读数乱跳
 ├─ 供电先查：VCC 纹波/掉电毛刺？（示波器挂 VCC）
 │    └─ 有 → 加去耦/换 LDO 后级（回 01-电源设计进阶）
 ├─ 接线再查：地线共用了大电流回路？模拟线挨着电源线？
 │    └─ 是 → 改布线：模拟线短、独立回流、远离功率线
 ├─ 软件后查：单次采样？没等稳定时间？换算公式错？
 │    └─ 是 → 加均值滤波 / 等待时间 / 核对 datasheet 公式
 └─ 还跳 → 用信号发生器或电位器替换传感器验证：
       替换后稳 = 传感器/接线问题；替换后仍跳 = MCU 侧问题
```

### 附：三类信号的软件侧最小套路

| 类型 | 最小可靠套路 | 别踩的弯路 |
|------|--------------|-----------|
| 模拟电压 | 定时触发采样（DMA 连续）→ 均值/中值滤波 → 查表/公式换算 | 别在中断里做浮点换算，先存原始值回主循环算 |
| 数字脉冲 | 输入捕获测脉宽/周期 → 加超时退出 → 滤掉明显异常值 | 别用阻塞轮询等脉冲，超时保护必须配 |
| 数字总线 | 上电先扫地址确认应答 → 按协议帧读 → 校验（CRC/奇偶）失败重读 | 别跳过"应答确认"直接读数据，错位读数难排查 |

## 常见坑（新手必看）

1. **精度≠分辨率**：显示到 0.01 不代表准到 0.01——选型看精度栏，别被分辨率位数忽悠；
2. **上电即读，没等稳定时间**：MQ 系列要预热（几分钟到几十分钟量级，以 datasheet 为准），SHT30 首次测量也有响应时间——上电先等再读，否则读数"看起来坏了"；
3. **I2C 地址冲突**：同型号传感器默认地址相同，两颗挂一条总线直接打架——查 datasheet 的 ADDR 引脚能不能改地址，或换一条总线；
4. **模拟线与电源线并行**：传感器模拟输出线跟 DC-DC/继电器电源线捆一起走，耦合噪声全进 ADC——模拟线短、远离功率线，必要时屏蔽；
5. **不做软件滤波**：单次采样当真值，读数永远在跳——均值/中值/滑动窗口三选一，成本为零收益巨大；
6. **量程顶格选**：经常测 40°C 买 0~150°C，需要的区间被挤在量程一小段，分辨率白白浪费——按需求留 20%~30% 余量选（经验值）；
7. **5V 传感器直怼 3.3V 引脚**：部分 MCU 引脚不耐 5V，直连轻则读数异常重则烧脚——先查 MCU 引脚耐压，再决定分压还是换器件；
8. **驱动直接抄别人的**：网上驱动默认的地址/量程/校准值可能和你的型号批次不同——抄结构可以，参数必须按你手上的 datasheet 改一遍。

## FAQ

**Q：两颗同型号传感器读数不一样，谁坏了？**
A：大概率都没坏——离散性是常态。做法：以一颗为基准算偏差修正写进软件；要求高的场景选出厂标定的数字型（如 SHT30 级别），别指望模拟分立方案自己就准。

**Q：12 位 ADC 为什么读不出 12 位"有效"精度？**
A：位数是"能分多细"，有效精度被噪声、基准波动、前端调理误差吃掉——信号链每一段都在丢精度，改善靠硬件（去耦、滤波、基准）+ 软件（均值）双管齐下。

**Q：I2C 上拉电阻取多大？**
A：常用 4.7kΩ 级起步（经验值）：总线短、速率低可以大到 10kΩ；速率高、总线长电容大要减小到 2.2k~3.3kΩ 级——以总线电容和速率按 datasheet 公式精算。

**Q：模拟传感器和数字总线传感器哪个好？**
A：没有谁好，只有合不合：总线型省调理省标定、贵一点；模拟型便宜快、但要自己做调理滤波校准。学习项目建议各玩一次，体会差别。

**Q：datasheet 里的"典型值"能直接当设计依据吗？**
A：典型值是"平均值参考"，设计要按最小/最大值留余量；本篇速查表全部是典型值，下单前务必回原厂 datasheet 核对最小/最大值。

**Q：传感器坏了和"超出量程"怎么区分？**
A：把被测对象换到量程中段的已知状态（如室温）看是否恢复正常读数——中段恢复正常=之前是超量程/工况出界；中段仍乱=器件或接线问题。

**Q：一篇里速查表 + 五问 + Checklist 会不会重复？**
A：分工不同：速查表管"有哪些候选"，五问管"怎么淘汰到一只"，Checklist 管"买回来怎么接对"——三件工具对应选型的三个阶段，交叉引用不重复展开。
