# 04 · 高速通信与信号完整性

> 定位：主线 [07-STM32/06 通信外设](../../07-STM32/笔记/06-I2C-SPI-CAN.md) 教你"把通信跑通"，本篇教你"把通信跑稳"——当信号沿变陡、线变长、频率变高时，波形会背叛你。触发点：做长线 RS485/CAN 工业布线、SPI 提速、USB/以太网接口，或示波器上看到振铃/过冲/偶发误码时。

**先说人话**：本篇讲什么，学完能做什么——

信号在导线上跑不是"瞬移"：沿越陡、线越长，反射、串扰、回流断裂三件事越找上门，表现为振铃、过冲、误码。本篇给你三样东西：一个判断"要不要当传输线对待"的临界线长算例（1/6 法则代入）、一张常见接口终端匹配速查表（RS485/CAN 120Ω、USB 90Ω 等）、一套回流路径与布线检查单。学完你能在画板前就预防高速问题，在调试时能用示波器读懂波形在告诉你什么。

前置：本篇是 [07-EMC 与防护基础](07-EMC与防护基础.md) 的"信号质量"姊妹篇——EMC 管干扰与防护，本篇管波形与匹配；两者共用"电流走环路"的底层图像。

## 1. 什么叫"高速"：上升时间说了算，不是时钟频率

> **这是什么**：判断信号是否"高速"，看的是**边沿陡不陡（上升时间 tr）**，不是时钟快不快。陡沿才含高频成分，才会激发传输线效应。

类比：水管末端的**水锤**——阀门"砰"地关死（陡沿），管道里咣当响（反射振荡）；慢慢关（缓沿）就没事。导线对电信号同理。

为什么边沿陡 = 高频多：方波是无数正弦叠加，边沿越陡，需要的高次谐波越多。一个 1kHz 的方波若边沿只有 1ns，照样是"高速信号"——这就是"时钟低频也会踩坑"的原因。

MCU 的 GPIO/外设输出沿普遍在 ns 级（具体值查所用型号 datasheet 输出特性表，本篇算例按 tr=2ns 假设值演示口径）。这意味着：**哪怕主频不高，现代 MCU 的任何陡沿信号都可能触发本篇问题**。

## 2. 三大敌人：反射、串扰、回流断裂

| 敌人 | 机理（一句话） | 现场表现 | 典型诱因 |
|------|----------------|----------|----------|
| 反射 | 传输线阻抗突变处，信号部分弹回 | 过冲/下冲、振铃、台阶 | 线末端开路、线宽突变、分支/桩线、连接器 |
| 串扰 | 相邻走线间电场+磁场耦合 | 静止线的毛刺、并行总线互扰 | 长距离并行走线、间距不足 |
| 回流断裂 | 信号电流是环路，返回电流被"断路" | 辐射超标、边沿变缓、互扰加重 | 参考平面开槽、信号换层无回流孔 |

三条共用一个底层图像：**电流永远走环路**——出去多少就要回来多少，返回电流在参考平面（地/电源层）上沿"信号线正下方"流动（阻抗最小路径）。这个图像记住了，第 5 节的规则全是自然推论。

## 3. 临界线长算例：什么时候要按"传输线"对待

> **这是什么**：短线当"集总电路"（导线=理想连线），长线当"传输线"（要谈阻抗与反射）。分界线用 **1/6 法则**（工程经验法则）：**线长超过"信号在 tr 时间内传播距离的 1/6"时，按传输线对待。**

FR-4 板上信号传播速度经验值约 **15cm/ns**（以板材叠层为准，估算口径）。则：

```
临界线长 L_crit ≈ v × tr ÷ 6
```

代入算例（v 取 15cm/ns）：

| 上升时间 tr | 临界线长 | 工程含义 |
|-------------|----------|----------|
| 1ns | 15÷6 = 2.5cm | 极陡沿（高速外设），几乎所有走线都要当传输线 |
| 2ns（假设值口径） | 5cm | 一般 MCU 陡沿信号：超过 5cm 就要考虑匹配/控长 |
| 5ns | 12.5cm | 缓和一些，长线仍需注意 |
| 10ns | 25cm | 慢沿信号，普通板内走线多数安全 |

**换算成结论**：SPI 提到 8MHz+ 且边沿陡、USB/以太网这类协议级高速信号——走线按传输线纪律来；UART@115200 边沿被驱动器刻意放缓（很多收发器带斜率控制），板内短线通常不用匹配，但**长电缆**的主要矛盾变成衰减与抗干扰（终端匹配 + 双绞，见第 4 节与 [09/01 物理层](../../09-通信协议/笔记/01-通信协议总论与物理层.md)）。

天线效应顺手一笔（EMC 侧视角）：线长接近波长 1/4 就成了好天线——100MHz 时 λ=3m，75cm 的电缆就是辐射利器；电缆屏蔽与滤波在 [07-EMC 与防护基础](07-EMC与防护基础.md) 展开。

## 4. 终端匹配速查表（查这节就够了）

> **这是什么**：对付反射的手段是"阻抗匹配"——让信号在源头或末端"看不到阻抗突变"。

| 端接方式 | 做法 | 适用 | 要点 |
|----------|------|------|------|
| 串联端接（源端） | 驱动器出口串 22~33Ω（常见值【经验值】） | 板内点对点单负载（SPI/时钟线） | 电阻靠源放，第一次反射在源端被阻尼吸收 |
| 并联端接（末端） | 末端对地/对 VCC 接匹配电阻 | 多负载总线、长电缆 | 一直耗电，弱驱动总线慎用 |
| 差分双端匹配 | 总线两端各接 R=差分特征阻抗 | RS485、CAN | 拓扑须是"两端"——中间分支越短越好 |

常见接口匹配标准值（协议规定/行业惯例，以对应规范为准）：

| 接口 | 差分特征阻抗 | 终端 |
|------|--------------|------|
| CAN | 120Ω | 总线两端各 120Ω（ISO 11898 口径） |
| RS485 | 120Ω 量级（双绞线） | 两端各 120Ω，长线必须 |
| USB 2.0 | 90Ω | 全速/高速板级走线控 90Ω 差分 |
| 100BASE-TX 以太网 | 100Ω | 变压器/ PHY 侧按规范处理 |

CAN 终端功耗代入算例（选电阻功率用）：显性电平差分电压标称 2V，两端 120Ω 并联等效 60Ω → 终端总电流 = 2V ÷ 60Ω ≈ 33mA → 总功耗 ≈ 67mW，每只电阻分担约 33mW——常规 0603/0805 电阻（1/10~1/8W）余量充足，但选型时要有这笔账。

RS485 现场口诀：**"通信偶发乱码，先摸两端有没有 120Ω，再查拓扑是不是链（不要星形/长分支）"**——九成现场 RS485 问题在这两条里。

## 5. 回流路径：布板时最值钱的一张图

> **这是什么**：每根信号线底下，参考平面上都有一条"镜像回流"。回流断路 = 环路面积暴涨 = 电感增大 + 串扰加剧 + 辐射超标三连击。

三条纪律（详细布板手法在 [06-PCB设计进阶](../../05-EDA与生产工具/笔记/06-PCB设计进阶.md)）：

1. **高速线不许跨参考平面开槽**：地平面上的分割槽（分地、接插件挖空）是回流悬崖——信号必须跨槽时，用"桥"（跨槽处连一小段铜）或改道；
2. **换层伴随回流孔**：信号从顶层换到内层，若两层的参考平面不同（如 L1 参考地、L3 参考电源），旁边要放地过孔给回流"换乘"——高速信号每个换层过孔旁边跟一个地过孔是标准动作；
3. **晶振/时钟下方净空**：这些最强的"源"下方不放任何跨分割走线，包地处理。

生活化记忆：回流像回家——平时走正门（信号正下方），路一封（开槽）就得翻墙绕小区（大环路），路上撞的每一个邻居都是串扰。

## 6. 布线规则速查（画板前过一遍）

| 规则 | 数值/做法 | 针对哪个敌人 |
|------|-----------|--------------|
| 3W 间距 | 关键线间距 ≥ 3 倍线宽 | 串扰 |
| 关键信号短直 | 高速线能短则短，少打孔 | 反射+辐射 |
| 差分对 | 同层、等长、等距、紧耦合 | 反射+共模辐射 |
| 参考完整 | 高速线全程有完整参考平面 | 回流断裂 |
| 时钟/晶振 | 包地、下方净空、远离板边与接口 | 辐射 |
| 桩线/分支 | 总线拓扑走链式，分支长度压到最短 | 反射 |
| 板边距 | 高速线离板边 ≥ 20H（H 为板厚量级的经验口径【经验值】） | 边缘辐射 |

阻抗控制工艺说明：多层板可向板厂指定"阻抗控制"（给叠层与目标阻抗，板厂用 SI9000 类工具核算线宽）——USB 90Ω、以太网 100Ω 差分走线通常就这么保证；两层板手工估算精度有限，能控线长与参考完整已是大部分场合的够用解。

## 7. 示波器看波形：读懂三张"病历"

> **这是什么**：调试高速问题的核心技能——探头放上去，波形会直接告诉你敌人是谁。测量方法基础在 [06-测量仪器与调试排障](../../02-电路基础/笔记/06-测量仪器与调试排障.md)，本篇只讲高速专属。

- **先修探头**：长地线夹 = 自制电感 = 自己造振铃——测高速信号用接地弹簧或短接地环，探头地线越短越真；
- **过冲/下冲**：冲过逻辑电平一大截（经验警戒线：超过摆幅 20~30% 就要处理【经验值】）→ 反射没匹配；
- **振铃**：边沿后拖着衰减正弦 → 同上，且频率越高越刺眼；
- **边沿台阶**：中途停顿再爬升 → 分支/桩线的两次反射叠加；
- **眼图**（高速串行/以太网调试概念）：无数码元叠加成"眼睛"，眼睁得越大质量越好——知道概念即可，等真用到千兆级再深入；
- **激励自己造**：没有专用信号源时，用定时器输出固定频率方波当测试激励（配置见 [03-定时器与PWM](../../07-STM32/笔记/03-定时器与PWM.md)）——方波沿在示波器上的形态就是你布线的"体检报告"。

## 8. 快速决策树（遇到问题按序走）

```
通信偶发误码/波形难看
├─ 线长超过临界线长（第 3 节算例）？── 是 → 加匹配（第 4 节速查）
├─ 示波器看到振铃/过冲？── 是 → 查源端串阻、末端终端（第 4 节）
├─ 时好时坏、动一动线缆就变？── 是 → 查接触/终端电阻虚焊/拓扑分支（第 4 节）
├─ 干扰别人或被干扰（复位/跳变）？── 是 → 转场 [07-EMC 与防护基础](07-EMC与防护基础.md)
└─ 板子还没画？── 按 第 5、6 节 预防，比改板便宜一百倍
```

## 工程实操任务

- [ ] 用定时器输出 1MHz 方波，分别在"10cm 直线"与"绕板一圈"两条走线上用示波器（接地弹簧）对比振铃差异，拍照存档；
- [ ] 给自己的 RS485 总线做"终端电阻有无"对比实验：断开 120Ω 跑 10 分钟计数误码，装回再跑——亲眼看匹配的价值；
- [ ] 在自己的板上找一根换层的高速线，检查旁边有没有回流地孔，没有的补一版看波形变化；
- [ ] 按第 3 节算例，把自己项目里所有"陡沿信号"列一张清单：信号名、tr 量级、线长、是否超临界——超的标出匹配方案；
- [ ] SPI 提速实验：从低速逐档提到失败沿，记录每个速率下的波形与误码，找到自己这根线的极限。

## 常见坑（新手必看）

1. **探头长地线看啥都振铃**：测出的"振铃"是自己探头造的——先换接地弹簧再下结论；
2. **RS485 只接一端 120Ω 或干脆不接**：长线通信"偶尔乱码、偶发正常"，排查一星期不如装两端电阻一分钟；
3. **星形拓扑接总线**：CAN/RS485 走成星形，分支桩线反射叠加——改链式，分支压最短；
4. **地平面随手开槽**：为了"分区好看"把地割了，高速线恰好跨过——所有玄学故障的著名来源；
5. **信号换层没有回流孔**：单看原理图全对，版图上回流断路——检查每个高速过孔旁边有没有伴生地孔；
6. **串联电阻位置放错**：22~33Ω 阻尼电阻要贴着驱动器引脚放，放到线中间等于没放；
7. **把"跑通了"当"跑稳了"**：低速验证通过 ≠ 高速可用——升速后要重新看波形（第 7 节）。

## FAQ

**Q：I2C 需要终端匹配吗？**
A：一般不需要——开漏 + 上拉的边沿天然被 RC 放缓，且 I2C 规范本就面向板内/短距。I2C 的问题是长线电容把上拉拉"缓"导致时序超限，解法是降速/减电容，不是加终端电阻。

**Q：120Ω 终端电阻能随便加在中间吗？**
A：不能。并联端接的意义在"末端吸收"，加在中间会形成新的阻抗不连续点。CAN/RS485 只在总线两个物理端点各放一只（收发器内建终端的除外，按模块手册）。

**Q：两层板能做高速吗？**
A：能，但要更守纪律：关键信号短直、地干净完整（两层板没有完整地平面，更要避免地被走线割裂）、必要时包地。速率到几十 MHz 的 SPI、RS485 长线都是两层板常态活。

**Q：示波器带宽不够测陡沿怎么办？**
A：测不准就先看"能看的"：用慢沿激励、看趋势不看绝对值；精确边沿测量需要带宽足够的示波器与探头（经验上带宽 ≥ 3~5 倍被测信号频率，【经验值】，以仪器手册为准），确认口径查 [06-测量仪器与调试排障](../../02-电路基础/笔记/06-测量仪器与调试排障.md)。
