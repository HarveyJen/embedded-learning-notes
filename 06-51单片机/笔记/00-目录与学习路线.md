# 06-51单片机 · 目录与学习路线

> 定位：**过渡跳板，不是终点**。路线给 51 的时间只有 1.5~2 周——目标不是"精通 51"，而是借最简单的芯片建立**寄存器思维、中断思维、时序思维**，为 STM32 铺路。
> 前置：[C 语言基础](../../01-C语言基础/笔记/00-目录与学习路线.md)（至少学到位运算、指针概念）、[电路基础](../../02-电路基础/笔记/00-目录与学习路线.md)、[模拟电路基础](../../04-模拟电路基础/笔记/00-目录与学习路线.md)（可并行）。

**这套笔记怎么用（写给第一次碰单片机的你）**：每篇笔记的每一节开头都有一两句"大白话"告诉你这一节解决什么问题；代码块前面有"这段代码做什么"、后面有对关键行的拆解——**先看懂话再看码**。所有计算（定时器初值、波特率）都给了完整的代入算例，跟着手算一遍再往下走，比多看三遍视频都管用。

## 学习节奏（10 天版）

> 为什么是这个顺序：先让"写一行代码→板子有反应"的链路跑通（点灯），再练"一根线复用多个用途"的分时思想（数码管），然后攻克本阶段核心"事件驱动"（中断/定时器），最后把所有零件拼成完整项目（串口+时钟）——每一步都在给下一步打地基，跳步的话到综合项目会全线卡壳。

## 51 → STM32 概念迁移表（学 51 的真正价值）

| 51 里学的 | STM32 对应 | 迁移说明 |
|-----------|-----------|----------|
| sfr P1 = 0x90 | GPIOx->ODR | 同为**内存映射 IO**，只是位宽/模式更丰富 |
| IE / EA / 优先级 | NVIC | 从"2 级固定优先级"升级到"抢占+响应四级" |
| T0 手动重装初值 | TIM 自动重装 | 硬件帮你干了，但原理一模一样 |
| SCON / SBUF / TH1 | USART 寄存器组 | 帧格式不变，波特率计算思路不变 |
| interrupt 1 中断号 | 启动文件里的中断向量表 | 名义变了，"向量表跳转"思想完全一致 |
| while(1) 大轮询 | 裸机主循环 / RTOS 任务 | 51 的轮询局限正是引入 RTOS 的动机 |

> 江协科技在 51 之后有同风格 STM32 教程（B站），概念无缝衔接——这也是推荐 51 先学"寄存器直操作"的原因：手动挡学明白了，自动挡随便开。

## 名词速查表（遇到生词先看这里）

| 名词 | 一句话解释 |
|------|-----------|
| **寄存器** | CPU 内/外设里"有编号的存储格"，写它=控制硬件，读它=获取硬件状态。类比：带门牌号的开关面板 |
| **SFR**（Special Function Register） | 特殊功能寄存器——51 中 0x80~0xFF 地址段的寄存器，P1/TCON/SCON 全是 SFR |
| **GPIO**（General Purpose IO） | 通用输入输出口，引脚可由程序设为输出电平或读入外部电平。51 的 P0~P3 共 32 个 |
| **sfr / sbit** | C51 关键字：`sfr P1=0x90` 声明字节寄存器；`sbit LED=P1^0` 声明其中一位 |
| **上拉/下拉电阻** | 把引脚"默认抬到高/压到低"的电阻，让引脚悬空时有确定电平（见电路基础笔记01） |
| **中断** | 事件发生时硬件自动暂停主程序、跳去执行 ISR、干完回来。类比：烟雾报警器 |
| **ISR**（Interrupt Service Routine） | 中断服务函数——中断触发后执行的那段代码，军规：短小快走、共享变量加 volatile |
| **向量表** | 每个中断在 Flash 里预留的固定入口地址表，硬件据此跳转 |
| **定时器** | 自动 +1 的计数器，数满溢出触发中断。"数多少下=多长时间" |
| **初值/重装** | 从初值数到溢出；模式 1 需手动重装初值，忘装=周期变长 |
| **晶振** | 提供时钟节拍的"心跳"器件；12MHz 好算时间，11.0592 好做串口 |
| **机器周期** | 51 的最小时间单位（12T 模式 = 12/晶振频率），12MHz 时为 1μs |
| **初值拆高低字节** | 16 位初值拆成 TH（高 8 位）/TL（低 8 位）：TH=初值÷256 取整，TL=初值%256 取余。例：64536÷256=252 余 64 → TH=0xFC、TL=0x18 |
| **波特率** | 串口每秒传的符号数，双方必须一致（差 >2% 乱码）；9600@11.0592 → TH1=0xFD |
| **UART/串口** | 两线（TX/RX）异步通信，靠"约定波特率"替代时钟线 |
| **PWM** | 脉宽调制——快速开关 IO，靠"亮的时间占比（占空比）"控亮度/转速 |
| **动态扫描** | 数码管快速轮流点亮，靠视觉暂留"看起来同时亮" |
| **消抖** | 机械按键闭合会弹跳 5~10ms，需延时确认/RC/状态机过滤 |
| **Flash / RAM** | Flash 存程序（断电不丢），RAM 存运行变量（断电丢、容量小，51 仅 512B） |
| **hex 文件** | 编译生成的固件文件，下载器把它烧进 Flash |
| **冷启动** | STC 下载法：先点"下载"再给板子重新上电 |

## FAQ

**Q1：51 都 40 年了还值得学吗？**
学的是思维不是芯片。寄存器、中断向量、定时器初值这些概念在 STM32/LPC/国产 MCU 上原样存在（LX-750PLUS 那种工业设备也还在用 74HC 系列+传统外设思路）。另外 STC15/STC8 等增强型 51 在成本敏感产品里仍有大量出货。

**Q2：要不要背寄存器地址？**
不背。要掌握的是**查手册→定位寄存器→配置位→验证**的方法论，51 只是因为寄存器少，适合第一次完整走这个流程。

**Q3：和 STM32 二选一可以吗？**
时间紧可以，但代价是 STM32 上手时同时面对"新 IDE+新库+复杂时钟树"，容易懵。51 的两周是花得值的。
