# 01 · 概述与最小系统

> 目标：搞清单片机是什么、最小系统四件套怎么接、第一次把程序下载进去。

**开篇大白话**：这一篇解决三个"第一次"——认识芯片（它到底是什么东西）、把芯片救活（最小系统，少接一样它就装死）、把第一段程序塞进去（下载流程）。都过了，后面十天才算真正开始。

## 1. 单片机是什么

**这一节说什么**：先建立一个直观印象——单片机就是一颗"缩小的电脑"，你写的 C 程序烧进去它就照做。

**单片机（MCU）= 把一台计算机塞进一颗芯片**：CPU + 内存(RAM) + 程序存储器(Flash) + 外设（定时器/串口/IO）全在一块硅片上。

类比：PC 是"整栋大楼"（CPU、内存、硬盘各是独立楼层），单片机是"集装箱房"——麻雀虽小五脏俱全，专干"控制"这一件事，几块钱一颗，丢进烤箱、电饭煲、线材测试仪里都能服役十年。

### STC89C52RC 资源速览（典型学习款）

| 资源 | 数量 | 说明 |
|------|------|------|
| 内核 | 8051（Intel 1980 年血统） | 8 位机 |
| Flash | 8KB | 存你的程序 |
| RAM | 512B | **极其珍贵**，大数组别乱开 |
| IO | 32 个（P0/P1/P2/P3 各 8 位） | P0 特殊，见笔记02 |
| 定时器 | T0、T1（外加 T2） | 本阶段用 T0/T1 |
| 中断 | 5 个基本源 + 总开关 | 笔记04 |
| 串口 | 1 路 UART | 笔记05 |
| 主频 | 典型 11.0592 / 12MHz | 晶振决定，见下文 |

> 对照：LX-750PLUS 主控 LPC2478 是 32 位 ARM7——但架构概念（寄存器、中断、定时器）与 51 同源，只是"档位更多"。学 51 的每个概念都在为它铺路。

## 2. 最小系统四件套（对照电路基础笔记05）

**这一节说什么**：芯片本体不是插上电就跑——它像一台需要"供电+心跳+清零按钮+引导开关"的机器。四件套就是让它"活起来"的最低配置，少一样芯片都不跑。买开发板时能看懂这四部分在板子哪个角落，就算入门了。

### ① 电源
5V 供电（VCC=40 脚，GND=20 脚）。**为什么先说它**：电是一切的前提，电压不稳时芯片行为完全不可预测。实用要点：下载失败、莫名复位，先量 VCC 是不是稳的 5V。

### ② 时钟——晶振 + 两个负载电容
**晶振是什么**：一块通电能稳定"振动"的石英片，像给芯片配的心脏起搏器——CPU 每收到一个节拍才走一步，没有节拍它一步都不动。XTAL1（19）、XTAL2（18）接晶振，两侧各对地接 **30pF**（按晶振负载电容选，常用 22~33pF，作用是帮晶振"起振并稳住"）。

**两个经典频率的取舍**（重要）：
- **12MHz**：12T 模式下机器周期 = 12/12MHz = **1μs 整**——算定时器初值最舒服（"12T 模式"是传统 51 的节奏：每 12 个晶振节拍才算一步，这一步就叫一个机器周期）；
- **11.0592MHz**：数字看着怪，但它是 **串口波特率的整数倍**（921600Hz 机器节拍 = 9600×96），串口零误码。
- 经典矛盾：走时准要 12MHz，串口准要 11.0592 → 老项目普遍**迁就串口选 11.0592**（走时误差用软件校）。这个"时钟树迁就外设"的思想，到 STM32 学 PLL 时会再次出现。

### ③ 复位电路——高电平复位
**为什么要复位**：芯片上电瞬间内部寄存器全是随机状态，必须有个"回到已知起点"的动作——就像考试开始前先把答题卡涂干净。51 是**高电平复位**：RST（9 脚）保持 2 个机器周期以上高电平 → 寄存器回到初始态。
上电复位：10μF 电容串在 VCC 与 RST 之间、10kΩ 电阻接 RST 到地——上电瞬间电容充电，RST 短暂为高 → 复位；充满后电阻把 RST 拉低 → 开始跑程序。按键并联在电容上：按下把 RST 直接接 VCC → 手动复位。

### ④ EA 脚 + P0 上拉
- **EA（31 脚）必须接 VCC**：**为什么**——EA 是"程序从哪跑"的选择开关：接高=用芯片内部 Flash 里的程序；接低=去外部存储器找程序。悬空或接低会去找外部存储器 → 不跑程序，新手高频坑；
- **P0 口接 10kΩ 排阻上拉**（P0 是开漏输出，自己"抬不高"电压，要外接电阻帮忙，原理见笔记02）。

## 3. 开发与下载流程（跑通一次，终身受用）

**这一节说什么**：把你写好的 C 代码变成芯片里能跑的程序，中间隔着"编译→生成 hex→烧录"三道工序。每一步都标了"为什么要做"，照做时心里有数。

```
① Keil C51 新建工程 → 选 AT89C52（通用型号即可）→ 写 main.c
   （为什么要选型号：编译器按型号决定 Flash/RAM 大小和指令集，选错了地址会错）
② 编译生成 .hex（Options→Output 勾选 Create HEX File，忘了这里=下载不到东西）
   （为什么要 hex：hex 是"给下载器看的机器码文件"，Keil 默认只编译不导出，
     必须手动勾上这个开关它才把结果写成 .hex）
③ USB 线（CH340 芯片）接板子 → 装好驱动 → 设备管理器确认 COM 号
   （为什么要确认 COM 号：电脑把 USB 转出来的串口编成 COM1/COM3/COM5…，
     下载工具要告诉你"板子插在哪个口"）
④ 打开 STC-ISP：选芯片型号 + COM 口 + hex 文件
⑤ 【关键】冷启动：点"下载/编程"按钮之后，再给板子断电→上电
   （为什么要冷启动：STC 芯片内部有个"上电监工"，只在重新上电的瞬间
     串口喊话才理你——先上电再点按钮，监工已经上岗了，喊话无效）
⑥ 提示"操作成功" → 程序已在 Flash 里，复位即跑
```

**下载失败排查顺序**：COM 号对不对 → TX/RX 是否交叉（板 RXD↔线 TXD）→ 是否共地 → 是否冷启动 → 驱动是否装好（CH340）。

## 4. 第一个工程模板

**这段代码做什么**：把 P1 口 8 个引脚全部拉成低电平（如果 P1 上接的是低电平点亮的 LED，就是 8 灯全亮），然后死循环挂住——这是所有 51 程序的最小骨架。

```c
#include <reg52.h>
// reg52.h：寄存器"通讯录"，把 P1、TCON 这些名字和实际地址对应起来
// 相当于告诉编译器：sfr P1 = 0x90 这种话已经有人替你说了

void main(void)
{
    P1 = 0x00;    // P1 口 8 个引脚全部输出低电平
    while (1);    // 单片机没有"程序结束"，必须死循环兜住
}
```

**关键行拆解**：
- `P1 = 0x00;`——`P1` 不是普通变量，它是地址 0x90 处的一个 8 位寄存器（reg52.h 替你声明好了）。给 0x00 = 8 个二进制位 `0000 0000`，每位对应一个引脚，0=低电平。**写一个名字，8 个引脚同时变化**，这就是"整口操作"；
- `while (1);`——空转死循环。**为什么必须有**：如果 main 跑到末尾"结束"了，CPU 没事干会继续往下取指令，取到的是 Flash 里的垃圾数据，程序乱飞。死循环=把 CPU 拴在家里，等中断来叫它。

两个第一次就要建立的观念：
- **操作 P1 就是写地址 0x90 的寄存器**——这就是"寄存器思维"，笔记02 展开；
- **main 不能 return**——单片机没有操作系统兜底，跑飞了就是乱来，`while(1)` 是所有裸机程序的标准结尾（51 阶段如此，到 RTOS 阶段才交给调度器）。

## 5. 常见坑清单

| 坑 | 现象 |
|----|------|
| 忘勾选 Create HEX | 编译"成功"但没有 hex 可下载 |
| 先点下载再上电的顺序反了 / 板子一直带电 | STC-ISP 一直"正在检测目标单片机" |
| EA 悬空 | 程序不跑 |
| 晶振虚焊 / 负载电容错 | 完全不跑或时好时坏 |
| TX/RX 接反 | 下载失败 + 串口乱码 |
| P0 没接上拉 | 接 P0 的器件全无反应 |

## 6. 章节小结

- 单片机=单芯片计算机，STC89C52RC：8K Flash / 512B RAM / 32 IO / T0T1 / UART
- 最小系统四件套：5V 电源、晶振+30pF、RC 高电平复位、EA 接 VCC（P0 补上拉）
- 频率取舍：12MHz 好算时间，11.0592 好做串口——工业惯例迁就串口
- 下载铁律：hex 要生成，STC 要冷启动，TX/RX 要交叉，要共地

## 课后思考题

1. 为什么复位要求"持续 2 个机器周期以上"而不是一瞬间？（时钟还没稳/电源爬坡时电路状态不定，持续高电平保证整个上电过程都处于复位态，等晶振稳定后才放行）
2. 11.0592MHz 做走时时钟误差会怎样积累？（每个机器周期 1.085μs 而非 1μs，软件若按 1μs 换算则每天快/慢约 8%→约 2 小时——所以走时程序必须按 1.085μs 真实周期计算，或直接用 12MHz）
3. 上电复位电容改成 1μF 会怎样？（复位时间缩短，若电源爬坡比复位时间还长，芯片在电源未稳时就开始跑 → 开机异常，这就是"复位时间要覆盖电源爬坡"）
