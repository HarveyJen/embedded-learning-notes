# 05 · DMA 与 ADC/DAC

> 目标：理解"解放 CPU"的 DMA 机制；打通 ADC 采样链（模拟前端→ADC→DMA→软件滤波）；DAC 输出波形。

**开篇大白话**：这一篇解决两个"CPU 不该亲自干的活"——搬数据（DMA：专职搬运工）和把模拟电压变数字（ADC：翻译官）。两者联手才是标准姿势：ADC 定时产出数据、DMA 悄悄搬进内存、CPU 只管最后的分析和决策。

## 1. DMA：CPU 的搬运工

**这一节说什么/解决什么问题**：让"数据在两个地址之间移动"这种体力活脱离 CPU。理解 DMA 的配置=填三道题：从哪搬、搬到哪、搬多少——其余全是这三题的变体。

**问题**：ADC 每毫秒来一个数据、串口每字节来一个数据——都靠 CPU 亲自搬，CPU 全在干"搬运工"正事干不成。
**DMA（Direct Memory Access，直接存储器访问）**：外设↔内存、内存↔内存的搬运**不经过 CPU**，CPU 只在"搬完一批"时被通知。

类比：快递分拨（CPU）不亲自跑腿送每个包裹（数据），雇一个传送带（DMA）——分拨只管分拣决策，包裹自己流动。

### DMA 三要素（配置本质就是填这三项）

1. **源地址/目的地址**：如 ADC 数据寄存器 → 内存数组；
2. **传输方向与宽度**：外设→内存/内存→外设/内存→内存；Byte/HalfWord/Word（1/2/4 字节——宽度决定"一次搬一袋还是一箱"）；
3. **传输数量与模式**：Normal（搬完停）/ **Circular（循环，日志/采样流必备）**。

**Circular 为什么是采样流的标配**：数组像"环形传送带"，搬满 256 个自动从头覆盖——数据永远新鲜，CPU 永远不用重启搬运；Normal 模式搬完就停，得手动重新 Start。

F103 有 DMA1（7 通道）/DMA2（5 通道）；**通道对外设是固定映射**（ADC1 只能走某些通道）——**为什么固定**：每个外设的"搬运请求信号"在硬件上焊死接在某些通道上，像收费站的专用车道，不能改道。CubeMX 里看到 ADC 挂了就选对应 DMA 通道，背后就是这张映射表。

## 2. ADC：模拟世界的入口

**这一节说什么/解决什么问题**：现实世界是连续的（温度、光照、电压），单片机只能处理离散数字——ADC 就是中间的"翻译官"。这一节把翻译过程的每个环节（量程、精度、采样时间）拆开讲清，不然读数偏低、跳动都不知道为什么。

### 信号链完整路径（模电笔记05 五段式的落地）

```
传感器 → (调理放大/滤波) → ADC引脚 → 采样保持 → 逐次逼近比较 → 数据寄存器 → DMA → 内存
```

**逐次逼近**是什么：ADC 内部像"猜价格游戏"——先猜一半（2048），比你给的大就砍一半再猜，小就加一半再猜，12 轮后锁定最接近的数字。这就是为什么转换要 12.5 个周期：一轮一拍地逼近。

### 关键参数与公式

- **12 位分辨率**：量化 4096 级；**电压 = D × VREF / 4096**（VREF=参考电压，ADC 拿它当"满量程"的基准刻度；板子上通常把 VREF 接到 VDDA——模拟电源引脚，即 3.3V）；
  **算例（一步步）**：读到 D=2048 → 电压 = 2048 × 3.3 ÷ 4096 = 6758.4 ÷ 4096 = 1.65V（正好中点）。**分辨率有多细**：3.3V ÷ 4096 ≈ 0.0008V = 0.8mV/格——比这更小的电压变化它"看不出来"；
- **采样时间**：每个通道可设 1.5~239.5 周期——采样开关闭合给内部电容充电的时间。**高阻抗信号源必须加长采样时间或前端加跟随器**（TL071 缓冲的用武之地，模电笔记02）。**类比**：采样电容像一个小水杯，信号源像水源——水源压力大（低阻抗）瞬间接满，水源细成一根吸管（高阻抗）就得让它流久一点，否则杯里水位（采到的电压）偏低；
- **ADC 时钟 ≤14MHz**：72MHz÷6=12MHz；转换时间 = 采样时间+12.5 周期 ≈ 1μs@12MHz；
- **规则组 vs 注入组**：规则组=常规轮询采样队列（最多16通道）；注入组=插队采样（4通道）——"VIP 通道"。

### 三种触发方式（工程演进）

| 方式 | 代码 | 适用 |
|------|------|------|
| 软件单次 | `HAL_ADC_PollForConversion()` | 低频读电位器 |
| **定时器触发 + DMA 循环** | 从模式：TIM3 TRGO→ADC | 匀速采样流（FFT 前提） |
| 外部触发 | EXTI/其他外设 | 事件同步采样 |

**匀速采样思想**：FFT/滤波算法要求"等间隔"采样——用定时器硬件触发而不是软件循环里读（软件读的间隔会被任务抖动污染）。这是从"能读数"到"能做信号处理"的分水岭。

## 3. 标准例程：定时器触发 + DMA 循环采样

**这一节说什么**：把上面所有零件拧成一条流水线——定时器发令、ADC 转换、DMA 搬运、CPU 分析。这是工业采样的标准模板，值得完整跑一遍。

CubeMX：ADC1 IN1 连续模式 + 加 DMA（Circular）+ TIM3 TRGO 触发 → 生成。**为什么触发源选 TIM3 TRGO**：TRGO（Trigger Output）是定时器专门给别的外设"发令"的输出脚位，定时器每溢出一次就给 ADC 发一次"开始转换"的信号，节奏由 PSC/ARR 保证（03 篇公式）——例如 PSC=71、ARR=999 → 1kHz 整齐采样。

**这段代码做什么**：硬件在后台自动"定时采样→搬运"，主循环随时对 adcBuf 里的 256 个最新采样做平均并换算成电压。

```c
uint16_t adcBuf[256];                       // 采样流落地区

HAL_TIM_Base_Start(&htim3);                 // 触发源启动
HAL_ADC_Start_DMA(&hadc1, (uint32_t*)adcBuf, 256);   // DMA 循环搬运，CPU 不再管

/* 主循环随时分析 adcBuf：均值/滤波/过阈值判断…… */
uint32_t sum = 0;
for (int i = 0; i < 256; i++) sum += adcBuf[i];
float volts = (sum / 256.0f) * 3.3f / 4096.0f;
```

**关键行拆解**：
- `HAL_ADC_Start_DMA(&hadc1, (uint32_t*)adcBuf, 256)`——DMA 三要素全在这一句里：目的地址=adcBuf（源地址已由 CubeMX 绑定为 ADC 数据寄存器）、宽度=HalfWord（16 位，跟 ADC 分辨率匹配）、数量=256、模式=Circular（CubeMX 里配的）；
- `(sum / 256.0f)`——**为什么除 256.0f 而不是 256**：sum 是整数，除整数会丢小数；256.0f 强制浮点除法。经典 C 细节；
- `* 3.3f / 4096.0f`——第 2 节公式的代码化：D × VREF ÷ 4096。

### 软件滤波两板斧（采样后第一件事）

- **均值滤波**：去随机噪声（上面例程）；
- **中值滤波**：去毛刺脉冲（排序取中间，防单点干扰）；
- 进阶再上 IIR/FIR——数字信号处理（四大件之外的加分项）。

## 4. DAC（F103 的 DAC 在 F103C8 上没有，F103 高容量款/F407 有）

**这一节说什么**：ADC 的反向——把数字变模拟电压输出。没有 DAC 的芯片也有替代方案（PWM+RC），思想比器件重要。

8/12 位、可由定时器触发。**经典玩法：DAC + DDS 思想输出任意波形**——软件每 tick 改 DAC 值（正弦表），比 AD9833 灵活（任意形状）但速率/平滑度不如专用 DDS。没有 DAC 的芯片用 **PWM+RC** 顶替（模电笔记03）——PWM 占空比变化的方波经 RC 低通滤波，平均电压就是"想要的模拟量"，03 篇 PWM 知识的又一次变现。

## 5. 常见坑

| 坑 | 现象 |
|----|------|
| 没配 DMA 循环模式 | 采满 256 个就停 |
| 高阻源直接接 ADC | 读数偏低/跳（采样电容充电不足）→ 加跟随器或加长采样时间 |
| VDDA 没接/没滤波 | ADC 全乱（模拟电源独立，10Ω+1μF 滤波是标准做法） |
| ADC 时钟超 14MHz | 精度下降/转换异常 |
| DMA 通道映射记错 | 配置冲突（查参考手册 DMA 请求映射表） |

## 6. 章节小结

- DMA=后台搬运工，三要素：源/目的地址、方向宽度、数量模式（Circular 常用）
- ADC 电压=D×VREF/4096；采样时间匹配信号源阻抗；时钟≤14MHz
- 工程姿势：定时器触发+DMA 循环=匀速采样流（信号处理的地基）
- 采后先均值/中值滤波；无 DAC 用 PWM+RC

## 课后思考题

1. 为什么"定时器触发采样"对 FFT 如此重要？（FFT 假设等间隔采样，间隔抖动=频谱模糊；硬件触发的时间确定性是软件循环给不了的——呼应 51 笔记04 时序确定性）
2. DMA 搬运时 CPU 在干嘛？DMA 和 CPU 抢总线怎么办？（并行干别的；总线仲裁 DMA 优先/CPU 让位——共享总线的资源仲裁思想，与 02 篇线与一脉相承）
3. 高阻传感器为什么要加运放跟随器再进 ADC？（ADC 采样电容充电需要电流，高阻源带不动 → 采样瞬间电压被拉低读数失真；跟随器输出阻抗低，充电无忧——模电笔记02 跟随器价值的直接兑现）
