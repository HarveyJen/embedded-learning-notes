# 07-STM32 · 目录与学习路线

> 定位：**本路线的重点阶段（2~3 个月）**。目标不是"会调库点灯"，而是：①建立完整的时钟/中断/总线体系观；②外设全部手写一遍（HAL 与寄存器两种方式）；③具备独立调试排障能力。
> 前置：06-51单片机（寄存器思维、中断、定时器概念必须过关）、C 语言（指针、结构体、位操作）。

**这套笔记怎么用**：每节开头有"这一节说什么"的大白话导读，关键概念配生活类比，所有计算（时钟树分频、PSC/ARR、波特率 BRR）都带完整代入算例，CubeMX 步骤附"为什么"。51 阶段练的是"手动挡"，这一阶段是"自动挡+看懂发动机舱"——每篇末尾的对照表都在帮你把旧概念平移过来，遇到新名词先查下方速查表。

## 名词速查表（遇到生词先看这里）

| 名词 | 一句话解释 |
|------|-----------|
| **时钟树** | 从晶振到各外设的多级分频/倍频分发网络。类比：小区总闸→楼栋→入户的电表分级 |
| **HSE/HSI** | 外部高速晶振（8MHz，准）/内部 RC（8MHz，糙但备用）；LSE=32.768kHz 给 RTC |
| **PLL** | 锁相环倍频器，把 8MHz 抬到 72MHz 的"增压器" |
| **AHB / APB1 / APB2** | 三条总线（高速主干/低速外设/高速外设）；APB 分频 >1 时其上定时器 ×2 |
| **NVIC** | 内核中断控制器，抢占+响应双优先级（51 只有两级） |
| **EXTI** | 外部中断控制器：引脚电平跳变 → 中断；同号引脚（PA0/PB0）互斥 |
| **SP / 堆栈** | 栈指针——函数调用与中断的"临时工作台"，启动文件第一步就是初始化它 |
| **推挽 / 开漏** | 输出结构：强 0 强 1 / 强 0 高阻 1（高电平靠上拉，可线与） |
| **上下拉** | 输入模式下的默认电平保障，按键必须配 |
| **PSC / ARR / CCR** | 定时器三寄存器：分频定粒度、重装定周期、比较定占空比 |
| **SysTick** | 内核自带 24 位滴答定时器，HAL_Delay 的心跳 |
| **DMA** | 后台搬运工：外设↔内存不经 CPU；三要素=源/目的地址、方向宽度、数量模式 |
| **ADC 采样时间** | 采样开关闭合给内部电容充电的时长，高阻源必须加长或加跟随器 |
| **I2C / SPI** | 两线多从（地址+ACK）/ 四线高速（CS 点名+时钟定节奏） |
| **CAN** | 差分双线、多主仲裁、硬件重发——汽车工业总线 |
| **IWDG / WWDG** | 独立/窗口看门狗：不喂就复位；窗口版"太早喂也算错" |
| **Sleep / Stop / Standby** | 低功耗三级：停 CPU / 停时钟保现场 / 停电保 RTC |
| **备份域** | VBAT 供电的独立区（RTC+备份寄存器），主电源掉了照样走时 |
| **SWD** | 两线调试接口（SWDIO/SWCLK），ST-Link 下载+断点的通道 |
| **HardFault** | CPU 跑飞兜底异常（野指针/越界/栈溢出），Call Stack 定位 |
| **HAL / LL 库** | ST 官方封装库：HAL 跨芯片易用；LL 轻量贴寄存器 |
| **BSRR / ODR** | GPIO 输出寄存器：BSRR 原子写安全；ODR 读改写可被中断踩 |
| **.data / .bss** | 已初始化/未初始化全局变量区，启动文件负责搬运与清零 |
| **MSP / PSP** | 主/进程栈指针，HardFault 勘查现场的"栈在哪"线索 |

## 51 → STM32 术语对照（衔接 04 篇迁移表）

| 概念 | 51 | STM32 |
|------|----|-------|
| 引脚组织 | P1 整口 8 位 | GPIOA~G 组，每组 16 脚，每脚 4 位配置（模式/速度） |
| 输出结构 | 准双向口（写1弱上拉） | 明确选择：推挽（强0强1）/ 开漏（强0，1靠上拉） |
| 中断管理 | IE+IP 两级 | NVIC：抢占/响应双优先级 + 向量表由启动文件提供 |
| 定时器 | 手动重装/自动重装 | 全部自动重装 + PSC 分频 + 多种从模式 |
| 串口波特率 | T1 兼职发生器 | 专用 BRR 分频器 |
| 时钟 | 一个晶振直供 | 时钟树多级分频/倍频（最大的新增概念） |
| 下载 | 串口冷启动 | ST-Link（SWD）一键下载+调试 |

## FAQ

**Q1：HAL 库还是寄存器还是标准库？**
学习路径：**HAL 入门（快，CubeMX 生成）→ 寄存器重学核心外设（真懂）→ 工作后看公司**（新项目多 HAL，老项目/精简项目寄存器或 LL 库）。标准库已停止更新，不必投入。

**Q2：为什么要买 ST-Link？串口不是能下载吗？**
串口下载只解决"烧进去"；ST-Link 解决"看进去"——断点、单步、看变量、看寄存器。调试能力是路线修订补充的**高优先级项**，没有调试器寸步难行。

**Q3：F103 还是 F407？**
F103（Cortex-M3）：资料最全、面试标准、性价比高；F407（Cortex-M4）：带 FPU/DSP、主频高。建议 F103 入门，学有余力换 F407——概念 90% 相同，换芯片只是换参考手册。
