# 00 · 目录与学习路线

> 定位：本模块解决"最后一公里"——电路原理你都懂了，怎么把它变成一块真正能拿在手里的板子？

**先说人话**：本篇讲什么，学完能做什么——

02-电路基础 教你"为什么这样设计"（为什么每个电源脚要配 0.1uF 电容），本模块教你"怎么把它画出来、做出来"：用**嘉立创EDA**（国产、免费）画出原理图和 PCB，导出生产文件，花几块钱寄给工厂打样，一周后收到一块自己设计的板子。学完本模块，你能**独立完成一块 STM32 最小系统板从画图到下单的全部流程**，还顺带学会看懂别人板子的设计、以及板子坏了怎么修。

学完本模块，这些场景你就能应付：

- 老板/比赛说"画个转接板、画个最小系统板"，你能直接开工而不是先报个培训班；
- 看到别人开源工程（立创开源硬件平台上一大堆），能下载下来看懂、改一改变成自己的；
- 板子焊好点不亮，知道按什么顺序排查，而不是"重焊一遍碰运气"；
- 想做个小东西（温湿度盒、遥控小车主板），从想法到实物自己闭环。

## 建议学习顺序

```
01 原理图（约3~4天）
   ↓
02 PCB（约4~5天）
   ↓
03 Proteus 仿真（可与 02 并行学，互不依赖）
   ↓
04 工具速查（当字典用，不必通读）
   ↓
05 维修实战（收到打样板之后学，正好用得上）
```

- **01 → 02 是硬依赖**：PCB 是从原理图"一键导入"生成的，必须先画完原理图；
- **03 可与 02 并行**：Proteus 是另一个独立软件，仿真验证电路逻辑，和画 PCB 互不影响；
- **04 随查随用**，**05 建议等你自己的板子到手后再学**，拿着真板子学排查，效率翻倍。

**三条典型启动路径**（按你现在的进度对号入座）：

- **还在 C 语言阶段**：每天主线之外 20~30 分钟给电路，02/05 学完就开画 01 → 02，下单后等板的一周正好穿插 03 Proteus——板子到手时你大概刚好进 STM32 阶段，自己的板子直接当实验平台；
- **已到 51/STM32 阶段**：01+02 主线两周突击（每天 1 小时），板子打样期间继续主线单片机课程，到货焊接调试用 05 排障；
- **求职冲刺期**：最小系统板打样到点亮 = 简历"独立完成 PCB 设计"项目素材（见 12 模块）；工控/硬件维修岗再把 05 篇实操过一遍。

**时间预算**：01 约 3~4 天、02 约 4~5 天、03 约 2 天、05 约 2 天（均按每天 1 小时），04 是字典不占时间——全程约 3~4 周，完全并行于主线，不需要中断 C/单片机的学习节奏。

### 学习前必读的三个建议

1. **必须动手，光看没用**：本模块是"软件操作 + 工程习惯"，像学做菜，看一百遍菜谱不如炒一盘。主线作品（STM32 最小系统）请全程跟着敲；
2. **别追求一步到位**：第一块板布线丑、丝印歪都正常，"能出厂能点亮"就是胜利；审美好是第二块板的事；
3. **和 02-电路基础 对照着学**：画到哪块电路，就回去看那块的"为什么"，两边互相巩固，比单刷任何一边都快。

## 开始之前：高频术语 30 秒预览

本模块天天见面的黑话，先混个脸熟（每篇还会细讲）：

| 术语 | 白话解释 |
|------|----------|
| 原理图（Schematic） | 电路的族谱：谁连谁，不管物理位置 |
| PCB | 族谱落成的房子：铜线在板子上实际怎么走 |
| 封装（Footprint） | 零件的"安装脚位图纸"，实物长什么样、焊在哪 |
| 符号（Symbol） | 零件在原理图里的"头像" |
| 网络/飞线 | 网络=连接关系清单；飞线=还没布线的"待连线"提示 |
| ERC / DRC | 原理图体检 / PCB 验收，各自自动查错 |
| Gerber | 板子的"底片"文件，工厂只认它 |
| BOM | 物料清单：买什么料、买几个 |
| 丝印 | 印在板子上的白字白框 |
| 打样 / SMT | 小批量试产几块板 / 工厂机器帮你贴片焊接 |

## 阶段验收标准

全部打勾，说明你已具备"独立出板"能力：

- [ ] 能在嘉立创EDA里独立完成 **STM32F103C8T6 最小系统板**的原理图（含晶振、复位、BOOT、SWD、去耦、LED），并通过 ERC 检查

- [ ] （进阶）板子焊好点不亮时，能按 05 篇的排查套路定位问题

## 工程实操任务

目标：把"画一块能打样的板子"拆成可勾选的里程碑，按顺序推进。

- [ ] 注册立创EDA/立创商城账号，安装专业版客户端，新建一个名为 `STM32最小系统` 的工程

## 常见坑（新手必看）

1. **只收藏教程不动手**：本模块的最大坑。软件是练出来的，"看完所有视频再开始"的人基本都没开始；
2. **跳过 01 直接画 PCB**：没有原理图就没有网络关系，PCB 里连线全靠手点，错了都不知道；
3. **第一块板就上四层板/高速电路**：先拿双层最小系统练手，走都走稳再跑；
4. **和 02-电路基础 完全割裂**：只记"步骤点哪里"，不问"为什么这么连"，换个芯片就废——两边对照才是正路；
5. **界面和教程对不上就慌**：软件迭代快，菜单名偶有变化，认功能名不认截图，实在找不到去官方帮助文档搜；
6. **不敢真下单**：怕画错浪费钱。几块钱的打样费就是学费，而且画错的过程恰恰是最有用的学习。

## FAQ

**Q1：完全零基础，没学过 02-电路基础，能直接学本模块吗？**
能照着画出来，但建议至少先看 02 模块的 05 篇（最小系统电路），否则晶振、BOOT、去耦这些名词会让你画得云里雾里、错了也不知道错哪。

**Q2：为什么要用嘉立创EDA，Altium Designer 不是更专业吗？**
AD 确实是行业标准，但收费且对新手门槛高。立创EDA 免费、元件库即搜即用、下单打样一条龙，学习阶段效率最高；工艺思路是相通的，以后转 AD/其他的软件很快。

**Q3：学完大概要多久？**
每天 1 小时，01+02 两篇主线约两周；加上下单等板、焊接调试，一个月内"从零到点亮自己的板子"是现实的目标。

**Q4：画好了不打算真打样，学这个还有意义吗？**
有。会画原理图 = 看懂任何开发板；会画 PCB = 理解产品的物理设计约束。这两样即使不下单，也是嵌入式面试和工作的硬通货。
