# 05 · 电路板维修实战

> 定位：修板子是嵌入式硬件能力的终极试金石，也是工厂设备维护岗的硬技能——看得出、量得出、换得对。

**先说人话**：本篇给你一套"接手任何一块坏板子都能套用"的排查方法论：先看、再量、后换（三板斧），配一条从接到板子到换件验证的标准排查时间线，再加一张高频故障速查表和焊接基础速成。学完你能：面对一块不工作的低压直流板卡，有条理地缩小故障范围、定位可疑元件并完成基本补焊换件，而不是两眼一抹黑。

---

## 安全警示（必读，此段高于一切）

> **本文所有涉及市电（220V 交流）侧的内容，仅作知识了解。没有强电经验的读者，实操范围只限于低压直流板卡（USB 供电、电池供电、适配器输出之后的板级电路）。**

- **开关电源初级侧、市电接入设备的内部，存在 220V 交流电，以及整流滤波后约 310V 的直流母线电压**——这个电压远超人体安全阈值，触电可致命。**没有强电经验，绝对不要碰。**
- **断电 ≠ 安全**：开关电源和含大容量电解电容的板子，断电后电容里仍储存残压，可能保持较长时间。**任何测量前先放电**：用一只大功率、阻值合适的大电阻（如数十千欧/瓦级以上的电阻）跨接电容两端缓慢放电，**严禁直接用螺丝刀短接**——瞬时会打出火花并损伤电容。
- 操作环境同样重要：**湿手不碰任何电气**、桌面保持干燥、戒指手链等金属饰品操作前摘掉；有条件的话，防静电手环是低压板维修的标配。
- 若确有强电学习需求，必须遵守的操作原则：**先断电、后验电确认、单手操作（另一只手不扶金属）、脚下绝缘垫**，并且全程有经验者在场。本篇不展开、不鼓励此类操作。

安全内容记住了吗？下面所有方法都默认你在低压直流板上操作。

## 一、维修三板斧：看、量、换

维修三板斧是接到坏板后的第一轮攻击组合：先用眼睛鼻子收集线索，再用万用表量化证据，最后用"换件"做最终判决。

类比：像医生看病——先"望闻问切"（观察法），再开化验单（测量法），最后对症下药并验证疗效（替换法）。三斧头的使用顺序固定：**观察 → 测量 → 替换**，跳步就会瞎换件。完整的仪器使用细节（档位选择、表笔操作）在 [06-测量仪器与调试排障](../../02-电路基础/笔记/06-测量仪器与调试排障.md)，本节聚焦"用在维修现场"的套路。

### 1. 观察法：五感侦探

定义：不上电、不拆件，先用感官收集故障线索——像法医勘查现场。**注意：手摸发烫这一招必须断电摸，且只摸你确认安全的低压区域。**

- **眼看**：烧焦发黑、电容鼓包顶盖开裂、电解电容底部漏液结晶、板子变色、走线断裂、焊点开裂、元件缺角。
- **鼻闻**：糊味是过流烧毁的标志性气味，闻到糊味基本锁定有元件击穿过流。
- **耳听**：上电瞬间"滋滋"声（打火/电容啸叫）、异响（风扇轴承坏、变压器啸叫）。
- **手摸（断电摸）**：断电后轻摸可疑区域，某芯片比周围明显发烫 → 重点嫌疑对象。

观察法的加分习惯：**边看边拍照**。手机微距拍下鼓包、烧焦、裂纹的位置——一是维修记录可回溯，二是对照网上同型号案例时用得上，很多"疑难杂症"其实是某批次的通病。

### 2. 测量法：万用表四招

定义：用万用表的四个档位，把"怀疑"变成"证据"。口诀：**量电压看有没有，量对地看短不短，量通断看通不通，量电阻看对不对。**

1. **直流电压档量电源轨**：黑表笔接 GND，红表笔依次量板子上各级电源点，读数应为标称值（3.3V/5V/12V 等），缺哪路电，故障就在哪路之前。
   - 细节：按"电源输入 → 各级稳压输出"的顺序量，一旦某级缺失，范围立刻缩小到该级之前。
2. **二极管档量对地阻抗**：红笔接 GND、黑笔接各电源轨（或反向量两次对比），读数明显偏低（接近 0）说明该电源轨对地短路——这是判断"板子有没有短路"的标准动作。
   - 细节：同型号的好板是最佳对照组，两板读数一对比，异常的轨立刻现形。
3. **通断档查走线**：蜂鸣档检查走线、焊点、连接器是否导通，排查断路和虚焊。
   - 细节：蜂鸣响不代表完全正常，微小阻值的虚接它也响，关键点要用电阻档复核。
4. **电阻档查电阻**：怀疑电阻变值/开路时，至少一端脱开再量（在线量会被并联路径干扰，读数失真）。
   - 细节：换挡位后先短接表笔确认读数正常，表笔氧化也会造成误判。

### 3. 替换法：终极判决

定义：怀疑谁，就换掉谁——用"换上好的就好、换回坏的又坏"来做最终确认。类比：球队连输先换状态最差的替补，而不是直接炒掉主教练。

策略与细则：

- **从最便宜、最可疑的开始换**：先换电容、保险丝、连接器这类几毛钱元件，再考虑芯片。
- **一次只换一个变量**：一次换三个件，好了也不知道是谁的功劳，下次还是不会修。
- **换前记录原状态**：元件方向、型号丝印、位置先拍照留底，防止换完装不回去。
- 手头有同型号好的板卡时，可以对调模块（如整个电源模块、显示模块）快速分锅。

## 二、标准排查流程时间线：从接到板子到换件验证

以下是一条文字时间线，按顺序执行，每一步都在缩小包围圈——像剥洋葱，一层一层往里剥：

```
[0] 接到坏板
 │  心里默念：先别上电！先别上电！先别上电！
 │  （带故障上电可能扩大损伤，且冷板状态下的外观痕迹
 │    最完整，一上电痕迹就被新损伤覆盖了）
 ▼
[1] 问故障史（2 分钟问出 80% 线索）
 │  怎么坏的？进水/雷击/带电插拔/摔过/老化渐坏？
 │  什么现象？完全无反应/时好时坏/冒烟后坏？
 ▼
[2] 外观检查（断电状态）
 │  眼看烧焦鼓包漏液 → 鼻闻糊味 → 放大镜查焊点裂纹
 ▼
[3] 电源轨测量（万用表直流电压档）
 │  先量输入（适配器/电池输出是否正常）
 │  再顺电源树逐级量：各级 LDO / DC-DC 输出是否达标
 ▼
[4] 时钟复位确认（有示波器则量晶振引脚）
 │  晶振不起振、复位信号异常 → 主控必然"装死"
 ▼
[5] 分块隔离（拔外设、断开后级）
 │  拔掉显示屏/传感器/后级模块，逐块接回
 │  哪一块接上电源就趴 → 故障在那一块
 ▼
[6] 定位元件
 │  在锁定的小块内用三板斧精查：测电压/对地阻抗/温度
 ▼
[7] 换件验证
    换上同规格好件 → 上电测试 → 复测全部电源轨
    → 老化观察一段时间，确认不再复发
```

时间线的精髓：**每一步都给下一步"缩小范围"**。不要跳步——跳过问故障史和外观检查直接换芯片，是新手最常见的浪费行为。

三个使用要点：

- **每步留下记录**：量了哪些点、读数多少，写在纸上——排查中断后能接着来，不用从头猜。
- **卡住就回退一步**：当前层剥不动时，回到上一步换角度（比如电源轨都正常但主板不跑，就回退查时钟复位）。
- **排除法记心里**：每确认一处正常，就在心里划掉一块区域，剩余范围只会越来越小。
- **不确定先停手**：遇到没把握的操作（拆 BGA、动电源初级）先查资料或问人，别凭"大概没问题"硬上。

## 三、高频故障清单表：对着现象查

下表覆盖板级维修里出现频率最高的五类故障，接到板子先对表：

| 故障现象 | 常见原因 | 怎么确认 | 维修动作 |
| --- | --- | --- | --- |
| 完全无反应（指示灯都不亮） | 保险丝熔断 / 电源输入 MOS 击穿 / 某级 LDO 无输出 | 电压档沿电源树逐级量；二极管档查保险丝两端是否断路 | 查明熔断原因（后级短路）后换同规格保险丝/LDO；**严禁换更大规格** |
| 时好时坏、拍一拍就好 | 虚焊 / 连接器接触不良 | 按压法：轻压可疑区域看故障是否复现；放大镜查裂纹焊点 | 补焊可疑焊点；清洗/重插连接器 |
| 上电某区域迅速发烫 | 电源轨对地短路 | 二极管档找对地低阻点；断电后用指感/（有条件用）热成像找热点 | 沿低阻电源轨排查并联的电容、芯片，隔离法锁定短路件 |
| 某接口失效（插上没反应） | 接口 ESD 被静电打坏 / 连接器损坏 | 对比好板同点位的对地阻抗；量接口信号线通断 | 更换接口连接器及前端的 TVS 保护管 |
| 电解电容失效（隐性故障大户） | ESR 变大、容量衰减、鼓包漏液 | 目视鼓包；参数异常时可拆下用电容档/（有条件）ESR 表验证 | 换同容量、同耐压或更高耐压、同尺寸的新电容 |

经验规律：**先怀疑电源，再怀疑电容，最后怀疑芯片**——电源与电容的故障率远高于芯片，而且便宜好换。

每次维修顺手填一张"排查记录"（一张纸就够）：

```
板子/型号：
故障描述（怎么坏的/什么现象）：
外观异常点：
电源轨实测（输入__/__V → 一级__/__V → 二级__/__V）：
对地阻抗异常的轨：
结论（坏件/处理）：
```

坚持记十块板，你对"哪类现象对应哪类原因"的手感会突飞猛进。

### 故障库扩充：按模块分类的常见故障速查

上面的五类是"万金油"故障，下面按电路模块分类扩充——板子是由模块搭起来的，故障也按模块出。对表方法：先判断坏板属于哪类产品（电源板/主控板/带外设的整机板），再扫对应类别的表。

#### A. 电源类（故障率最高，永远先查）

| 故障现象 | 常见原因 | 怎么确认 | 维修动作 |
| --- | --- | --- | --- |
| 输出电压偏低 | 滤波电容失效（带载能力差）/ 整流二极管坏一只 / 反馈分压电阻变值 | 空载量电压正常、带载跌落 → 电容嫌疑大；对比好板反馈点电压 | 换滤波电容；查反馈电阻阻值 |
| 输出电压偏高 | 反馈电阻开路/变值（芯片以为输出不够，拼命拉高）——**偏高比偏低更危险，先断开后级再修** | 二极管档查反馈网络电阻；有条件带隔离变压器测 | 换反馈电阻；修复前不要接主控 |
| 空载正常、带载就趴 | 滤波电容干涸 / 稳压芯片老化带载能力下降 / 输入限流电阻变值 | 用可调电源限流试验；量电容容量（需脱开一端） | 换电容优先，再换稳压 IC |
| 电池设备待机掉电快 | 保护板 MOS 漏电 / 某电容漏电 / MCU 没进休眠（固件问题） | 串万用表 µA 档量静态电流对比规格；分区断电找漏电点 | 换漏电元件；固件问题回软件排查 |

#### B. 主控类（板子"装死"，电源正常时查这里）

| 故障现象 | 常见原因 | 怎么确认 | 维修动作 |
| --- | --- | --- | --- |
| 电源全正常但单片机不跑 | 复位异常（复位电容漏电/复位 IC 坏）/ 晶振不起振 / BOOT 脚电平接错 | 量复位脚电压（应稳定在高/低电平，不能悬停中间）；示波器量晶振；核对 BOOT 丝印 | 换复位电容/复位 IC；换晶振或负载电容；改正 BOOT 配置 |
| 跑着跑着死机或自动复位 | 电源纹波过大（带载跌落瞬间复位）/ 高温死机（虚焊受热开裂） | 示波器抓电源轨瞬间跌落；按压+加热可疑区域复现 | 加大滤波电容；补焊；改善散热 |
| 程序偶尔跑飞、参数丢失 | 掉电时序不良（掉电检测欠佳）/ Flash 写入时被干扰 | 复现"拔电瞬间正在写数据"场景 | 加大掉电保持电容；软件侧加掉电检测（BOD/PVD） |
| 芯片局部发烫但功能时有时无 | 芯片半击穿（内部 ESD 损伤） | 断电摸热点+对地阻抗对比好板 | 更换主控（确认外围无短路后再换，否则新片秒坏） |

#### C. 接口与通信类

| 故障现象 | 常见原因 | 怎么确认 | 维修动作 |
| --- | --- | --- | --- |
| 串口乱码 | 波特率偏差（晶振损坏/被换过）/ TX、RX 接反 / 没共地 / 3.3V 与 5V 电平不匹配 | 逻辑分析仪抓波形数波特率；万用表通断档核对 TX→RX 交叉；量两端 GND 通断 | 换晶振；纠正接线；共地；加电平转换 |
| USB 不识别 | D+/D- 虚焊 / ESD 管击穿拉低信号 / 12MHz 晶振坏 | 量 D+/D- 对地阻抗对比好板；示波器看有无 12M 残留 | 补焊；拆/换 ESD 管；换晶振 |
| 485/CAN 总线不通 | A/B（或 H/L）接反 / 终端电阻缺失或短路 / 收发器芯片坏 | 量 A-B 间电阻（无终端电阻应为高阻，120Ω 终端 ×2 并联约 60Ω）；示波器看差分波形 | 纠正接线；补/修终端电阻；换收发器 |
| 按键失灵或误触发 | 按键氧化接触不良 / 上拉电阻缺失或虚焊 / 走线断 | 按下量通断档是否导通；量按键脚电平变化 | 换按键（几毛钱，直接换最快）；补上拉 |

#### D. 外设类

| 故障现象 | 常见原因 | 怎么确认 | 维修动作 |
| --- | --- | --- | --- |
| LED 不亮或忽明忽暗 | LED 开路死 / 限流电阻开路 / 虚焊 | 二极管档量 LED 压降（单向导通为好）；量限流电阻 | 换 LED/电阻；补焊 |
| 显示屏花屏/缺行缺列 | 排线接触不良（最常见）/ 驱动 IC 坏 / 背光供电异常 | 重新插拔排线（净手+断电）；量背光 LED 供电 | 清洁重插排线/贴胶带固定；换屏 |
| 继电器不吸合或常吸合 | 驱动三极管/MOS 坏 / 续流二极管击穿 / 线圈开路 | 量线圈电阻对比标称；量驱动管各极电压；二极管档量续流管 | 换驱动管/续流二极管/继电器 |
| 蜂鸣器不响 | 驱动管坏 / 无源蜂鸣器没给 PWM（固件） / 有源无源弄混 | 量驱动管输出；确认蜂鸣器类型（有源给电就响） | 换驱动管；固件侧查 PWM |
| ADC 读数漂移/不准 | 基准电压（VREF）不稳 / 分压电阻变值 / 前端 RC 电容漏电 / 地线干扰 | 量 VREF 是否稳定；脱开量分压电阻；量采样点电压与读数换算对比 | 换基准源/分压电阻/电容；改善地线 |
| I2C/SPI 传感器无数据 | 上拉电阻缺失或阻值过大 / SDA/SCL 接反 / 器件地址错（固件）/ 器件坏 | 断电量 SDA/SCL 对地阻抗（上拉正常应不到几十 kΩ）；示波器看有无 ACK | 补上拉（常用 4.7k）；纠正接线；换器件 |

#### E. 环境与人为类

| 故障现象 | 常见原因 | 怎么确认 | 维修动作 |
| --- | --- | --- | --- |
| 进水/腐蚀板 | 电解腐蚀致走线断裂、残留物漏电 | 放大镜看走线发绿发黑；酒精清洗后复测 | 超声/酒精彻底清洗 → 低温烘干 → 补断线（飞线） → 复测 |
| 雷击/浪涌后损坏 | TVS/压敏电阻牺牲（自身短路保护后级）/ 整流桥击穿 / 保险丝熔断 | 二极管档量 TVS 两端（短路即已牺牲）；量整流桥四臂 | 换保险丝+TVS+整流桥——**必须换齐，TVS 是一次性牺牲件** |
| 摔落后失灵 | 晶振最脆（先查）/ 陶瓷电容裂纹 / BGA 焊球裂 | 换晶振试验；轻按芯片中央复现 | 换晶振；补焊；BGA 返修超出入门范围送修 |
| 高温环境才出现故障 | 电解电容高温失效 / 虚焊受热膨胀 / 芯片热不稳定 | 常温正常+加热复现（热风枪低档远距离吹可疑区域） | 换电容；补焊；改善散热 |

> 对表心法：**现象像什么模块，就先扫哪张表；拿不准就回电源类**——五个表里查不出，回到第二节时间线从头走一遍，别急着怪芯片。

### 故障库实战案例：五类各一个，带读数走全程

下面五个案例对应 A~E 五类，每个都按第二节时间线 [0]~[7] 完整走一遍，关键测量值全部给实数——照着演练一遍，比读十遍表格管用。所有案例均为低压直流板。每个案例末尾配【动手实操步骤】与【注意事项】，把"怎么修"落到手上。

**实操通用工具准备**（五案例共用，动手前摆齐）：温控烙铁套装 + 焊锡丝（0.6~0.8mm）+ 助焊剂 + 吸锡带 + 防静电镊子 + 数字万用表 + 无水酒精 + 软毛刷 + 杜邦线/细漆包线 + 放大镜（或手机微距）。摆台原则：元件、工具、记录纸分三区，桌面铺硬纸板防刮花。

#### 案例一（电源类）：USB 小板 3.3V 轨"空载正常、带载趴"

**背景**：一块 USB 转 3.3V 供电的小板（AMS1117-3.3 LDO 降压），给外接模块供电。故障史：用户说"单独用正常，一接模块就重启"。

排查时间线：

```
[1] 问故障史：带载才坏 → 优先怀疑电源带载能力（对照 A 类第 3 行）
[2] 外观检查：电解电容（输入 10uF/输出 22uF）目视无鼓包——别被外观骗了，
    电容干涸常常不鼓包，先记下"电容嫌疑仍在"
[3] 电源轨测量（空载）：
    USB 5V 输入 → 实测 5.02V √
    3.3V 输出   → 实测 3.29V √ （空载全部正常！）
    ★ 关键动作：空载正常不等于修好了，带载复测——
      接上 100mA 假负载后 3.3V 跌到 2.61V ×（跌 0.7V，远超正常 0.05V 内）
[4] 二次定位：带载时手摸输出电容与 LDO，
    LDO 微温正常；输出电解电容毫无温感但电压在跌——电容嫌疑升至第一
[6] 定位验证：拆下输出电容，电容档实测容量 22uF 标称 → 实测 3uF ×
    （干涸衰减，ESR 大概率也已变大）
[7] 换件：换 22uF/16V 新电解 → 带载复测 3.28V 稳定 √ → 老化 10 分钟无异常
```

**复盘要点**：①"空载正常"是电源类故障最大的烟雾弹，**必须带载复测**；②电容干涸不鼓包，外观正常别急着排除；③换件后要复测原故障场景（接模块），不是只量空载。

**动手实操步骤**（带载测试 + 拆换电解电容）：

1. 做假负载：100mA@3.3V 约 33Ω 电阻（P=I²R≈0.33W，选 1W 以上防烫），或直接用故障时报的那个模块充当；
2. 带载复测：红笔点 3.3V 轨测试点、黑笔夹 GND，记录跌落值（本例 2.61V）——测试点优先选电容正极引脚，别探针打滑短路邻脚；
3. 断电放电：拔 USB → 数十千欧大电阻跨接电容两脚 3~5 秒 → 万用表确认两端 <0.1V 再动手；
4. 拆旧电容：烙铁 320℃ 同时加热两脚（或交替加热），另一手镊子夹电容身轻拔；顽固时先用吸锡带把两脚的锡吸走大半再拔；
5. 记极性：电解电容侧面竖条纹是负极 → 对应板上丝印的斜角/涂黑半区，拍照留底再拆；
6. 装新电容：按极性穿孔 → 先焊一只脚、趁焊锡未冷校正垂直 → 再焊另一脚 → 剪掉多余引脚；
7. 三段验证：空载量电压 → 带载复测跌落 <0.05V → 接回原模块跑原故障场景 10 分钟。

**注意事项**：

- 极性装反会鼓包甚至炸开——**通电前对着照片目检三遍**；
- 新电容耐压 ≥ 原耐压（原 6.3V 建议换 10V 以上更稳），容量等值即可、别随手翻倍（影响纹波与启动特性）；
- 单脚焊接 ≤3 秒，反复长时间加热会烫起焊盘；
- 引脚穿过孔后若插不进，先用吸锡带清孔，别硬怼。

#### 案例二（主控类）：STM32 最小系统板"电源全好却不跑"

**背景**：自己打样的最小系统板（对照 05 模块主线作品），焊完点不亮，LED 程序毫无反应。

排查时间线：

```
[1] 问故障史：首次焊接调试板，无外部损害史 → 排除雷击/进水，方向转向焊点与配置
[2] 外观检查：放大镜过一遍，发现 BOOT0 电阻一端焊点可疑（灰暗），
    先拍照记录，但不急着补焊——按流程走
[3] 电源轨测量：
    3.3V → 3.28V √ ；VDDA → 3.28V √ ；对地阻抗二极管档 0.62V √（无短路）
    → 电源排除，转 [4]
[4] 时钟复位确认：
    复位脚（NRST）电压 → 实测 1.7V ×（正常应接近 3.3V 稳定高电平）
    ★ 复位悬在中间电平 = 芯片一直被"按着重启键"，当然不跑
    量复位电容（0.1uF）→ 电容档实测漏电明显，脱开一端复测确认 ×
[5] 分块隔离：复位电容脱开后 NRST 回到 3.3V √
[6][7] 定位+换件：换新 0.1uF 复位电容 → NRST 稳定 3.28V √
    → 烧录点灯程序 → LED 亮起，老化 30 分钟无异常
    （BOOT0 那个灰暗焊点顺手补焊——虽不是本例病因，但属于潜在虚焊点）
```

**复盘要点**：①"装死"三板斧顺序：电源 → **复位** → 晶振，复位悬停中间电平是极高频病因；②中间电平的来源常是复位电容漏电或复位线虚接；③顺手发现的虚焊点当场补掉，别留给下一次。

**动手实操步骤**（复位电容测量与更换，0603 贴片）：

1. 在线初判：断电，电容档量复位电容两端——好电容读数应缓慢爬升后稳定；漏电电容读数偏低且回不到正常值，记录现象；
2. 脱开确认：按时间线第 5 步拆下一端复测（漏电结论必须"脱开一端"才算数）；
3. 拆件二选一：
   - 双烙铁法（推荐新手）：两把烙铁同时夹住元件两端，锡熔瞬间镊子一夹即下；
   - 热风枪法：320℃ 小风嘴对元件画圈加热（别定点猛吹），锡熔后镊子取下；
4. 清理焊盘：吸锡带把两端焊盘余锡拖平，露出光亮焊盘；
5. 贴装：镊子夹元件对位 → 烙铁点焊一端焊盘并送锡"钩"住元件 → 校正位置 → 再焊另一端；
6. 功能复测：NRST 电压稳定 3.28V → 按复位键，NRST 应瞬间跌到 0V 再弹回 3.3V（这个动作才是复位电路的"考试"）→ 烧录程序运行。

**注意事项**：

- 热风枪吹贴片区前，周围 1cm 内小件用铝箔纸/耐高温胶带遮蔽，防吹飞烤坏；
- 0603 很小，镊子夹持力要轻——一用力元件飞走，地上找半小时是常态（桌面铺白纸方便找）；
- 按复位键测试用指甲轻点，别用螺丝刀怼 PCB（板弯会带出新的虚焊）；
- NRST 是低有效复位：正常工作时必须是稳定高电平，量到中间电平先查电容再看复位按键是否卡住。

#### 案例三（接口类）：串口"乱码"

**背景**：51 学习板（12MHz 晶振）与 USB 转 TTL 模块通信，串口助手显示乱码。故障史：昨天还正常，今天接反过一次线。

排查时间线：

```
[1] 问故障史："接反过一次" → TX/RX 对调过、可能还热插拔过 → 接口类重点
[2] 外观检查：CH340 模块无异常；51 板晶振区域无摔痕
[3] 先做"软件侧排除"（不拆板）：
    串口助手波特率核对 → 两边都是 9600 √ ；校验位 8N1 √
    ★ 乱码第一嫌疑永远是"两边配置不一致"，先排除再动烙铁
[4] 接线核对（万用表通断档）：
    模块 TXD → 板 RXD？蜂鸣响 √
    模块 RXD → 板 TXD？蜂鸣响 √ （交叉正确）
    模块 GND → 板 GND？蜂鸣响... 但用电阻档复核 → 实测 8Ω ×
    ★ 通断档响≠良好！GND 排线内部似断非断，接触电阻 8Ω
[5] 换 GND 排线 → 电阻档 <0.5Ω √ → 串口助手输出正常中文 √
[6] 追加验证：连续收发 10 分钟无乱码，故障闭环
```

**复盘要点**：①乱码排查顺序：**波特率/配置 → 接线交叉 → 共地 → 电平匹配 → 才轮到晶振**；②通断档蜂鸣响不等于零阻，关键连接（尤其 GND）用电阻档复核；③"昨天还好好的"的故障史往往指向接触类问题而非元件损坏。

**动手实操步骤**（接线检测与更换）：

1. 四线逐一复核：TXD→RXD、RXD→TXD、GND→GND、VCC（如需要）——通断档先定位，再电阻档精测，**<1Ω 为合格**，逐根记录读数；
2. 弯折试验：边轻弯排线中段边盯电阻读数，读数跳动 = 内部断丝实锤（本例 GND 线 8Ω 且弯折时跳到 40Ω）；
3. 换线：杜邦线整根换新；排线插头用镊子轻挑锁扣再直拔，别斜着硬撬；
4. 共地改善：两端 GND 之间再并一根粗一点的线（地线细、阻抗大，是长线通信乱码的常见根因）；
5. 电平核对（顺手完成）：确认两端都是 3.3V 或都是 5V TTL——一端 5V 一端 3.3V 时加电平转换模块；
6. 连续验证：串口助手连续收发 10 分钟，字符无错、无偶发乱码才算闭环。

**注意事项**：

- 别只信蜂鸣——8Ω 它照样响，"响了"和"导通良好"是两回事；
- 杜邦母头氧化接触不良，用细针轻刮内壁或直接换线，反复插拔救不回来；
- 插拔捏插头壳，别拽线身——拽线就是新"似断非断"的生产过程；
- 量接线时把两端都断开设备（至少一端），避免在线并联路径干扰读数。

#### 案例四（外设类）：I2C OLED 屏无显示

**背景**：STM32 板驱动 0.96 寸 I2C OLED，程序无报错但屏幕全黑。故障史：屏是网上买的散新件，第一次接线。

排查时间线：

```
[1] 问故障史：全新搭建、首次点亮 → 排除"用坏"，方向转向接线与硬件配置
[2] 外观检查：屏排线无歪斜；VCC/GND/SDA/SCL 四线按丝印插好
[3] 电源轨：屏 VCC 引脚实测 3.3V √ （供电到了）
[4] I2C 总线电平测量（关键步骤）：
    断电，量 SDA 对地电阻 → 实测 34kΩ √（确认"板上有上拉"）
    量 SCL 对地电阻 → 实测 34kΩ √
    ★ 为什么不是标称的 4.7k？——在线量走的是"上拉→VCC 轨→板上负载"的
      组合路径，读数本来就不等于单只电阻；此处只判两件事：
      上拉存在（不是开路的无穷大）、两只读数接近（两线对称）
    上电，程序发数据时量 SDA/SCL → 有明显电平跳变 √（总线在动）
[5] 分块隔离：换一块同型号好屏 → 立刻显示 √ → 原屏坏
[6] 二次确认：原屏单独接 USB 供电查 I2C 地址应答 → 无 ACK ×，坐实屏坏
[7] 换屏复测：点亮老化，同时用手轻弯排线根部，显示稳定 √
```

**复盘要点**：①I2C 无显示排查链：**供电 → 上拉存在 → 总线有波形 → 换屏对照**；②"换好件对照"是外设类最快的判决手段（案例三替换法）；③新购散新件先怀疑自身，别一上来怀疑自己的代码。

**动手实操步骤**（换屏对照与排线处理）：

1. 断电拔原屏：捏排线插头壳垂直直拔（FPC 插座先轻挑黑色翻盖再抽排线，0.5mm 间距排线怕斜撬）；
2. 好屏对照：同型号好屏原位插上 → 显示正常 → 原屏嫌疑升至 90%；
3. 原屏独立验证：原屏接独立电源看背光是否微亮（能亮说明背光电路活着，只是控制部分/驱动坏）；有第二块主控就再上一次对照，排除"两块板恰好都挑屏"的小概率；
4. 排线根部检查：放大镜看 FPC 排线根部 3mm 内——这里是弯折裂纹高发区，裂纹发白或断续；
5. 复装复测：新屏装回 → 上电显示 → 用指腹轻压排线根部与轻弯排线，显示不闪不灭才算合格。

**注意事项**：

- I2C 屏地址可能不同（常见 0x78/0x7A，SA0 脚接法决定）——换屏后全黑先查地址再骂屏；
- FPC 插座与排线插拔寿命有限（几十次量级），调试期别反复插拔，用"整组换屏"代替"换线试验"；
- 屏玻璃与排线怕静电：操作前先摸接地金属，冬天干燥季尤其要紧；
- 屏四周螺丝/胶垫装回时对称受力，单边拧紧会压裂玻璃（表现为新裂纹型花屏）。

#### 案例五（环境类）：进水板复活全流程

**背景**：一块带锂电池的温湿度记录仪板，桌面打翻饮料浸过。用户曾试开一次机，未果后送修。

排查时间线：

```
[0] 接板即断电、取出锂电池、断开电池排线——**带水绝不上电**
[1] 故障史：含糖饮料！糖分残留会持续导电腐蚀，比清水恶劣得多
[2] 外观检查：USB 口附近板面发黏，放大镜见几处走线已发绿（早期腐蚀）
[3] 清洗（先于一切测量）：
    无水酒精（或专用板清洗剂）软毛刷刷洗浸液区 → 酒精冲淋两遍 →
    低温烘干（吹风机冷热风交替远吹 30 分钟，别聚焦一点烤）
[4] 复测电源轨：
    接稳压电源限流 100mA 供入 5V → 整板电流 12mA（正常待机量级 √）
    逐轨量 3.3V/1.8V 均 √ ——大部分"进水病"在洗干净后自愈
[5] 补救腐蚀点：一处走线发绿处通断档实测已断 ×
    → 飞线修复：刮开两端焊盘绿油上锡，细漆包线跨接 → 通断 √
[6] 整机复测：装电池开机 → 正常采集；上电 30 分钟摸检无异常热点
[7] 交付提示给用户：腐蚀有潜伏期，一周内若再出问题及时回修
```

**复盘要点**：①进水板流程口诀：**断电 → 取电池 → 清洗 → 烘干 → 限流上电**，顺序错了可能把可修复板修成报废板；②限流上电是进水板的第一道保险（电流异常立刻断，防止二次损伤）；③糖类/盐类液体必须彻底清洗，清水凉干不算完事。

**动手实操步骤**（清洗、烘干、飞线修复）：

1. 拆解与吸液：取出锂电池、断开排线 → 纸巾先吸走游离液体 → 拆下能拆的塑料件与屏蔽罩（藏液体重灾区）；
2. 刷洗：软毛刷蘸无水酒精反复刷浸液区，刷子带出的液体"不黏手"为洗净标准；糖/盐类液体至少重复刷洗两遍；
3. 冲淋：酒精沿板面冲淋两遍带走残留，重点冲连接器孔位与 IC 底部缝隙；
4. 烘干：烘箱 60℃ 30 分钟，或吹风机远距离（≥15cm）冷热风交替、板面倾斜放置让残液顺流而出；静置回温 10 分钟；
5. 限流上电：稳压电源限流 100mA 供入标称电压，观察电流读数——秒回正常待机量级（本例 12mA）→ 逐轨复测电压；
6. 飞线补断线（仅限确认断的走线）：刮开断线两端绿油露出铜箔 → 各上薄锡 → 0.1~0.15mm 漆包线（两端头先上锡）跨接焊牢 → 中段点一滴胶固定 → 通断档复测；
7. 整机验证：装电池开机全功能测试 → 上电 30 分钟摸检无异常热点 → 记录维修档案并告知"腐蚀有潜伏期"。

**注意事项**：

- 酒精易燃：远离火源、开窗通风、别在点着烙铁的同一时刻大量倾倒酒精；
- **烘干不彻底就上电 = 二次短路**，宁可多烘半小时，摸上去有潮气/凉感就不算干；
- 清洗剂禁用自来水（矿物质残留导电），酒精也须是无水的（医用低浓度酒精含水多，残留照样漏电）；
- 飞线走线避开天线区、晶振区和接口插拔路径；飞线过长要贴板固定，悬空线是下一次"接触不良"；
- 电池泡过液体的板子，电池本身要单独评估（鼓包/异温直接判废换新），别只修主板。

**五案例通用规律**（读完后自己总结一遍再对照）：
1. 每个案例都走了完整时间线，但**各案例的"卡点"不同**——电源类卡在带载复测、主控类卡在复位、接口类卡在共地、外设类卡在换件对照、环境类卡在先洗再修；
2. 万用表读数"好/坏"全靠**对照**：对照标称值、对照好板、对照空载/带载；
3. 修复动作都很小（换一颗电容、换一根线、补一条飞线）——维修的价值全在**定位**，定位准了换件只是收尾。

## 四、焊接基础速成：换件的基本功

焊接是把新元件"长"到板子上的手艺，修板子绕不开；它也是新手与老师傅差距最直观的地方——同一个元件，老师傅焊的能用十年，新手焊的三天就虚。

核心认知先建立：**焊锡不是胶水，是让焊锡与金属形成合金层的冶金过程**——所以温度、清洁、助焊剂缺一不可。

- **烙铁温度**：常用 **300~350℃**。无铅焊锡熔点更高，可略上调；温度过高反而烧焦助焊剂、损伤焊盘。新手用带温控的烙铁，别用"一插电不知道多少度"的老式烙铁。
- **助焊剂的作用**：去除金属表面氧化层、提升焊锡流动铺展性。焊不上、拉尖、发渣，九成是助焊剂不够——补一点再焊，立竿见影。
- **标准动作**：烙铁头同时接触焊盘与元件引脚约 1~2 秒 → 送焊锡丝让其熔化铺开 → 撤锡丝 → 撤烙铁 → 自然冷却（别吹气加速）。
- **拖焊拆多脚芯片**：拆多引脚芯片时给引脚排足量堆锡，烙铁沿引脚排连续快速"拖"过，使整排焊点同时熔化，用镊子取下芯片；装新件则先对角固定两个引脚再拖焊其余引脚，最后用吸锡带清理连锡。
- **吸锡带用法**：吸锡带覆在焊点上，用烙铁隔着吸锡带加热——熔化的焊锡被铜编织带吸走。用于拆件清场和清理连锡。
- **焊接质量标准**：好焊点**光亮、圆润、呈锥形**，焊锡均匀包裹引脚与焊盘；**虚焊的特征是表面灰暗粗糙、有裂纹、锡与引脚"假接触"**——看起来有锡、实际没形成合金层，时通时断，是"时好时坏"故障的头号来源。

新手焊接失败对照表：

| 现象 | 大概率原因 | 对策 |
| --- | --- | --- |
| 焊锡成球不铺开 | 焊盘/引脚氧化或脏污 | 先清洁，补助焊剂再焊 |
| 焊点拉尖 | 烙铁撤离不对或温度偏低 | 先撤锡丝再撤烙铁，沿引脚方向带出 |
| 焊点灰暗粗糙 | 温度过高烧焦助焊剂 / 焊锡质量差 | 降 20℃、换优质焊锡丝 |
| 虚焊（时通时断） | 加热时间不足、没形成合金层 | 补助焊剂重新加热 1~2 秒 |

练手建议：拿废板（或某宝几毛钱的洞洞板）专门练 50 个电阻焊点，再挑战拖焊，成本极低。

## 五、维修禁忌：这些动作会让小病变大病

1. **带电插拔卡板/模块**：插拔瞬间的浪涌和引脚错位短路，专打接口和主控——必须断电插拔。
2. **乱调可调电阻/出厂参数**：无标记地拧动可调电阻、乱改配置，可能把设备校准参数毁掉，且几乎无法复原。动之前先记录原位置。
3. **直接短接保险丝**：保险丝熔断是它在"用生命报警"，背后必有短路原因；短接后上电等于让短路继续烧，可能烧毁更贵的部件。先找短路根因。
4. **用嘴吹板上的灰尘**：口腔湿气 + 静电可能损伤电路，还可能把唾沫喷进板子。用防静电毛刷或气吹清理，操作前先摸接地的金属物释放自身静电。
5. **换件不看规格硬代换**：耐压不够的电容换上去爆给你看，功率不足的电阻换上去冒烟。换件原则：**同型号 > 同参数（容量/耐压/功率/封装）> 确认可靠后的大厂等效替代**。
6. **上电"试一试"心理**：外观有明显烧焦、进水、漏液的板子，不处理直接上电，往往把"一个坏元件"变成"一片坏区域"。先检查、先放电、再上电。
7. **进水板直接上电烘干**：水是导体，带水通电等于人为制造短路。正确做法：断电 → 清洗 → 低温彻底烘干 → 确认干燥后再测再上电。
8. **修完不复测就交付**：换件后只确认"原来的现象消失"还不够，要把所有电源轨复测一遍，防止换件过程引入新故障。

## 常见坑（新手必看）

1. **忘放电就上手**：含大电容的板子断电后仍有残压，量之前先用大电阻给电容放电，这个动作要练成肌肉记忆。
2. **在线量电阻当真值**：电路是网状并联的，不脱开一端量出的电阻值不可信，二极管档对地阻抗才是判断短路的正确姿势。
3. **换了保险丝就收工**：没查清熔断原因，新保险丝大概率再熔一次，还可能烧出更大损失。
4. **虚焊看不出来**：虚焊点外观可能完全"正常"，按压复现 + 补焊是最快的确认手段；放大镜/手机微距拍照是穷人版检测仪。
5. **以为芯片最可疑**：新手总想换主控芯片，实际统计上电源、电容、连接器的故障率远高于芯片——先查外围再怀疑核心。
6. **热风枪温度风量乱开**：温度过高、风量过大会吹飞周边小元件、烤坏连接器，拆件前用废板练手感。
7. **静电打死元件不自知**：干燥天气人体静电轻松过几千伏，摸板前先放静电，敏感芯片（尤其接口类）存放用防静电袋。
8. **修好了不老化验证**：当场点亮不等于修好，虚焊和热稳定性问题常在运行升温后复现——修完至少通电运行观察一段时间。

## FAQ

1. **Q：完全零基础，第一件该买的工具是什么？** A：几十元的自动量程数字万用表。维修三板斧里两板斧靠它，详见 [04-其他常用开发工具速查](04-其他常用开发工具速查.md) 的装备清单。
2. **Q：万用表的二极管档为什么能判断短路？** A：二极管档输出一个小电流恒压测试信号，读数反映两点间的压降特征；对地阻抗极低（接近 0V 压降）说明该点与地近似直通，即短路。
3. **Q：怀疑电容坏了但不想拆，能在线量吗？** A：在线测只能看"是否击穿短路"；容量和 ESR 的准确测量需要至少脱开一端，专业判断用带 ESR 功能的仪器。
4. **Q：没有示波器怎么确认晶振起振？** A：部分万用表频率档可粗测晶振引脚频率（信号弱、不一定可靠，仅供参考）；更可靠的办法是替换法——换晶振或换负载电容试验。正式学习建议按 [06-测量仪器与调试排障](../../02-电路基础/笔记/06-测量仪器与调试排障.md) 配齐观测手段。
5. **Q：维修学多久能接活？** A：低压直流板级维修的基本功（三板斧 + 时间线 + 基础焊接）认真练一两个月即可入门；但市电侧设备（开关电源初级、家电强电部分）属于强电领域，需要系统的电气安全训练，本篇不做鼓励性展开。
