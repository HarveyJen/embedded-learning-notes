# 02 · 立创EDA PCB设计

> 定位：原理图是族谱，PCB 是族谱落成的房子。这一篇教你把 01 篇的最小系统原理图，变成一块能寄去工厂生产、一周后拿在手里的真板子。

**先说人话**：本篇讲什么，学完能做什么——

把原理图一键转成 PCB，画板框、摆器件（布局）、拉铜线（布线）、铺地铜、跑 DRC 检查，最后导出 **Gerber + BOM + 坐标文件**三件套，在嘉立创花几块钱下单打样。学完你能独立完成一块双层板的全流程，"画一块自己的板子"从此不再是别人的技能。

---

## 1. 原理图到 PCB：先想清楚关系

> **这是什么**：原理图只管"谁连谁"（逻辑关系），PCB 管"具体谁挨着谁、线怎么走"（物理实现）。族谱上你和大伯是叔侄关系，但房子里你俩住不住对门，是另一码事——住对门（布局好）串门就快（信号好），住远了天天跑断腿（信号差、干扰大）。

工程树里原理图和 PCB 是两个文件，但通过网络（Netlist，连接关系清单）绑定：改了原理图要同步到 PCB，PCB 不能"自由发挥"乱连。

## 2. 转换与板框

**一键转换**：打开 01 篇完成的原理图 → 菜单 **设计 → 原理图转 PCB**【以当前版本为准】→ 软件自动新建 PCB 文件，所有器件带着**飞线**（表示"这两个脚该连"的细线）堆在板框外。

**转换后先做三件事**：

1. 确认器件数量：原理图里多少个位号，PCB 里就该有多少个封装，少了就是有器件没封装；
2. 确认封装没张冠李戴：随机点开两三个器件，看焊盘形状对不对（排针该是 1 排孔、LED 该是两个焊盘）；
3. 心里过一遍布局草图：先别急着拉线，这一步动脑比动手重要。

**画板框**：

1. 在 PCB 编辑页左侧找到层管理/设计管理器，切换到**边框层（Board Outline / 板框层）**【名称以当前版本为准】；
2. 用导线/矩形工具画一个**闭合**矩形，比如 40mm × 30mm（闭合是硬要求，不闭合导出 Gerber 会报错）；
3. 新版软件也有板框绘制向导/快捷入口，以当前版本界面为准；
4. **禁布区**：板边、安装孔周围、接插件下方等"不许放器件/走线"的区域，用禁布区工具圈出来【部分版本在层设置或放置菜单里，以当前版本为准】。经验：器件离板边至少留 2mm 以上。

## 3. 布局原则（成败在布局，不在布线）

> **这是什么**：布局 = 搬家时先定大件家具的位置。大件摆对了，小件随手放都顺；大件摆歪了，后面怎么挪都别扭。

| 原则 | 白话解释 |
|------|----------|
| 先大后小 | 先放主芯片、排针、按键等大件，再塞电阻电容 |
| 先核心后周边 | 主芯片居中偏板内，别贴边 |
| 去耦电容贴电源脚 | 0.1uF 电容必须紧贴对应 VDD 引脚背面/旁边，这是性能铁律 |
| 晶振靠近芯片 | 晶振+负载电容紧贴 OSC 引脚，走线越短越好，晶振下方别走其他信号线 |
| 接口靠板边 | SWD 排针、电源排针放板边，插线不用把手伸进板子中间 |
| 模拟数字分区 | 本主线全是数字电路暂不涉及；记下这条，以后画带 ADC 的板子再说 |

实操手法：从原理图选中一个功能块（如晶振电路），PCB 里对应器件会联动高亮，抱团摆好再摆下一块。

**布局操作顺序（跟着做）**：

1. 全选器件（框选或快捷键），整体拖进板框内，别让器件悬在板外；
2. 摆主芯片：拖到板中央，空格旋转到顺手的方向；
3. 摆接口件：SWD 排针、电源排针拖到板边；
4. 摆"贴身件"：去耦电容一颗颗贴到对应 VDD 引脚旁边（可以放在芯片正背面），晶振+两颗负载电容贴 OSC 引脚；
5. 摆"抱团件"：复位电阻电容按键一组、BOOT 电阻一组，各占一个角落；
6. 预览走线通道：目测主芯片到排针之间有没有路，器件别把路口堵死——布局阶段多想 30 秒，布线阶段少拧 30 分钟。

## 4. 布线规则表（工程经验值）

> **这是什么**：布线 = 在房子里铺水管电线。粗细按"流量"（电流）定，间距按"不打架"定。下表是工程常用经验值，新手照抄够用；严格设计用线宽计算器算。

| 项目 | 常用值（经验值） | 说明 |
|------|------------------|------|
| 电源线宽 | 1A 电流 ≈ **20~30mil 起步** | 越粗越好，本主线 3.3V/GND 建议 20mil 以上 |
| 信号线宽 | **10mil 级** | 普通 GPIO、晶振线足够 |
| 过孔 | 外径/孔径 **20/10mil**（0.5/0.3mm）最典型 | 换层时打孔，别用太小的孔增加成本 |
| 线间距 | **≥ 线宽**（保守） | 防止生产与串扰问题，DRC 默认规则通常更宽松，可自行收紧 |
| 差分等长 | 概念先行 | USB、CAN 等差分对要求两线等长等距，本主线用不到，知道有这回事即可 |

布线操作：快捷键 `W` 开始布线【以当前版本为准】，顶部/右侧属性栏可改线宽；布线中按数字键或 `*` 切换层，软件自动放过孔【以当前版本为准】。优先把 GND 留给铺铜，能不走长地线就不走。

**布线推荐顺序**：

1. 先走电源（3V3/GND 主干，粗线），电是全板的生命线；
2. 再走晶振线（最短最直，区域净空）；
3. 然后走 SWD 调试线（PA13/PA14 到排针，短直为佳）；
4. 最后走杂散信号线（LED、BOOT、复位），哪有飞线走哪；
5. 收尾确认：底部面板/飞线显示里**飞线数 = 0**，一根都不能剩。

> 单位换算：1mil = 0.0254mm，40mil ≈ 1mm。

## 5. 铺铜与接地

> **这是什么**：铺铜 = 把板子上没走线的空地全浇上"GND 铜皮"。相当于整栋楼的地板都是接地极——信号想回家（回流）随时脚边就是路。

操作：菜单 **布线/放置 → 铺铜区域**【以当前版本为准】沿板框画一圈，属性里设置：

- 网络 = `GND`；
- 顶、底两层各铺一块；
- 画完右键"重建铺铜"让铜皮避让开走线。

**过孔缝合**：顶底两块 GND 铜皮要"焊"成一体，隔一段距离打几个 GND 过孔（把两面地板钉在一起的钢筋钉）。本主线板子小，随手打十来个即可，密集缝合是高速板的讲究。

## 6. 丝印与安装孔

- **丝印** = 印在板子上的白字和白框：位号（R1、C1）、极性标记、板名版本号（如 `MINI-STM32 V1.0`）。操作：切到丝印层，用文字工具添加【以当前版本为准】；排针旁标上 `3V3 SWDIO SWCLK GND`，插线不再靠猜；
- **安装孔**：四角放 3mm 孔（配 M3 螺丝），菜单"放置 → 安装孔"【以当前版本为准】；孔位离板边和器件留够距离，别让螺丝柱压到电容。

## 7. DRC 设计规则检查

> **这是什么**：DRC = 工厂请的"验收监理"，专查线离得太近、该连没连、不该连的连上了。交板前必跑，报错清零才导出。

菜单位置：**设计 → 检查 DRC**（以当前版本为准），双击报错可定位。

| 报错 | 人话 | 处理思路 |
|------|------|----------|
| 间距不足 | 两条线/焊盘贴太近，工厂可能连一起 | 挪线、换层绕开、或收细其中一条 |
| 开路 | 飞线还在，该连的没连 | 看残留飞线补布线；别放过任何一根 |
| 短路 | 不该碰的线碰上了 | 拖动检查交叉点，删多余线段；铺铜网络设错 GND 也会报这类 |

## 8. 导出生产文件三件套

> **这是什么**：工厂不认你的工程文件，只认三样：Gerber（板子的"照片底片"，行业通用格式）、BOM（要买哪些料的清单）、坐标文件（贴片机把元件摆到哪的坐标表）。

在 **制造**（或文件 → 导出）菜单下找以下导出项【菜单位置以当前版本为准】：

1. **Gerber（PCB 制板文件）**：给板厂做板身；
2. **BOM（物料清单）**：位号、型号、封装、数量一张表。导出后可对照真实工业产品的组织方式：[08-真实工业产品BOM案例-LX750PLUS](../../02-电路基础/笔记/08-真实工业产品BOM案例-LX750PLUS线材测试仪.md)；
3. **坐标文件（Pick and Place / 贴片坐标）**：只有你要 SMT 贴片时才需要。

## 9. 下单嘉立创打样（流程白话）

1. 登录嘉立创官网，入口在 PCB 下单页【以官网为准】；
2. 上传 Gerber 文件（压缩包），网站自动解析板子尺寸层数；
3. 选参数：双层板、常用板厚 1.6mm、喷锡（默认绿色阻漆最便宜）；
4. **5 元打样梗**：小尺寸双层板常有"5 元打样"活动（有尺寸数量限制，以当期活动页为准），几块钱体验真实生产；
5. **SMT 贴片（可选）**：上传 BOM + 坐标文件，元件直接从立创商城配齐、机器焊好寄来——新手建议**第一块板选裸板自己焊**，练手艺、坏了好排查；
6. 下单后约 3~5 天到货（以实际物流为准）。

下单参数速查（学习板通用安全选项）：

| 参数 | 推荐选项 | 说明 |
|------|----------|------|
| 板层 | 2 层 | 双面板，学习板标配 |
| 板厚 | 1.6mm | 行业最常见厚度 |
| 阻焊颜色 | 绿色 | 最成熟最便宜，别为颜色加钱 |
| 数量 | 5 块 | 打样通常按最小起订量送 |
| SMT | 首板建议不加 | 自己焊更有收获，见上文 |

## 10. 实操主线：最小系统板全流程

接续 01 篇的原理图，一口气走完：

1. **转换**：原理图 → 设计 → 原理图转 PCB，确认所有器件到位；
2. **板框**：边框层画 40mm × 30mm 闭合矩形；
3. **布局**：主芯片居中 → 去耦电容贴 VDD 脚 → 晶振贴 OSC 脚 → 复位/BOOT 电阻电容抱团 → SWD 和电源排针靠板边 → LED 找个空地；
4. **布线**：信号线 10mil，电源/地 20mil 以上，晶振走线最短优先，剩余全部交给铺铜；
5. **铺铜**：顶层、底层各铺 GND，重建铺铜，打若干缝合过孔；
6. **丝印**：板名版本、SWD 排针每根针的名称、LED 旁标 `PWR` 之类功能字；
7. **安装孔**：四角 3mm；
8. **DRC**：报错清零；
9. **三件套导出**：Gerber + BOM + 坐标文件（裸板下单可只交 Gerber，BOM 留着自己买料用）；
10. （可选）真实下单一块——花几块钱，收获"这是我设计的板子"的实物。

## 常见坑（新手必看）

1. **改了原理图忘了同步 PCB**：后续改动用"设计 → 更新 PCB/导入变更"【以当前版本为准】，别删了重转（位号布局全丢）；
2. **板框不闭合**：差一个小缝隙，Gerber 导出或工厂审核直接打回；
3. **去耦电容摆太远**：原理图上对了、PCB 上摆到两厘米外，等于没去耦，电源一抖芯片就复位；
4. **晶振下面走信号线**：时钟被骚扰，板子"玄学死机"，晶振区域净空；
5. **电源线太细**：8mil 走 500mA，轻则压降重则发热，对照第 4 节规则表；
6. **铺铜没设 GND 网络**：铺了一块"悬空铜皮"，既不起作用还可能惹 DRC 报错；
7. **丝印压焊盘**：白字印在焊盘上，焊接时字被烫掉还影响上锡，丝印挪开；
8. **DRC 报错直接无视**：交板前的报错就是工厂替你省的返工钱，一条条消灭再导出。

## FAQ

**Q1：双层板够用吗？要不要上四层？**
学习阶段双层完全够。四层板（中间整层做地/电源）抗干扰更好，等做高速电路再学。

**Q2：Gerber 到底是什么？**
把 PCB 每一层（走线、丝印、阻焊…）各导出成一张"底片"的标准格式，全世界的板厂都认，你不用懂内部格式，导出上传即可。

**Q3：5 元打样是真的吗？**
真有这类活动，但有尺寸/数量限制，且参数选项影响价格，以嘉立创当期活动页为准。教学用小板基本都能蹭到最低价。

**Q4：第一块板要不要选 SMT 贴片？**
建议裸板 + 自己焊。焊接是嵌入式的手艺活，且自己焊的板子坏了你会修；SMT 适合料小难焊或量产时用。

**Q5：板子打回来焊好点不亮怎么办？**
先查供电电压、再查晶振起振、再查复位和 BOOT——完整排查套路见 05 篇电路板维修实战。
