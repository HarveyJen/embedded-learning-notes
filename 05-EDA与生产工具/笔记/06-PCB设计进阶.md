# 06 · PCB设计进阶

> 定位：02 篇教你"画出能跑的板子"（及格线），本篇教你"画出稳定工作、不干扰别人、也扛得住别人干扰的板子"（良好线）——最小系统板打样成功之后的下一步。

**先说人话**：本篇讲什么，学完能做什么——

02 篇的最小系统板焊好能点亮，说明"连对了"；但为什么有的板子插上 USB 就让旁边收音机吱吱叫？为什么接个继电器自己就复位？为什么晶振旁边走根线时钟就不稳？这些全是 **EMC（电磁兼容）**问题。学完本篇，你画板时会多问三个问题：**电流怎么回去**（回流路径）、**这根线算不算"长"**（阻抗匹配）、**干扰从哪进从哪出**（三要素）；并且能回头把自己 02 篇的最小系统板审一遍，改出一张 v2.1 图。

前置要求：先完成 [02-立创EDA-PCB设计](02-立创EDA-PCB设计.md) 的完整打样流程。电源与去耦的基础概念在 [04-电源与稳压电路](../../02-电路基础/笔记/04-电源与稳压电路.md)，本篇不重复。

## 1. EMC 是什么：自己不吵别人，也扛得住别人吵

> **这是什么**：EMC（Electromagnetic Compatibility，电磁兼容）= 两句话：**自己工作时产生的电磁骚扰别超标**（不干扰别人，叫 EMI），**自己扛得住外来的电磁骚扰**（不被别人干扰，叫 EMS）。类比公共场合素质：说话音量别扰民（EMI），同时听力够好、别人讲话你能听清（EMS）。

- 产品上市要过 CE/FCC 等认证，EMC 都是硬项目；
- 学习和比赛阶段没人罚你，但"板子莫名其妙不稳定"的多数疑难杂症，本质就是 EMS 没做好——所以学 EMC 不是为了应付认证，是为了少熬夜。

## 2. 干扰三要素与三条传播路径

> **这是什么**：任何电磁干扰都能拆成三件套：**骚扰源**（谁在吵）→ **耦合路径**（声音怎么传过去）→ **敏感设备**（谁被吵到）。三件掐死任何一件，干扰问题就解决。类比：邻居家音响（源）、墙和空气（路径）、正在睡觉的你（敏感设备）——关音响（掐源）、贴隔音棉（断路径）、戴耳塞（保护敏感端），三条路都通。

嵌入式板子上的常客：

| 角色 | 板上的"人" |
|------|-----------|
| 骚扰源 | 开关电源的开关动作、晶振/时钟线、MOS 管开关沿、继电器线圈断开瞬间、电机电刷 |
| 敏感设备 | ADC 输入、复位电路、晶振电路、模拟小信号链 |
| 路径 | 下面三条传播路径 |

三条传播路径（类比"隔墙传声 / 顺水管传 / 空气广播"）：

| 路径 | 机理（大白话） | 类比 | 典型案例 |
|------|----------------|------|----------|
| 耦合（近场感应） | 两根挨着的线，一根上变化的电压/电流通过寄生电容、互感在另一根上"感应"出噪声 | 隔墙传声：墙越薄（靠越近）听得越清 | 排线里时钟线和复位线长距离并行，时钟一动复位就误触发 |
| 传导（顺线传播） | 噪声顺着电源线、信号线"走有线"，公共电源/地阻抗是它的高速路 | 顺着水管传到隔壁 | 继电器吸合瞬间拉垮 5V 轨，共享这条轨的单片机跟着复位 |
| 辐射（空间发射/接收） | 高频电流流过"天线状"的环路或长线，向空间发射；反过来长线也能当天线接收 | 空气广播电台 | 一米长的 USB 线成了天线，插上电脑触摸屏就乱跳 |

排查顺序经验值：**先查传导**（最常见、最好查，示波器挂电源轨就能看）→ **再查耦合**（看布局有没有长距离并行线）→ **最后怀疑辐射**（通常要环路大、频率高才明显）。新手最容易犯的错是一上来就怀疑"辐射"，其实十有八九是传导。

动手前先填这张"三要素登记表"，问题立刻清晰：

| 问 | 填什么 | 掐这里 |
|----|--------|--------|
| 源是谁 | 继电器？DC-DC？晶振？ | 掐源：加 RC 吸收、换软开关方案、降速 |
| 路在哪 | 共电源轨？并行排线？长环路？ | 断路：分离供电、拉开距离、缩小环路 |
| 受害者是谁 | 复位脚？ADC？晶振？ | 护弱：滤波、去耦、加保护器件 |

三个都能掐当然最好；实际工程里"断路径"通常最便宜最快——改布局比改电路容易。

## 3. 回流路径与地平面：铺铜接地不是玄学

> **这是什么**：电流永远走闭环：从电源出发经负载，必须有一条"回来"的路。信号电流沿信号线过去，返回电流沿地/电源平面回来——而且**高频时它专挑环路电感最小（面积最小）的路走，通常就是信号线正下方的地铜**。类比：下班回家你选最快的路；高频回流也选"阻抗最小"的路，那条路恰好就在信号线正下方。

为什么强调这个（把"玄学"变成物理）：

1. **环路面积 = 发射天线面积**。去程和回程抱得越紧，两个磁场抵消得越好，对外辐射越小；回流绕了大弯，环路撑大，这块板就成了一个小广播电台；
2. **回流也怕绕路**。信号线在布局上拐个弯、打个孔，回流要是被迫绕一大圈找地，环路瞬间变大——干扰、串扰、EMI 全来了。

由此得出四条朴素结论（这就是"铺铜接地"背后的原理，不用背咒语）：

1. 双面板尽量两面铺 GND 铜，信号线正下方保持**完整地铜**；
2. 地铜别被长槽、断口切成"迷宫"——切断了的地方，回流只能绕行；
3. 信号**换层打孔**时，在孔旁边就近补一个地过孔给回流"搭桥"；
4. 电源主干走线旁边尽量有一条并肩的地回流路径，环路最小。

```
信号线（顶层） ──────────────────────►
地铜  （底层） ◄──────────────────────   ← 高频回流就在信号线正下方
                    ↑ 环路面积小，辐射小

信号线打过孔去底层时：
顶层 ────┐
         │过孔
底层     └────►   但回流还在顶层！
就近补一个地过孔：回流跟着过孔下去，环路才不变大
```

**布线时每走一根线，自检三问**：

1. 这根线的电流从哪来、**从哪回**？（答不出回流路 = 埋雷）；
2. 回流路上有没有被我切的槽、跨域的断口？（有 → 换路或缝合）；
3. 这根线换层了吗？换层的孔旁边有没有地过孔？（没有 → 补一颗，成本忽略不计）。

## 4. 阻抗匹配入门：50Ω 到底是什么

> **这是什么**：走线在"快边沿信号"眼里不是导线，而是**传输线**：它对快速变化的信号表现出一个瞬态阻抗，叫**特性阻抗**——由线宽、与参考平面的距离、板材介电常数共同决定，行业最常用的目标值是 50Ω。类比：水管突然变粗或变细，水流会在变径处来回撞出"水锤"；信号在阻抗突变处也会来回反射，波形上表现为振铃、台阶、过冲。

先破一个新手误解：50Ω **不是**用万用表量走线能量出来的电阻——它是信号"边沿"看到的瞬态阻抗，万用表量出来的永远是欧姆级的直流电阻（基本等于 0）。

**什么时候才需要管（粗判据）**：关键不是时钟频率多高，而是**信号上升时间**。工程粗判经验式：

```
FR-4 上信号传播速度经验值 ≈ 15 cm/ns
临界长度经验公式：走线长度 L（cm） > 约 2.5 × 上升时间 Tr（ns） 时，按传输线对待
（即：走线传播延时超过上升时间的约 1/6，反射就开始明显——经验法则，用于粗判）
```

举例（数字为示例）：某信号上升时间 4ns → 临界长度约 10cm。普通 STM32 GPIO 推 LED、板上走 5cm 线：不用管；拉一根 30cm 排线去连外设、或走 USB 差分线：必须按传输线对待。具体芯片的边沿参数以原厂 datasheet 为准【待查证】。

新手阶段背这三条就够：

1. USB、CAN 这类差分总线按协议要求控阻抗（90Ω、120Ω 等，以协议为准），四层板让厂家控；
2. 普通 GPIO 短线：不管它，不丢人；
3. 长线 + 快边沿出现振铃：**源端串一个 22~33Ω 电阻**（经验值），大多数情况就能压住。

真要处理时，常见端接手段速查（知道名字和用途即可，深究留给规划中的信号完整性篇）：

| 端接方式 | 一句话原理 | 适用 |
|----------|-----------|------|
| 源端串阻（串联端接） | 在驱动端串电阻，把驱动阻抗"补"到接近走线阻抗，反射波回源头被吸收 | 点对点信号最常用，一颗电阻搞定 |
| 并联端接 | 在接收端对地（或对电源）接一只等于特性阻抗的电阻，吞掉反射 | 挂总线的末端，代价是一路直流功耗 |
| 差分线控阻抗 | 一对线互相为对方提供回流路径，按协议控差分阻抗 | USB/CAN/网线等差分总线 |
| 不端接 | 短线 + 慢边沿时反射小到看不见 | 板内普通 GPIO 短线 |

## 5. 层数选择：双面板还是四层板

> **这是什么**：层数 = 板子里有几层铜。双面板（顶层+底层）最便宜；四层板（TOP + 完整 GND 平面 + PWR 平面 + BOTTOM）贵一些，但中间有完整地平面，回流、屏蔽、控阻抗全部上台阶。

判断表（工程经验值）：

| 情况 | 建议 |
|------|------|
| 时钟几十 MHz 以内、器件稀疏、成本敏感 | 双面板 + 认真铺地铜，够用 |
| 带 USB / 高速总线 / 密集封装 / 模数混布 | 四层板起步 |
| 信号速率高到需要控阻抗 | 四层板（有完整参考平面才控得住阻抗） |
| 成本与速率冲突 | 优先保地平面完整：宁可砍功能，也别双面板硬凑 |

四层板最经典的叠层（JLC04161H 一类常见工艺，叠层参数以打样厂页面为准）：

```
层 1  TOP        元件 + 短信号
层 2  GND        完整地平面（不切割！）← 顶层信号的正下方回流面
层 3  PWR        电源平面 / 大铜块
层 4  BOTTOM     元件 + 次要信号
```

为什么这样排：关键信号放 TOP，紧贴层 2 完整地平面——回流永远在正下方，环路最小；层 3 做电源平面，与层 2 靠近还白送一层"平板电容"帮助电源去耦。

成本现状：国产打样四层板与双层板的差价已经不算大（以打样厂实时报价为准），学习阶段"该上四层就上"，把精力花在设计上而不是救火上。

## 6. 常见 EMI/ESD 措施速查

> **这是什么**：手头常备的"防干扰零件"，每个用一句话记住用途，别用错地方。元器件基础回顾见 [07-工业常用元器件速查手册](../../02-电路基础/笔记/07-工业常用元器件速查手册.md)。

| 器件/措施 | 一句话用途 | 布局关键 |
|-----------|-----------|----------|
| TVS 二极管 | ESD/浪涌来的瞬间导通钳位，牺牲自己保护后级 | **必须贴近接口/连接器**，先 TVS 后电路，接地路径短而粗 |
| 共模电感 | 对共模噪声呈大阻抗，挡住顺着线缆进出的共模干扰 | 串在线缆入口处，前后留净空 |
| 磁珠 | 高频段呈高阻抗，"吃掉"电源支路上的高频噪声 | 串在敏感供电支路，靠近被保护端 |
| RC 吸收（snubber） | 吸收开关瞬间的尖峰振铃 | 就近并联在继电器触点、开关节点两端 |
| 屏蔽罩 | 对辐射"物理捂住" | 罩边缘与地良好搭接，否则等于没罩 |
| 接口地接机壳 | 让静电从接口直接泄放进机壳 | 接口旁的安装孔/机壳地连接点 |

ESD 防护思想一句话：**让静电"从哪来回哪去"，走最短路径入地，别让它流经芯片**。

## 7. 电源完整性的"够用版"

> **这是什么**：电源完整性（PI）研究一个问题：芯片脚上"抽电"的瞬间，电压掉不掉。够用版就三板斧——去耦电容阵列 + 大水塘 + 电源平面思想。

1. **去耦电容阵列**：每个电源脚一颗 0.1µF（贴脚）+ 每个电源区域一颗 10µF 级。不同容值谐振频点不同，组合起来覆盖宽频段【经验值】；
2. **大水塘**：板级 100µF 级电解/聚合物电容，稳住"整体抽水"的低频波动——电机启动、无线模块发射的瞬间全靠它兜底。位置放在电源入口和"大胃口"负载旁边，不用挨着每个芯片；
3. **电源平面思想**：四层板用整层做 PWR/GND 平面，供电阻抗最低；双面板做不了平面，就"电源主干走粗线 + 与地并肩"，把回流环路控制住。电源选型与纹波来源见 [01-电源设计进阶](../../14-进阶专题/笔记/01-电源设计进阶.md)。

去耦电容为什么必须贴脚：贴远了，焊盘+走线的寄生电感就把电容"架空"——电感在高频下是拦路的，等电容反应过来芯片已经饿过了。所以**电容的位置比数量重要**。ADC 读数乱跳的场景还会结合软件滤波，参见 [05-DMA与ADC](../../07-STM32/笔记/05-DMA与ADC.md) 与 [05-负反馈与模拟前端实战](../../04-模拟电路基础/笔记/05-负反馈与模拟前端实战.md)。

三层结构分工一张表：

| 层级 | 谁负责 | 管什么频段（大白话） | 放哪 |
|------|--------|----------------------|------|
| 0.1µF 去耦 | 电容阵列 | 芯片脚"瞬间抽水"的高频抖动 | 紧贴电源脚 |
| 10µF 区域储备 | 区域电容 | 一个区域的中频波动 | 每个功能区块角落数量 1~2 颗 |
| 100µF 大水塘 | 板级储能 | 整板低频"抽水高峰" | 电源入口 + 大负载旁 |

## 常见坑（新手必看）

1. **晶振下方走其他信号线**：晶振是全板的"心跳"，底下穿线等于把杂讯直接拍进心跳——晶振区域地铜净空，其他线绕行；
2. **接口 TVS 摆太远**：TVS 离接口 3cm，静电在半路就窜进芯片了，装了等于没装——TVS 必须第一个站岗，贴接口放；
3. **分割地乱切**：为了"模拟地数字地分开"把地铜切成迷宫，回流绕大圈，串扰和辐射反而更重——新手阶段统一整块地，不会错；
4. **过孔换层不留回流孔**：信号打孔去了底层，回流还在顶层平面，不在孔边补地过孔，环路变大，时钟线尤其明显；
5. **盲目包地**：到处拉"包地保护线"却说不出防的是谁，占布线空间还没效果——先想清楚干扰路径，再决定要不要包；
6. **去耦电容摆成一排挂在电源干线上**：看着有 10 颗 0.1µF，但离芯片脚都很远，等于没贴——位置比数量重要；
7. **长排线直连快边沿信号**：30cm 排线拉 SPI 时钟，振铃严重还对外辐射——源端串 22~33Ω（经验值）或直接降通信速率。

## FAQ

**Q：我的板子就是个最小系统，也要管这些吗？**
A：管住三件事就赢：去耦贴脚、晶振净空、地铜完整。其余规则在你拉长线、加继电器、上高速总线时才真正登场。

**Q：50Ω 要不要拿万用表量走线验证？**
A：不用也不行。特性阻抗由线宽/叠层/介质决定，靠计算工具和厂家工艺保证，万用表量的是直流电阻，量不出来。

**Q：双面板铺铜，顶层底层都铺地吗？**
A：学习阶段最稳的口诀：两面都铺 GND，多打地过孔缝合，保证信号线正下方总有完整地铜。"一面地一面电源"的玩法等你吃透回流再玩。

**Q：EMC 是不是只有做产品过认证才需要？**
A：认证是"别人逼你过"；但 ADC 乱跳、一动继电器就复位、插上 USB 触摸屏失灵这些日常 bug，本质都是 EMC 没做好——学它是为了少熬夜。

**Q：怎么快速判断问题是干扰还是软件 bug？**
A：看相关性：问题是否总跟着"外部事件"出现（插拔 USB、吸合继电器、电机启动）？是→大概率硬件干扰；纯随机且与事件无关→先查软件。

**Q：磁珠和 0Ω 电阻、普通电感怎么区分着用？**
A：0Ω 电阻用于"可选断开"的连接点；普通电感储能用（DC-DC 里）；磁珠是"高频电阻"，专串在供电支路上吃噪声——三者长得像但职业不同，别互相顶班。
